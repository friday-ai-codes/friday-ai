# Phase 65 Plan 01 — AI 对话串流隔离

## Goal
把前端全局单例 streaming 状态与副作用改为按 `conversation_id` 隔离，切会话不串台。

## Tasks
1. `useSSEStream.connectSSE` 引入本流局部 `streamRunId` + `options.onRunId`，模块级 `currentRunId` 降级为 `lastRunId`（兼容旧 `getCurrentRunId`，标 @deprecated）。
2. `chat.ts` `handleSSEEvent(event, ownerConversationId?)` 前台守护：owner ≠ current 时仅放行 `title_generated` 列表标题更新，其余 return。
3. `chat.ts` `sendMessage`：onEvent 注入 owner；断线轮询与 error 写入用 `ownerConversationId === currentConversationId` 守护；本流 run_id 用局部 ref；finally 以 `isCurrent` 守护全部「写当前 UI」收尾。
4. 新增 `chat.stream-isolation.spec.ts` 守护（后台不写当前 UI / 前台零回归 / title_generated 列表更新 / 未传 owner 零回归）。
