1. query = `(session.decomposition or {}).get("requirement_text", "")`。空 query → 返回 `{"hits": [], "query": "", "kinds": [str(k) for k in RECALL_ENTITY_KINDS]}`（不调检索）。
2. repository_ids：用路由候选仓收窄召回 —— 读 `(session.routing or {}).get("candidates")`，非空则 `repository_ids = [c["repo_id"] for c in candidates if c.get("repo_id")]`，否则 None。
3. user = `session.created_by`（38-01 新增字段；为 None 时不特殊处理，直接透传——search_similar 经 `resolve_allowed_project_ids(None)` 返回 [] → fail-closed 空召回，不泄漏越权数据）。
4. 调 `results = await DeliveryKnowledgeSearchService().search_similar(query, user=user, top_k=self.top_k, entity_kinds=[str(k) for k in RECALL_ENTITY_KINDS], repository_ids=repository_ids)`（import `from knowledge.retrieval import DeliveryKnowledgeSearchService`）。整段包 `try/except Exception`：任何异常 → log warning（structlog）+ 返回空 hits（best-effort 不阻断编排，对齐 38-CONTEXT「失败返回空不抛」）。

6. 返回 `{"hits": hits, "query": query, "kinds": [str(k) for k in RECALL_ENTITY_KINDS]}`（hits 落 recall_context；query/kinds 供 engine 发 §15 事件——engine 由返回值取 trace 字段，保持 engine 与具体 adapter 解耦）。
