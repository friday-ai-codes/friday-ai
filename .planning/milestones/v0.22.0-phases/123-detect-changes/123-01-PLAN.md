① `DiffMirrorResult` frozen dataclass：`base_sha: str` / `head_sha: str` / `unified_diff: str`。

② `async def diff_mirror(base: MirrorSnapshot, head: MirrorSnapshot, *, timeout: float = 120.0) -> DiffMirrorResult`（per D-01/D-06）：
- 若 `base.repo_dir != head.repo_dir` 或 `repository_id` 不同 → `MirrorError("invalid_params", …)`
- `_run_git(["diff", "--unified=0", "--find-renames", base.commit_sha, head.commit_sha], cwd=base.repo_dir, timeout=…, max_output_bytes=DETECT_CHANGES_MAX_DIFF_BYTES)` —— **two-dot**，⛔ 禁止 `A...B`
- rc 仅允许 0 或 1；其他 → `MirrorError("mirror_fetch_failed", _scrub(stderr)[:300])`
- 返回 DiffMirrorResult

③ `async def ensure_mirror_sha(repository_id: str, sha: str, …) -> MirrorSnapshot`（RESEARCH A3 / Discretion 采纳）：
- 校验 `_SHA_RE.match(sha)`；非法 → `MirrorError("invalid_params", …)`
- 复用 `ensure_mirror_commit` 的 bare 目录与 token/proxy 路径；fetch 用 `+{sha}:refs/friday/pin-{sha[:12]}`（与现有 pin 同构），⛔ 不得 `refs/heads/{sha}`
- 返回的 `commit_sha` 必须等于请求 sha（或 resolve 后的完整 40 位）

常量：`DETECT_CHANGES_MAX_DIFF_BYTES = 16 * 1024 * 1024`。观测：mirror 失败已有路径保持 `_scrub`；新增日志若有则 `component` 沿用 mirror 既有约定，stderr 必 scrub（T-123-CRED）。

⛔ 不改 `ensure_mirror_commit` 对 base_ref 的 pin 语义；不引入 GitPython DiffIndex。
