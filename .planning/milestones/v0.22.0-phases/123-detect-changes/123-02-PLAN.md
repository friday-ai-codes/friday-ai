流程（严格顺序）：
1. `await ensure_repository_readable(user, repository_id)` —— ACL 失败上抛 `GraphAccessDenied`（壳层翻译；⛔ 不 catch 成空清单；D-03 / T-123-ACL）
2. 若无 `repo.last_indexed_commit_sha` → 返回 `ok=False, error_code="repository_not_indexed"`（D-03）
3. `base = await ensure_mirror_commit(repository_id)`（pin 索引水位；D-01）
4. head：若 `compare` 匹配 40 位 sha → `ensure_mirror_sha`；否则 `ensure_mirror_commit(repository_id, branch=compare)`。若解析后 `head.commit_sha == base.commit_sha` → 返回明确 `error_code`（推荐 `empty_diff_range`）或 `ok=True` 空 files + 声明「compare 与索引水位相同」——二选一写进 docstring 与测试，⛔ 静默假装「无改动且可信」（Pitfall 6）
5. `diff = await diff_mirror(base, head)`；`MirrorError` → 折成 `ok=False, error_code=exc.code, error=exc.detail`（推荐编排层折信封，双面同形；D-03）
6. `parse_unified_diff` → 收集触及路径 → ORM 批量查 `Symbol`：`repository_id` + `branch_name=""` + `file_path__in=…`（⛔ 不用 feature overlay；RESEARCH Pattern 2）
7. `_exclusion_matcher_for_repo` fail-closed 过滤路径后再交叠（T-123-EXCL / GRAPH-04）
8. `detect_affected_symbols(...)` → 按文件分组（D-15）
9. impact 种子 = `impact_seed=True` 且非 `formatting_only` 的 uid 列表（D-07）
10. 若种子数 > `DETECT_CHANGES_MAX_SYMBOLS_FOR_IMPACT`(100)：`impacts=[]`，`summary.truncated=True`，`summary.not_expanded=True`，**零次** `run_impact`（D-08 / T-123-DOS）；仍须填 `graph`——对任意 touched 符号或空仓路径调用一次 `fetch_graph_for_tool(..., graph_branch=None)` 取 `degradation_payload(meta)`（RESEARCH A5 采纳）
11. 否则 **顺序** for-loop `await run_impact(repository_id=…, repo=repo, graph_branch=None, user=user, symbol_id=sid, max_depth=…, min_confidence=…, include_low_confidence=…, limit=…)`（D-09/D-10/D-11）。单次 `GraphError` → 该条 `impact_error`/`unavailable_reason`，继续（D-12）。并发若做，上限≤3 且默认仍顺序——本 plan **选定顺序 for-loop**（Discretion）。
12. 成功返回：`ok=True, tool="detect_changes", repository_id, diff_base_sha, diff_head_sha, base_ref（若有）, files, impacts, summary{affected_symbol_count, impact_seed_count, truncated, not_expanded, …}, affected_processes=[], staleness=await staleness_payload(repo), graph=degradation_payload(...)`。`as_of` 经 staleness；behind 大时加强 `declaration` 文案但不硬拒（D-04/D-14）。

观测（D-16）：`code_graph_detect_changes_started|completed|failed`，`category="caller"`, `component="code_graph"`, 带 `duration_ms`；best-effort try/except pass。⛔ 日志不含 token、不含整段 diff。
