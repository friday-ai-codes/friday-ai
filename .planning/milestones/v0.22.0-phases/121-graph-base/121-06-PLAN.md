🚨 与 `load_graph` 同款契约：`matcher` 与 `exclusion_fingerprint` 是**必填关键字参数**，由 `cache.py` 解析一次后注入；⛔ 本函数**不得**调用 `build_matcher_and_fingerprint`（同一次请求内二次解析 = 一次 DB 读 + 全量 glob/regex 重编译，且这条同步路径吃不到 `build_matcher_for_repo` 的 60s `_matcher_cache`）。返回单值 `CodeGraph`。

每轮 frontier 设上限常量 `SUBGRAPH_FRONTIER_LIMIT: Final[int] = 5000`，超出即截断并在元数据/日志计数（防种子选在超级枢纽符号上时子图退化成全图）。

然后只按最终 symbol_id 集合取 `Symbol` 行装配节点（同样过 exclusion 与 overlay 去重），并复用 Task 121-05/06 的边装配逻辑（限定在该节点集内）。
