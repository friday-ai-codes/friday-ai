# Phase 81: 项目工作台 - UI 设计契约（UI-SPEC）

**Created:** 2026-06-26
**Scope:** UI-01（列表）/ UI-02（详情工作台）/ UI-03（记忆确认 + 工件类型管理）
**Design system:** 复用既有 Friday 控制台风格——Tailwind 4 + reka-ui + CVA；与 `web/src/pages/spaces/` 视觉/布局一致；默认中文（vue-i18n）。**不引新 UI 库**。

---

## 0. 设计原则

- **复用优先**：列表/详情骨架、卡片、表格、对话框、表单、徽标全部复用既有组件与 spaces 页范式；只新增项目域专属内容。
- **稳定与兜底**：每个数据区有 loading 骨架 / 空态 / 错误兜底；危险操作（删类型/转主R/终止项目/拒绝草稿）走 `useConfirmDialog` 二次确认。
- **权限驱动**：非 Space 成员无入口；非项目成员只读或不可见（与后端 fail-closed 对齐，前端不作权威，仅体验）。
- **i18n 全量中文**：所有可见文案进 `zh-CN.json`；守护测试以真实 messages 断言关键文案。

---

## 1. UI-01 项目列表 `/projects`

- **布局**：顶部标题 + "创建项目"主按钮（复用 Phase 77 `CreateProjectModal`）；筛选栏（Space 下拉 / 状态多选 developing·archived·terminated / 成员筛选 / 关键词搜索）；下方项目卡片网格或表格。
- **项目卡片**：项目名 + 所属 Space 徽标 + 状态徽标（开发中=绿/归档=灰/终止=红）+ 成员头像组（带主R 标识）+ 工作项/工件计数 + 飞书看板关联标识。点击进详情。
- **状态**：加载=骨架卡片；空=引导创建插画 + 文案；错误=重试。
- **数据**：`projects.ts` list（支持 space_id/status/member/q 查询参数，TanStack Query）。

## 2. UI-02 项目详情工作台 `/projects/[id]`

- **头部**：项目名（可编辑，主R/有权成员）+ Space 面包屑 + 状态切换（开发中→归档→终止，非法流转禁用 + 提示）+ 飞书看板链接 + 操作菜单。
- **Tab 导航（懒加载）**：
  1. **概览**：描述 + 关键计数 + 最近活动（记忆/工作项/MR 时间线摘要）+ Cursor rules 模板"复制/下载"入口（CURSOR-02）。
  2. **成员**：成员表（头像/姓名/身份角色徽标：主R·PM·前端·后端·测试）+ 增删改（有权）+ **主R 转移**（确认对话框，唯一约束）+ 未映射飞书人提示可补绑。
  3. **工作项**：story / 缺陷列表（类型徽标 + 飞书三元组 + 状态）+ 手动并入/移除（COMPOSE）。
  4. **工件**：按 `ArtifactType` 分组列表 + 在线查看——飞书 doc/表格内嵌渲染（Phase 79 后端 API）、外链跳转、md/内部可编辑（编辑器复用既有）；UI 稿仅元数据卡 + 外链。每工件显示载体/版本/贡献者。
  5. **记忆**：时间线（条目 + 时间戳 + 贡献者）+ 新增/编辑（保留修订历史可展开查看）+ **LLM 提议草稿区**（见 UI-03）。
  6. **关联**：知识/仓库/项目/PR·MR 关系列表（KnowledgeEdge 派生，分组 + 关系类型标签 + 跳转）；MR 卡显示源/目标分支 + 状态(open/merged/closed) + review 状态 + 平台。
- **实时**：订阅项目 WS（成员/状态变更即时刷新，Phase 77）。

## 3. UI-03 记忆确认 + 工件类型管理

- **LLM 记忆提议确认**（记忆 Tab 内或抽屉）：draft 列表（pending）——每条显示提炼内容 + 来源会话 + 时间；操作"接受入库 / 编辑后入库 / 拒绝"（接受=确认对话框；入库经 Phase 80 `MemoryService.create_from_draft`）。脱敏后内容展示，绝不展示原始凭证。
- **工件类型后台管理** `/admin/artifact-types`（或设置区，超管）：类型表（key/名称/载体/可 RAG/启用/内置）+ 新增自定义类型 + 启停切换（禁用即时：明示"不可新建实例、既有只读"）+ 删除（**builtin 禁删、有实例禁删** → 按钮禁用 + tooltip 说明）。危险操作二次确认。

---

## 4. 验收（前端）

- 三个 UI 需求页面可达、数据接通 Phase 77~80 API、筛选/创建/编辑/确认闭环可用。
- `pnpm vue-tsc --noEmit` 绿；新增组件 vitest 守护（i18n 文案 + 权限态 + 空/错/载态）；不破坏既有 ~130 前端测试。
- 视觉与既有控制台一致，全中文，骨架/空/错兜底齐备，危险操作有确认。

> 注：figma 设计稿未提供——本 UI-SPEC 以既有 `web/src/pages/spaces/` 与 Friday 控制台设计系统为视觉权威，执行时复用其布局/组件 token，不自创风格。
