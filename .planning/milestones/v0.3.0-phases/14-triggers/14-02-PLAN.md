## 规划定案（供 verify 对照）

- **OQ-1（规划定案）**：GitHub skip-PR 路径全量 diff 经新增 `get_branch_diff` 抽象方法获取——GitLab 包 `repository_compare`（diffs[].diff 自带 per-file 文本），GitHub 包 `repo.compare` + `file.patch`；统一返回 `MRDiffResult`（复用既有 dataclass，不新增 DTO）。
- **截断语义（Pitfall 2 / A1 / A2）**：平台侧 patch 字段缺失、文件数/行数超 max 参数 → 该文件 diff 置空或截断 + `truncated=True`；不补本地 git 兜底（范围克制）。
- 既有 `compare_branches`（冲突预检/统计语义，返回 BranchCompareResult）**不改动**——get_branch_diff 是并列新方法，语义为"取全量 diff 文本"。

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| 平台 API → MRDiffResult | 外部平台返回的 diff 文本/文件清单不可信（超大、缺字段） |
| 凭证 → client | token 仅经构造注入，方法体不得触碰凭证存储 |

| T-14-07 | Tampering（平台返回畸形字段） | MRDiffFile 组装 | mitigate | getattr/dict.get 判空取用，缺字段降级空串 + truncated，不让单文件异常拖垮整批（Test 2/4） |
