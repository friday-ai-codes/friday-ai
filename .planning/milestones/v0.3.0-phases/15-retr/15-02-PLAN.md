## 规划定案（供 verify 对照）

- **Filter 封装（P1/P6）**：`_build_knowledge_filter(allowed_project_ids, entity_kinds, include_superseded)` 私有函数；`include_superseded` 仅当 True 时省略 is_latest 条件——默认 False 恒 true。禁止 export 无 filter 的 raw search  helper。
- **分路配额（P5）**：demand 路 kinds=[work_item, tech_plan] quota=ceil(top_k*0.7)；code 路 kinds=[code_change] quota=ceil(top_k*0.3)。跨路 RRF：对两路 hit 列表按 chunk point id 做 RRF rank fusion（k=60，与 Qdrant Fusion.RRF 常数同级），再 entity_id dedupe 保留最高 RRF 分。
- **Qdrant filter 构建**：扩展 knowledge 模块内 `_build_knowledge_must_filter` 直接使用 qdrant_client.models（不修改 QdrantService._build_filter 全局语义——code index 与 knowledge 字段不同）。
