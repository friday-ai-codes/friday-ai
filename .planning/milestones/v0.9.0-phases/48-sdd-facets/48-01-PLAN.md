    - openspec/ 存在 + facets 无 methodology → 写 facets["methodology"]="SDD"，asave 被调用，返回 True
    - openspec/ 不存在 + facets["methodology"]=="SDD"（自动写入）→ 删除 methodology 键（防漂移/陈旧），asave 被调用，返回 True
    - openspec/ 不存在 + facets["methodology"]=="自研流程"（非 SDD 的他值）→ 不动、不 save，返回 False
    - openspec/ 存在但 "methodology" 在 facets["_pinned"] 列表 → 跳过（不读写、不 save），返回 False（尊重人工 pin，复用 FacetService pin 语义）
    - openspec/ 存在 + facets["methodology"] 已为 "SDD" → 无变更 → 不 save（幂等），返回 False；二次调用后 updated_at 不变（断 updated_at 漂移）
    - Repository 不存在（id 无匹配）→ 直接返回 False，不抛
    - openspec 为文件而非目录（repo_path/openspec 是普通文件）→ 视为不存在（os.path.isdir 语义），不打标
  </behavior>
  <action>
    新建 `server/services/sdd_detect.py`，镜像 `sensitive_detect.py` 的模块形状（`from __future__ import annotations`、`structlog.get_logger(__name__)`、`__all__`），但**纯文件系统探测、无重依赖**（D-48-5）：仅 import `os` 与 structlog，函数体内惰性 import `Repository`；**禁止** import indexer / tree-sitter / LLM / FacetService（避免重依赖与循环）。

    实现 `detect_and_tag_sdd(repository_id, repo_path)`（D-48-2/D-48-3，SDD-01）：
    1. 判据：`present = os.path.isdir(os.path.join(repo_path, "openspec"))`（仓库根存在名为 openspec 的目录；最小充分信号，不解析内容——内容校验留 v2 SDDX-01）。
    2. 惰性 `from repositories.models import Repository`，`repo = await Repository.objects.filter(id=repository_id).afirst()`；`repo is None` → return False。
    3. `facets = dict(repo.facets or {})`；`pinned = set(facets.get("_pinned", []))`。若 `"methodology" in pinned` → return False（尊重 pin，复用 facet_service.py pin 语义，不写不清）。
    4. 计算目标：present 时 `facets["methodology"] = "SDD"`；present 为假且 `facets.get("methodology") == "SDD"` 时 `del facets["methodology"]`（仅清除**自动写入的 SDD**，防漂移；其他值不动）。
    5. 幂等 no-op 守护（关键，D-48-3）：若新 facets dict 与原 `repo.facets` **相等**则**不调用 asave**直接 return False——因 `updated_at = auto_now=True`，多余 asave 会漂移 updated_at。仅在确有变更时 `repo.facets = facets` 并 `await repo.asave(update_fields=["facets", "updated_at"])`，return True。
    6. 结构化日志（structlog 约定）：打标成功 `logger.info("sdd_detected", repository_id=str(repository_id), methodology="SDD")`；清除 `logger.info("sdd_tag_cleared", repository_id=str(repository_id))`。
    7. methodology 为本 phase 新增**独立语义键**，与 `FacetService` 事实分面键不冲突（对齐 facet_service.py 既有约定，FacetService 不碰 methodology）。

    同步建 `server/tests/test_sdd_detect.py`，覆盖 behavior 全部用例（pytest-asyncio + pytest-django，`@pytest.mark.django_db`；用 `tmp_path` 构造含/不含 openspec/ 的目录；幂等用例先 detect 一次取 `repo.updated_at`，再 detect 断言不变）。参照 server/tests 既有异步 ORM 测试写法。
