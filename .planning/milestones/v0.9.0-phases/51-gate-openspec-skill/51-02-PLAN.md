## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| 编码派发决策 → 容器 | gate 是「未批准 spec 仓不得编码」的唯一拦截点；fail-open 会让未治理代码进生产 |
| gate 校验异常处理 | 异常若 fail-open 或冒泡崩 wave 都不可接受 —— 必须 fail-closed + 隔离 |
| dispatch metadata → runner env | follow_openspec env 只应对 approved SDD 仓注入，误注入非 SDD 仓会改其编码行为 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-51-GATE | Elevation | _dispatch_wave gate | mitigate | follow_openspec=True 仓强制 SddSpec.status==APPROVED 校验，未批准拦截不 dispatch（不静默放行，GATE-01） |
| T-51-FAILOPEN | Tampering | gate 异常路径 | mitigate | gate 校验异常 fail-closed（视未批准 reason=gate_error），绝不放行未校验 SDD 仓编码（D-51-5） |
| T-51-DOS | Denial of Service | gate 异常隔离 | mitigate | 单仓 gate 异常 try/except 隔离，绝不崩整 wave 调度；其余仓正常 dispatch（liveness 保护，D-51-5） |
| T-51-ENVLEAK | Information Disclosure | env 注入 | accept | env_FRIDAY_TASK_FOLLOW_OPENSPEC 仅布尔信号无敏感数据；与 PF-06 既有 env 注入面同级，低风险 |
</threat_model>
