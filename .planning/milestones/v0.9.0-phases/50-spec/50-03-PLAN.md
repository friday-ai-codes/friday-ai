<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client→/api/specs/ | 未授信输入（action/comment/过滤参数）跨界；评审/归档为高权限操作 |
| 认证用户→受限 action | 非 superuser 不得 approve/reject/archive/mark_implemented |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-50-07 | Elevation of Privilege | transition 受限 action | mitigate | view 内读 action 后显式 superuser 判定，非 superuser 403（D-50-3 fail-closed）|
| T-50-08 | Information Disclosure | spec 存在性 | mitigate | 不存在统一 404 中性消息；不因权限差异区分 403/404 之外的泄漏 |
| T-50-09 | Tampering | 状态直改 | mitigate | 序列化器全 read_only，状态仅经 transition→SddSpecService，禁 PATCH |
| T-50-10 | Spoofing | reviewer 伪造 | mitigate | reviewer 强制取 request.user，不接受 body 传入 |
| T-50-11 | Denial of Service | 过滤参数注入/异常 | mitigate | status/repository_id 非法值前置 400，不触 service/不穿透 500 |
</threat_model>
