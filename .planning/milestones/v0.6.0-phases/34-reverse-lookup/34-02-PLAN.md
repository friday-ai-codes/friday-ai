<objective>
交付 RREF-02「评论入图」：把 Phase 29 `project_comment_tree(work_item)` 投影出的当前评论树文本并入 `feishu_work_item` 知识实体的投影内容（作为 work_item 快照的评论段），并在评论事件流更新后触发 work_item 重投影——使评论可被既有检索召回且天然关联到 WorkItem。

Purpose: 评论承载需求澄清/审批语义，纳入 work_item 知识投影后，agent 检索需求时能看到评论上下文，是 v0.7 评论触发方案再生成的数据前置（本 phase 仅入图，不做再生成）。
Output: `feishu_work_item` 投影增评论段（最少改动、不破坏既有快照）+ 评论事件→work_item 重投影触发（best-effort，不阻塞）。不新增 EntityKind、无新 model、无 migration。
</objective>

<interfaces>
- `project_comment_tree(work_item) -> list[dict]` / `aproject_comment_tree`（async 包装，Phase 29）：从事件流读时投影当前评论树（线程层级），节点含 `feishu_comment_id/author/body/event_type/approval_semantic/is_deleted/event_time/children`。读时计算、不写库、确定性排序（同层 event_time 升序）。
- `feishu_work_item.normalize(request) -> list[IngestionEvent]`：现产单一 work_item 全量快照事件，content 为 `## 分段` markdown（`info.name`/description/自定义字段/PRD/技术方案/关联工作项）。**feishu_document.normalize 复用本函数产出**——改 content 会同步反映到 document 路径的 work_item 锚，二者保持一致（非破坏）。
- delivery `WorkItem` 三元组键：`(feishu_project_key, work_item_type, work_item_id)`；解析参考 `feishu_document._resolve_work_item`（int 转换失败返回 None）。
- `aschedule_ingestion(IngestionRequest)`：触发点唯一入口，`transaction.on_commit` + 后台投递，**异常全吞永不阻塞主流程**。重投影传 `IngestionRequest(source_kind="feishu_work_item", source_id=triple, trigger="comment_event_appended")`。
- ingestion hash-no-version：content 不变 → content_hash 相等 → `_persist_sync` 不翻版本（评论无变化重投影是幂等 no-op）。
</interfaces>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| 评论事件流 → knowledge 投影 | 评论 body（业务内容）进入 work_item 知识实体投影，经既有检索召回 |
| comment_event_service → ingestion 触发 | 重投影触发不得阻塞/回滚评论落库（操作态事实源优先） |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-34B-01 | Information Disclosure | 评论入 work_item 投影 | accept | 评论文本经既有 `DeliveryKnowledgeSearchService` 召回，沿用 Phase 15 access_scope（project 维度权限过滤）；不新增暴露面、不放宽既有权限，风险等同既有 work_item 快照 |
| T-34B-02 | Denial of Service | 评论触发重投影 | mitigate | 仅 created_count>0 触发；aschedule_ingestion on_commit + 后台 + 异常全吞，幂等重复摄取（hash 相等）不翻版本，不放大写放大 |
| T-34B-03 | Tampering | 评论事件流 | mitigate | 评论入图为读时投影（project_comment_tree 不写事件行）；事实源仍是 append-only WorkItemCommentEvent（INV-3/INV-6 不变） |
| T-34B-04 | Availability/降级 | 评论投影缺料 | mitigate | 无 WorkItem/无评论/投影异常 → 快照缺评论段 + warning，不抛不回滚（缺段不缺实体，专测 guard ⑤） |
