<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| 浏览器→API | 用户选取/拖拽/粘贴的本地图片经 multipart 上传（前端校验为体验前置，后端权威——见 35-01 T-35-01） |
| 渲染层→召回结果 | 后端已脱敏的 work_item 召回项 + degraded_reason 渲染（不二次拼接敏感信息） |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-35F-01 | Denial of Service | 前端上传 | mitigate | 前端校验 ≤10MB + MIME 白名单，超限/非图片不发请求（后端 35-01 T-35-01 权威兜底） |
| T-35F-02 | Information Disclosure | 外链渲染 | mitigate | 召回外链 a[target=_blank] 强制 rel="noopener"（防 window.opener 反向控制） |
| T-35F-03 | Tampering | objectURL 内存 | mitigate | URL.createObjectURL 替换/卸载时 revokeObjectURL，避免泄漏/泄露内存 |
| T-35F-04 | Information Disclosure | degraded/error 文案 | accept | 仅渲染后端已脱敏 degraded_reason 与固定 i18n 文案，无前端敏感拼接 |

> 无 npm 新依赖（复用既有 reka-ui/vue-query/vue-i18n/lucide）→ 无供应链 T-35F-SC。
</threat_model>
