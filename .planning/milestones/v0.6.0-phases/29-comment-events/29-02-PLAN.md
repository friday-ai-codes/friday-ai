    定义 `CommentEventService`：

          · feishu_comment_id 缺失 → 跳过 + warning（不构造无锚事件）；
          · event_time = _parse_ms(created_at)（毫秒戳→aware UTC，缺失 None）；
          · semantic = classify_approval_semantic(body)；
          · event_type 推导：semantic != "none" → "approval"；否则 thread_parent_id 非空 → "replied"，空 → "created"（per CONTEXT Grey Area 3：edited/deleted 本 phase 不合成，留待真实信号）；
          · **去重锚** (work_item, feishu_comment_id, event_type, event_time) 经 `WorkItemCommentEvent.objects.get_or_create(..., defaults={author/body/thread_parent_id/attachments/approval_semantic})` 实现幂等可重入（同评论多次拉取不产生重复事件，CONTEXT）；
          · attachments 取 comment dict 的 attachments（parse_comments 当前未产出则默认 []，不臆造）。
        返回新建事件数。整个写入经 sync_to_async 包裹（可整批一个同步函数内循环 get_or_create）。
      - `async def ingest_comments(self, identity, source: str) -> dict`：**拉取式摄取路径**（供 manual/编排 Phase 32 调用）。
          · _resolve_project(identity.feishu_project_key)；缺 project → comments facet 记 missing+error="project_unconfigured"，返回降配结果（不抛）；
          · 经 create_feishu_client_for_project 调 get_comments(project_key, work_item_id, work_item_type)（复用 Phase 27，**不重写解析**）；try/except 包裹，回源异常 → _safe_error 脱敏 + warning + comments facet=missing/error，**不回滚 WorkItem**（WIT-03 范式）；
          · resolve 已落库 canonical work_item（按三元组 afirst）；缺 work_item → 记 missing + warning 跳过 append（CONTEXT：缺 work item 跳过）；
          · 成功 → append_events → comments facet=complete（拉取空列表也算 complete，不假装 missing）。
        record SyncState 复用 work_item_service 同范式：`WorkItemSyncState.objects.update_or_create(work_item, facet=SyncFacet.COMMENTS, defaults={status/source/last_synced_at/error})`（经 sync_to_async）。
      - `async def append_webhook_comment(self, identity, *, comment_id, body, author="", thread_parent_id="", created_at=None, source) -> int`：**webhook 接线路径**（29-03 调用）。按三元组 afirst 解析已落库 work_item；缺 work_item → warning 跳过返回 0（不创建 WorkItem，那是 upsert 的职责，CONTEXT）。把单条 webhook 评论归一成 append_events 接受的 dict（id=comment_id, content=body, created_at, author, thread_parent_id），调 append_events 返回计数。

    在 server/delivery/services/__init__.py re-export `CommentEventService`、`classify_approval_semantic`（project_comment_tree 在 Task 2 加入），更新 __all__。
