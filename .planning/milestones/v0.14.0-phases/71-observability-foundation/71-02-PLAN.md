新建 `server/system/log_sink.py`（中文 docstring，best-effort 绝不反噬业务，沿用 `log_buffer.append_log` 的 `except: pass` 范式）：
- 模块级 `_queue: deque[dict] = deque(maxlen=5000)`（满则左端自动丢弃——但 maxlen 自动丢弃不会触发计数，故**手动**判定：append 前 `if len(_queue) >= _MAXLEN: _dropped += 1; return`，再 append，保证 log_dropped_total 精确）。`_lock = threading.Lock()`。`_MAXLEN = 5000`。
- 四计数模块级 int（加锁更新）：`_enqueued`（入队成功）、`_written`（成功落库条数）、`_dropped`（队列满丢弃）、`_write_failed`（落库失败条数）。
- `def enqueue_system_log(entry: dict) -> None`：线程安全入队；满则 `_dropped += 1` 不抛；整体 `try/except: pass`。entry 已是脱敏后的 dict（由 processor 传入）。**绝不**在此做 ORM（入队是同步热路径，落库交后台 worker）。
- 后台批量 worker：复用 `services.background_runner` 不合适（它是请求脱离用 loop），日志 worker 用**专用 daemon 线程** + 定时/阈值触发（per 71-CONTEXT）。实现 `def _ensure_worker() -> None`（懒启动加锁单例 daemon 线程，名 `friday-log-sink`），循环：每 `_FLUSH_INTERVAL`（默认 1.0s）或队列积压达 `_BATCH_SIZE`（默认 200）时，加锁 drain 一批 → `_flush(batch)`。`_flush` 把 batch dict 转 `SystemLogEntry(**mapped)` 列表，一次 `SystemLogEntry.objects.bulk_create(objs, ignore_conflicts=True)`；成功 `_written += len`，异常 `_write_failed += len(batch)` + best-effort（绝不抛、不重试无限循环——失败批丢弃，per "永不反噬业务"）。ORM 在 daemon 线程同步调用（线程内无 async loop，直接同步 ORM 安全）。
- dict→model 字段映射 helper `_to_entry(d)`：解析 `ts`（ISO str→datetime，失败用 now）、`level`（归一小写 + WARNING→warn）、component/category/event/message/user_id/source/trace_id/request_id；剩余非标准字段收进 `payload`；从 payload 提取 run_id/conversation_id/execution_id 等到 `correlation`。
- `def snapshot_counters() -> dict[str, int]`：返回 `{"queued": len(_queue), "max": _MAXLEN, "enqueued": _enqueued, "written": _written, "dropped": _dropped, "write_failed": _write_failed}`（供 71-04 计数端点与 73 快照采集，per 71-CONTEXT「队列四计数必须可被快照采集」）。
- `def _reset_for_tests() -> None`：清队列 + 计数（测试钩子）。提供同步 `flush_now()`（测试直接 drain+落库，便于断言）。
新建 `server/tests/test_system_log_sink.py`（pytest-django，db marker）：
  - enqueue 200 条 → `flush_now()` → `SystemLogEntry.objects.count()==200` + counters written==200。
  - 队列满（塞 5001 条不 flush）→ dropped>=1、queued<=5000。
  - `_to_entry` 把 WARNING→warn、缺 ts 用 now、未知字段进 payload、conversation_id 进 correlation。
  - bulk_create 抛错（monkeypatch）→ write_failed 递增、不冒泡（enqueue/flush 不抛）。
