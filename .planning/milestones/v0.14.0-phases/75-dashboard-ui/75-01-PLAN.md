   - interface `SnapshotEnvelope { available: boolean, error: string }`（各源基类）。
   - `HostSnapshot extends SnapshotEnvelope { cpu_percent, mem_total_mb, mem_used_mb, mem_percent, asyncio_tasks: number|null, threads, background_tasks: Record<string, number> }`。
   - `DbSnapshot extends SnapshotEnvelope { vendor?, connections?: {total,active,idle,idle_in_transaction,waiting?}, max_connections?: number|null, pool?, pgbouncer? }`。
   - `RedisSnapshot extends SnapshotEnvelope { clients?: Record<string, { available, error, connected_clients?, maxclients?, used_memory?, used_memory_human?, keyspace_hits?, keyspace_misses?, hit_rate?: number|null }> }`。
   - `QdrantSnapshot extends SnapshotEnvelope { liveness?: boolean, cached?: boolean, collection_count?: number|null, approx_size?: { sampled_collections, points_count_sampled, truncated }|null }`。
   - `ConcurrencySnapshot extends SnapshotEnvelope { provider_slots?, durable_queues?, runner?, rag? }`（按 snapshot_service SNAP-05 块，宽松 any/Record 兜底）。

   - `MetricsSnapshot { host, db, redis, qdrant, concurrency, counters: QueueCounters, generated_at: string }`。
   - `export async function getMetricsSnapshot(): Promise<MetricsSnapshot>` → `get('/system/metrics/snapshot/')`。
2. **时序查询**（`GET /system/metrics/query/`）：
   - `type MetricName = 'qps' | 'tps' | 'sla' | 'error' | 'duration' | 'ttft' | \`gauge:${string}\``。
   - `type MetricAgg = 'p95' | 'p90' | 'p50' | 'avg' | 'max'`；`type MetricDimension = 'source' | 'provider' | 'call_source' | 'error_class' | 'route' | 'model'`。
   - `interface MetricPoint { bucket: string, dim: string, value: number }`（qps/tps/error/duration/ttft/gauge）。
   - `interface SlaPoint { bucket: string, dim: string, availability: number|null, eligible: number, failures: number, business_rejected: number }`。
   - `interface MetricsQueryResult<T = MetricPoint> { metric: string, agg: string, step_seconds: number, start: string, end: string, vendor: string, degraded: boolean, note: string, series: T[] }`。
   - `interface MetricsQueryParams { metric: MetricName, start?: string, end?: string, step?: string, dimension?: MetricDimension | '', agg?: MetricAgg }`。
   - `export async function queryMetrics(params: MetricsQueryParams): Promise<MetricsQueryResult>`（series 默认 MetricPoint）+ `export async function querySla(params): Promise<MetricsQueryResult<SlaPoint>>`（metric 固定 'sla'，便于 SLA 卡按精确类型消费）。两者均 `get('/system/metrics/query/', {...params})`（client 自动 drop undefined）。
3. **告警规则 CRUD**（`/system/alerts/rules/`）：
   - `interface AlertRule { id: number, name: string, metric: string, op: 'gt'|'gte'|'lt'|'lte', value: number, window: number, dimension: Record<string, string>, severity: 'P0'|'P1'|'P2', enabled: boolean, channels: ('email'|'feishu'|'webhook')[], cooldown: number, title_template: string, created_at: string, updated_at: string }`。
   - `type AlertRuleWrite = Omit<AlertRule, 'id'|'created_at'|'updated_at'>`（patch 用 Partial）。
   - `listAlertRules(params?: { enabled?: boolean }): Promise<{ items: AlertRule[], total: number }>` → `get('/system/alerts/rules/', params)`。
   - `createAlertRule(body: AlertRuleWrite): Promise<AlertRule>` → `post('/system/alerts/rules/', body)`。
   - `getAlertRule(id): Promise<AlertRule>`、`updateAlertRule(id, body: Partial<AlertRuleWrite>): Promise<AlertRule>` → `patch(\`/system/alerts/rules/${id}/\`, body)`、`deleteAlertRule(id): Promise<void>` → `del(\`/system/alerts/rules/${id}/\`)`。
4. **告警事件**（`GET /system/alerts/events/`）：
   - `interface AlertEventRow { id: number, rule: number|null, severity: 'P0'|'P1'|'P2', title_zh: string, rule_info: Record<string, any>, target: Record<string, any>, target_key: string, status: 'firing'|'resolved', started_at: string, ended_at: string|null, duration_s: number|null, current_value: number|null, last_seen_at: string|null, email_sent: string, notified_channels: string[], created_at: string }`。
   - `interface AlertEventQuery { severity?: string, status?: string, rule_id?: number, start?: string, end?: string, limit?: number, offset?: number }`。
   - `listAlertEvents(params?: AlertEventQuery): Promise<{ items: AlertEventRow[], total: number }>`。
5. **系统日志**（`/system/logs/` + `/clear/`）：
   - `interface SystemLogRow { id: number, ts: string|null, level: string, component: string, category: string, event: string, message: string, user_id: string, source: string, trace_id: string, request_id: string, payload: Record<string, any>, correlation: Record<string, any> }`（对齐 SystemLogEntrySerializer）。
   - `interface SystemLogQuery { component?, level?, user_id?, source?, start?, end?, keyword?, limit?, offset? }`（全 string/number 可选）。
   - `interface SystemLogResult { items: SystemLogRow[], total: number, counters: Record<string, number> }`。
   - `querySystemLogs(params?: SystemLogQuery): Promise<SystemLogResult>` → `get('/system/logs/', params)`。
   - `clearSystemLogs(body: SystemLogQuery & { confirm_all?: boolean }): Promise<{ deleted: number }>` → `post('/system/logs/clear/', body)`。
6. **webhook 留痕**（`/system/webhooks/`）：
   - `interface WebhookEventRow { id: number, received_at: string, kind: string, source_ip: string, headers: Record<string, any>, raw_body: any, user_id: string, verified: boolean, correlation: Record<string, any>, created_at: string }`。
   - `listWebhookEvents(params?: { kind?, user_id?, verified?: boolean, start?, end?, limit?, offset? }): Promise<{ items: WebhookEventRow[], total: number }>`、`getWebhookEvent(id): Promise<WebhookEventRow>`。
7. **调用下钻**（`/system/calls/drilldown/` + `/system/conversations/<uuid>/drilldown/`）：
