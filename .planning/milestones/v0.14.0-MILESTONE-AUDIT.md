## 6. Accepted / Deferred（非 gap）

1. **SQLite percentile 降级**：`percentile_cont` 仅 Postgres 可执行，本地 SQLite 走 MAX/AVG 兜底并标 `degraded=true`。这是方案 §A.4 预先声明的设计边界，生产为 Postgres，功能不阻塞。
2. **运行期 UAT（~10 项）**：真实 SMTP 投递、真实指标越线驱动 firing→resolved、PG `pg_stat_activity` 连接分布、真实 Redis INFO 命中率、真实 Qdrant 枚举与缓存命中、浏览器亮暗双主题、375/768/1024/1440 四档响应式、快照内联阈值变色与源降级 n/a、实时速率卡窗口/自动刷新/时间范围联动、日志下钻三类脱敏渲染。以上代码路径均被 mock/transaction 测试覆盖（分支齐全），仅需真机肉眼/真实外部服务终态确认——按里程碑约定属 accepted-deferred，不计 gap。
3. **既有 structlog 跨模块测试污染**：pre-existing，非本里程碑引入；规范命令以 `-p no:randomly` 固定序运行全绿（本次 269 passed）。
