# Milestone v0.2.0: 用户身份令牌与 Agent 工具打通

**Status:** ✅ SHIPPED 2026-06-10
**Phases:** 6-11
**Total Plans:** 21

## Overview

本里程碑给每个用户一套 GitHub/GitLab 风格的个人访问令牌（PAT），并以「用户身份 + 用户权限」贯通整条 agent 工具链路。依赖链严格按序推进：PAT 模型增强（独立先行）→ 令牌即用户身份（单点认证地基，全链路前置）→ 对话/会话用户隔离（依赖可信身份）→ 管理员只读会话后台（依赖隔离语义）→ MCP 绑定用户令牌 + RemoteTool 执行端点（依赖身份）→ task 容器接通（链式依赖最重，放最后）。所有阶段复用既有认证/权限/序列化/加密路径，未重写既有系统；安全约束（明文绝不落盘、fail-closed、脱敏、graceful 吊销）作为一等公民贯穿设计。

## Phase Details

### Phase 6: PAT 模型增强与一次性明文

**Goal**: 用户能创建带名称/备注/可选有效期的个人访问令牌，明文仅展示一次，列表可按前后缀区分并自助吊销
**Depends on**: Nothing（纯模型/序列化/前端增量，无认证语义风险，可独立先行）
**Requirements**: PAT-01, PAT-02, PAT-03, PAT-04, PAT-05, PAT-06
**Plans**: 3 plans

Plans:

- [x] 06-01-PLAN.md — Wave 0 验证脚手架：后端 token_suffix/note/序列化器只读断言 + 前端指纹/never 警告/note payload spec（RED）
- [x] 06-02-PLAN.md — 后端增量：模型加 note + token_suffix 字段 + AddField 迁移 + 序列化器/acreate 透传（plaintext[-4:]）
- [x] 06-03-PLAN.md — 前端增量：DTO + 表单 note 输入/never 非阻塞警告 + 列表备注列/prefix…suffix 指纹

**Details:**
Success Criteria：1) 创建令牌（必填名称、可选备注、可选有效期，不填即永久），创建响应一次性展示明文并可复制；2) 创建「永不过期」令牌看到非阻塞安全风险提示；3) 列表展示名称/备注/创建·最后使用·过期时间 + 明文前缀 + 后 ≤4 位指纹；4) 用户能吊销自己的令牌，界面无延期/续期入口；5) 仅能管理自己的令牌，明文关闭后不可再获取，前后端均不持久化明文。
Constraints：维持无盐 sha256 + 唯一索引（contract 锁定）；后缀严格 ≤4 位避免熵损失；明文绝不进 logger/序列化器 list·detail/前端 store/localStorage/URL。
**UI hint**: yes

### Phase 7: 令牌即用户身份（认证地基）

**Goal**: 携带有效 PAT 的请求以令牌所有者身份 + 其 RBAC 权限被鉴权（替代「有效即全权限」），MCP 入口 fail-closed，PAT 与 JWT 互不干扰，审计链路不断
**Depends on**: Phase 6（需可信 owner 与可识别指纹）
**Requirements**: IDENT-01, IDENT-02, IDENT-03, IDENT-04, IDENT-05
**Plans**: 3 plans

Plans:

- [x] 07-01-PLAN.md — Wave 0 验证脚手架（RED）：owner 断言 + test_pat_identity（前缀闸门/owner 身份/PAT·JWT 共存）+ MCP fail-closed authentication_failed
- [x] 07-02-PLAN.md — 认证地基：authentication.py 返回 (owner, token) + friday_pat_ 闸门 + authenticate_header（保 401）+ settings 认证类 PAT 优先
- [x] 07-03-PLAN.md — MCP 入口 fail-closed：McpToolView 基类收紧 IsAuthenticated + 显式 auth 类（17 子类全继承）

**Details:**
Success Criteria：1) 有效 PAT 请求 request.user = 所有者并施加其 RBAC（不再「有效即全权限」）；2) 无令牌/匿名调用 MCP/工具入口一律被拒（AllowAny→认证，fail-closed）；3) cookie-JWT 与 friday_pat_ 前缀令牌各走对认证分支互不吞掉；4) 已吊销/过期令牌一律被拒；5) 鉴权后审计正常（request.auth 为令牌实例，fingerprint 正确且不含明文）。
Constraints：「改 authenticate 返回值」与「逐入口权限 audit」同阶段交付（Pitfall 1）；authenticate 开头加 friday_pat_ 前缀闸门、非 PAT Bearer 返回 None（Pitfall 2）；认证类纯同步 ORM + select_related("created_by")（Pitfall 6）；保持 request.auth 为 AccessToken 实例（Pitfall 3）。

**Requirements**: ISO-01, ISO-02, ISO-03, ISO-04
**Plans**: 4 plans

Plans:

- [x] 08-01-PLAN.md — Wave 0 RED 验证脚手架：test_conversation_isolation.py 覆盖全 25 路径 cross-user-denied(404) + 回填/admin-no-bypass/open-mode + conftest fixtures
- [x] 08-02-PLAN.md — 数据地基：Conversation.created_by FK + AddField(0018) + RunPython 回填(0019,可逆) + ConversationService owner-scoped 取数
- [x] 08-03-PLAN.md — 直接会话端点 #1-12 owner gate（list/create/detail/delete/patch/preflight/runtime/messages/fork/stream/interrupt/export），SSE 流前 404
- [x] 08-04-PLAN.md — 关联模型端点 #13-25 owner gate（coding-session/plan + trace/clarification via .conversation），去 superuser bypass

**Details:**

Constraints：历史 backfill 是本阶段第一个 plan（Pitfall 4），迁移分两步（加 null=True 列 + 索引 → data migration 回填给最早 superuser），回填前不收紧 null=False；收口 get_owned_conversation_or_404，所有按 id 取会话入口必经它，SSE/WebSocket 纳入同阶段验收（Pitfall 5）。

## Milestone Summary

**Decimal Phases:**

- None — 本里程碑无插入式小数阶段，6→11 全为整数阶段按序执行。

**Key Decisions:**

- 令牌即用户身份：authenticate() 返回 owner，施加用户 RBAC，暂不做读写 scope 细分（GitHub/GitLab PAT 语义，最小改动复用既有 IsAuthenticated/PermissionService）。
- 历史无主会话回填给最早的 superuser（Conversation 无 owner 字段，最早 superuser 最稳妥归属，不丢数据）。
- 默认所有人（含管理员）在 AI 对话只看自己；另设只读「管理员会话管理」后台查看他人会话，交互需 fork 一份（隐私默认隔离 + 运维可见两不误）。
- 用户令牌以直传 PAT 形态注入 task 容器，日志/审计脱敏（优先简单可落地；泄漏面以脱敏 + 后续短 TTL 缓解）。
- skill/mcp 以持久绑定表绑定用户令牌；吊销令牌时在途任务跑完仅阻断新调用（graceful，避免中断回滚复杂度）。
- 依赖链 6→7→8→9→10→11；Phase 7 单点认证地基全链路前置，MCP 入口同阶段收紧 fail-closed；Conversation.created_by 历史回填是 Phase 8 首个 plan；令牌注入与脱敏必须同阶段（Phase 11）交付。

**Issues Resolved:**

- 修复 3 个 code-review BLOCKER：Phase 7 inactive-owner PAT、Phase 8 fork 丢 owner、Phase 8 各阶段 review findings。
- Phase 8 越权统一为对象级 404 / list 一律 []（禁 403，ISO-04 不泄漏存在性）；去除各端点 superuser bypass。
- Phase 11 多项加固：WR-01 守护 resp.json() 200 路径、WR-02 挂载 remote MCP 时保留 builtin 编码工具、WR-03 校验 tools_endpoint scheme/host、WR-04 跳过缺 name 的工具 schema。

**Issues Deferred:**

- 6 个阶段（6-11）VERIFICATION 均为 human_needed（自动化全绿），浏览器/容器级 E2E 人工验收顺延（与 v0.1.0 收尾一致）。
- Nyquist 卫生：各阶段 *-VALIDATION.md frontmatter nyquist_compliant 仍为 false（Wave 0 测试契约已执行并转 GREEN，仅标志位未回填）。

**Technical Debt Incurred:**

- Phase 11 实时明文 PAT 通道（contextvar）未接入：_resolve_user_pat 恒返回 ''，RemoteTool 链路端到端休眠，ToolTokenBinding 暂未被执行路径读取（受 PAT-02 约束的有意 follow-up，Open-Q1 Option C）。
- MCPB-02 集成 PARTIAL：执行端点已按 PAT 认证为 owner，但 execute_tool 未接收 user 上下文、绑定未被执行路径消费（同上 follow-up）。
- v2 跟踪：细粒度 scope（PATX-01）、令牌 rotate/续期（PATX-02）、IP allowlist/限额（PATX-03）、短 TTL 派生凭证替代直传 PAT（PATX-04）。
