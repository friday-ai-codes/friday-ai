<objective>
PR-01：修复多仓 wave 编码收尾时各仓 PR/MR 的 `target_branch` 取值——现状把「第一个仓的 `default_branch`」当全局 `base_branch` 对所有仓共用（病根：`_execute_with_branch` 行 ~317-319 + `_create_mr_for_repo` 行 1708），改为各仓用**各仓自己的** `Repository.default_branch`（每仓独立解析，per D-01/D-02）。

</objective>
