<objective>
抽出统一删除入口 `purge_file(repository_id, rel_path)`（PF-03 + PF-05），作为三条索引删除路径与 Phase 23 排除清理共用的唯一删除点。覆盖：Qdrant 主 collection（复用 `delete_by_file_path`）+ overlay collections（PF-05，遍历 `RepositoryBranchIndex.collection_name` 逐一删 file_path 命中 point）、FileIndex 行、ChunkRegistry/ChunkEdge（ChunkRegistry 删除经既有 `pre_delete` 信号联动清边）、codegraph（复用 `adelete_for_files`，覆盖 base + 各分支）。把 `run_incremental_index` 与 `run_git_diff_index` 的 DELETE 路径改调 `purge_file`，消除"只删 Qdrant 不删 FileIndex/ChunkRegistry"的孤儿残留（PF-03 per D-01）。

Output: `server/services/purge.py`（新增）、`indexer.py` 删除路径收敛、删后四面无残留 + 幂等守护测试。
</objective>
