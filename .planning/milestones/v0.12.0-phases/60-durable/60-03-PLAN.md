<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| 多副本 worker 进程 → Postgres procrastinate 表 | 多 worker 竞争领取同一 job；周期 rescue 跨副本需单例 |
| worker 进程 → 业务 payload 执行 | at-least-once，慢任务可能被误判 stalled 重投 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-60-05 | DoS / 正确性 | 慢任务被误判 stalled 重复执行 | mitigate | get_stalled_jobs 基于 worker heartbeat（非固定 nb_seconds）；at-least-once 显式声明；handler 幂等留 Phase 61 |
| T-60-06 | Elevation / 正确性 | 多副本周期 rescue 重复扫 stalled | mitigate | @app.periodic（DB 每周期单次 defer）+ queueing_lock 单例；test_stalled_rescue 守护 queueing_lock 不堆积 |
| T-60-07 | Tampering | 误用 DjangoConnector 跑 worker（连接不适配长跑） | mitigate | run_worker 用 get_worker_connector()；test 断言返回 PsycopgConnector；docstring/Anti-Pattern 标注 |
| T-60-08 | Information Disclosure | payload 携明文凭证落 procrastinate 表 | mitigate | payload 仅放 id/最小参数（CLAUDE.md：凭证不入 payload/env）；本阶段不接业务任务 |
</threat_model>
