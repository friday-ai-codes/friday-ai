<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| 容器 agent → knowledge handler | agent 生成的工具入参不可信 |
| handler → server /api/mcp/tools/* | 携带 PAT 的出站 HTTP，端点必须可信 |
| server 响应 → agent 上下文 | 上游错误细节/敏感内容不得回显进 agent 可见文本 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-103-05 | Information Disclosure | handler 错误回显 | mitigate | 非 200 只回显 HTTP code 不回显响应体；日志不记 token/入参明文（Task 1 测试钉） |
| T-103-06 | Spoofing/SSRF | endpoint 指向恶意 host 导致 PAT 外泄 | mitigate | `_is_valid_tools_endpoint` 镜像校验（scheme/host），失败不挂 server（Task 1） |
| T-103-07 | Denial of Service | agent 死循环刷知识工具打爆服务端 | mitigate | per-task 配额默认 200 + 用尽返回文案（Task 1）；服务端天然有 McpToolView 指标可告警 |
| T-103-08 | Elevation of Privilege | 排除文件经容器工具越权可见 | mitigate | 服务端 fail-closed 排除继承 + 第七面回归测试（Task 3） |
| T-103-09 | Tampering | allowed_tools 合并错误禁掉编码内建工具 | mitigate | 单一构造函数收口 + WR-02 专项测试（Task 2） |
| T-103-SC | Tampering | 依赖安装 | accept | 零新增第三方依赖（httpx/structlog/claude_agent_sdk 均存量） |
</threat_model>
