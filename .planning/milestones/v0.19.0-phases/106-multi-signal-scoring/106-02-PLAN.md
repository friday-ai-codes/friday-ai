<objective>
把全部权重与常数外置为单个 JSON SystemSetting 键 `repo_router.weight_config`（RESEARCH §5 推荐：单键 + 专用端点校验，`CLAUDE_CODE_CONFIG` 先例），并建立三件套：SettingKeys 常量（weight_config / nr_snapshot / alias_dict 三键一次加齐，后续 plan 只消费不再改 system/models.py）、`repo_router_config.py` loader/校验单点（读走 `get_json_setting` 60s 缓存 + signal 写时失效 = 保存即生效；非法回退 `DEFAULT_WEIGHT_CONFIG` + warning）、`RepoRouterWeightConfigView` 专用 GET/PUT 端点（服务端强校验，通用 settings PUT 不可用于权重——RESEARCH Anti-Pattern）。

校验口径按 CONTEXT 裁决执行：C_crit 不进加性和后权重表为 5 信号、**绝对和无须为 1**（相对权重经重归一化生效）——因此不校验 Σw=1，改为校验（a）每个权重落在离散网格 {0, 0.05, 0.08, 0.10, 0.12, 0.15, 0.20, 0.30, 0.40, 0.55}（防过拟合四道闸之一），（b）文本主导不变量 INV-R2 的相对形式 `fsum(domain, stack, team) <= 0.5 * fsum(全部 5 权重)`，（c）常数范围。此取舍在代码注释与 SUMMARY 记录（CONTEXT ROUTE-06 节的「Σw=1」字面被同文档 ROUTE-04 节的 C_crit 裁决取代）。

Purpose: ROUTE-06 的存取与安全底座；106-04（nr_snapshot 写入）、106-05（前端）、106-06（router 消费）都构建其上。
Output: SettingKeys 三键 + config 模块 + 专用端点 + 测试。
</objective>
