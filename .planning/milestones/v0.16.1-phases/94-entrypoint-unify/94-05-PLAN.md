<objective>
UNIFY-05：消除对话方案生成的「澄清双挂起二义」——`start_plan_research._maybe_suspend` 在
CLARIFYING 时不再复用 chat 单题 `CLARIFICATION_PENDING_MARKER`（="ask_clarification"），改用
**独立的 plan 澄清渲染 marker**（仅作前端渲染信号），并显式携带 `session_id` + `clarification_id`
让前端走 plan 多题卡而非 chat 单题卡。挂起/续推权威**唯一以 `delivery.Clarification` + `PlanSession`
为准**（收答经 91-04 专路由 `POST /conversations/{id}/plan-clarification/answer/` → `aanswer_round_and_resume`），
彻底切断「marker 偷渡进 chat 单题 `_extract_pending_clarification` → 写 `ConversationIntentTrace` →
不续推 PlanSession」的误路由可能。

Purpose: 单一来源收口，消除挂起表示二义（Pitfall 4）。
Output: 独立 plan marker + ToolResult 字段 + 二义消除守护测试。
</objective>
