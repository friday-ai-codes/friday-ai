<objective>
修复地基缺口（Checker BLOCKER）：`/api/node-types/` 实际未向前端暴露端口 `shape`。根因——`NodePort.get_schema()`（server/workflows/nodes/base.py:626-649）已在每个 input/output 项写入 `shape`，但 `NodePortSerializer`（server/workflows/api/serializers.py:831）只声明 `name/label/type/required/description/schema`，DRF 序列化时**静默剥离**未声明的 `shape`。后果：前端 `resolvePortShape` 恒得 undefined → 契约校验 / 磁吸 / 着色全部静默 no-op，SLOT-03 运行时失效；既有 `test_node_schema.py` 只断言 `get_schema()` 原始 dict，绕过序列化器，故掩盖此缺口。

本 plan 在 `NodePortSerializer` 补 `shape` 字段声明，并补一条**端到端集成断言**（走真实 GET /api/node-types/）证明 shape 不再被剥离——这是 Wave 1 地基，下游契约判定链（93-01 → 93-02 → 93-05/06）的前端 shape 消费依赖此 API 暴露才非空。

Purpose: 让前端从权威 SSOT（`/node-types/`）真正读到端口 shape，使 93-01 契约兼容判定/93-05 着色/磁吸不再恒为 no-op。
Output: `NodePortSerializer.shape` 字段 + GET /api/node-types/ 集成断言（含 ai_plan_research.clarify / clarification_card 非空 shape + 通用端口空 shape 零回归）。
</objective>
