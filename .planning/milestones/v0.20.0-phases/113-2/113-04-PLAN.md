① 新建 `task/core/blueprint_context_wait.py`。模块 docstring 编号列约束（照 `question_loop.py:7-15`）：①「短等待原语：容器侧**有界**轮询 `read_blueprint_context`，**不做服务端长轮询**——公共 handler 工厂的 `timeout=60.0` 写死且共享于 10 个工具，改它波及全部」；②「**超时返回正常结果而非 `is_error`**：`is_error` 会诱导 agent 重试而非降级（记假设 + 开澄清线程）」；③「**不发心跳**：knowledge handler 工厂不持有 `callback`，加参数会波及全部既有工具；轮询自身每 5s 一次 HTTP 出站即活动性」；④「向后兼容：read handler 为 None（endpoint/token 缺失）时直接返回未命中，绝不崩」；⑤「脱敏：命中条目正文绝不进容器侧日志，只记 `hit` / `polls` / `waited_ms`」。

模块常量：`DEFAULT_TIMEOUT_MINUTES = 3`、`MAX_TIMEOUT_MINUTES = 5`（硬上界，超过应走长等待退出重派）、`DEFAULT_POLL_INTERVAL_S = 5.0`（不用 `ask_user` 的 3.0——这里是 HTTP + DB）。

```
async def await_blueprint_context(
    read_handler,                       # 复用 _make_knowledge_handler("read_blueprint_context", ...) 造出的 handler
    key_pattern: str,
    *,
    kind: str = "",
    since_seq: int = 0,
    timeout_minutes: int = DEFAULT_TIMEOUT_MINUTES,
    poll_interval_s: float = DEFAULT_POLL_INTERVAL_S,
    _now: Callable[[], float] | None = None,
    _sleep: Callable[[float], Awaitable[None]] | None = None,
) -> dict
```
实现（骨架照 `question_loop.py:97-121`，逐项落差异）：
1. `read_handler is None` → 立即 `{"hit": False, "reason": "tool_unavailable", "waited_ms": 0, "polls": 0, "max_seq": since_seq}`。
2. `timeout_minutes = min(max(0, timeout_minutes), MAX_TIMEOUT_MINUTES)`；`deadline = now() + timeout_minutes * 60`；`last_seq = since_seq`；`polls = 0`。
3. `while now() < deadline:` → `polls += 1` → `raw = await read_handler({"key_prefix": <key_pattern 的字面前缀部分>, "kind": kind, "since_seq": last_seq, "limit": 200})` → 解析 handler 返回体（`{"content": [{"type":"text","text": json_str}]}`，**沿用工厂的返回形状**；`is_error` 为真 → 视为本轮未命中并继续，不中断等待）→ `entries = body.get("entries") or []`；`last_seq = max(last_seq, body.get("max_seq") or last_seq)`（**增量幂等，避免重复拉全量**）→ 逐条用 `matches_key_pattern(entry["key"], key_pattern)`（本模块的极简纯函数：精确 / `*` 尾通配 / 前缀）判定 → 命中即 `return {"hit": True, "entry": entry, "waited_ms": …, "polls": polls, "max_seq": last_seq}` 并**停止轮询** → 未命中 `await sleep(poll_interval_s)`。**不发心跳**。
4. 超时 → `return {"hit": False, "reason": "timeout", "waited_ms": …, "polls": polls, "max_seq": last_seq}`（**正常结果，不是 `is_error`**）。
5. 日志只 `log.info("blueprint_context_await_finished", hit=…, polls=…, waited_ms=…)`——**不记 key_pattern 之外的任何正文**。
