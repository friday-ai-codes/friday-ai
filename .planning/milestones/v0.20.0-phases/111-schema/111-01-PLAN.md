- `$defs.citation`：required `["citation_id", "source_type"]`；`source_type` enum `["knowledge_entity", "rag_chunk", "repo_file", "artifact_version", "blueprint", "repo_charter", "work_item", "feishu_doc", "url"]`。

顶层 required（CONTEXT 锁定：六段 + meta + requirement_spec + must_haves + citations 池）：`["schema_version", "meta", "requirement_spec", "repo_associations", "current_state_analysis", "implementation_overview", "api_contracts", "impact_analysis", "interaction_flows", "must_haves", "citations"]`；`decision_log`/`deferred_ideas`/`execution_plan` 可选（execution_plan 是 confirmed 后的派生段）。各段结构按 DESIGN §3.4–§3.12：
- `meta`：required `["title", "project_id"]`；summary 为 block_list。
- `requirement_spec`：required `["goal", "feature_points"]`；feature_points item required `["id", "title"]`。

- `current_state_analysis`：array；item required `["repository_id", "findings"]`；findings item required `["id", "text", "kind", "citations"]`（§3.7 citations 必填）；`kind` enum `["capability", "gap", "risk", "convention"]`。
- `implementation_overview`：required `["requirement_narrative", "items"]`；items item required `["id", "feature_point_id", "repository_id", "change_type", "title"]`；`change_type` enum `["create", "modify", "remove", "indirect_refine"]`；`files_touched` item required `["path", "action"]`，`action` enum `["create", "modify", "remove"]`（注意：蓝图侧是 remove，technical_plan 侧是 delete——映射在派生器做，见 Task 2）；`wave` integer minimum 1；`depends_on` array of string。

- `impact_analysis`：required `["business_impact", "affected_features"]`；affected_features item required `["feature", "kind"]`，`kind` enum `["behavior_change", "perf", "compat", "data", "none"]`；`regression_scope` item `level` enum `["full", "smoke", "none"]`。
- `interaction_flows`：array；item required `["id", "name", "steps"]`；steps item required `["seq", "actor", "action"]`。
- `must_haves`：required `["truths", "artifacts", "key_links"]`。
- `citations`：type object，additionalProperties `$ref: #/$defs/citation`。
