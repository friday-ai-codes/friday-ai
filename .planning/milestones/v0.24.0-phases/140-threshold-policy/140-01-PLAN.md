| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-140-01 | Tampering | run identity/case set | mitigate | canonical case-set/evaluator hash、严格身份字段与 INVALID fail-closed |

| T-140-SC | Tampering | package supply chain | accept | 本计划不新增依赖，不触发 package install |
