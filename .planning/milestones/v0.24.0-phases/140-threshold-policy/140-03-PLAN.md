<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user query → service/logging | 自然语言和潜在凭证进入 graph query，日志必须只保留非敏感元数据 |
| background task → process index | contextvars 不跨线程/任务自动传播，必须显式 re-bind 触发用户 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-140-09 | Information Disclosure | query/retrieval logs | mitigate | sentinel 行为测试 + AST 禁 query kwargs/slices + 异常脱敏 |
| T-140-10 | Repudiation | graph query caller | mitigate | 唯一 caller 三事件、用户与 request/trace/source 关联键 |
| T-140-11 | Denial of Service | high-frequency logging | mitigate | sampling/debug 汇总、循环内 INFO 静态禁令 |
| T-140-12 | Spoofing | background initiated user | mitigate | initiated_by_user_id 显式参数、system fallback、bind_task_context |
| T-140-13 | Denial of Service | observability failure | mitigate | 每个日志/指标调用独立 best-effort，业务语义回归测试 |
| T-140-SC | Tampering | package supply chain | accept | 不新增依赖 |
</threat_model>
