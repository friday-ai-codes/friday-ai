| Boundary | Description |
|----------|-------------|
| 实时请求线程 PAT 明文 → dispatch metadata | 唯一合法明文来源；仅在请求线程内可得，绝不从 DB 取 |
| settings.FRIDAY_BASE_URL → 容器工具端点 | 端点 base 来源；错用 callback_url 会打到 runner 中转 |
| server 日志/审计 ↔ 运维可见 | PAT 明文绝不进 log；审计走 redact_for_ledger |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-11-11 | Information Disclosure | 从 AccessToken/DB 取 PAT 明文（违反 PAT-02） | mitigate | 仅透传实时请求线程明文；零 DB 明文读取（test_dispatch_never_reads_access_token_plaintext 守卫） |
| T-11-12 | Information Disclosure | PAT 明文进 server 日志 | mitigate | log 只记 has_user_token bool / source；明文不入 log/审计 input |
