# Requirements: Friday AI

**Defined:** 2026-06-23
**Core Value:** 让团队"开箱即用、安全地"把需求自动变成代码——能稳定地批量索引大量仓库、能并行而不打爆资源地跑 AI 对话/编码，且过程实时可见、凭证管理清晰。

## v1 Requirements

Milestone v0.13.0 并发治理与索引体验。每条映射到一个 roadmap 阶段。

### AI 对话串流隔离（STREAM）

- [x] **STREAM-01**: 用户在某会话流式输出进行中切换到另一会话时，正在进行的回答不会串入当前会话 UI；流式状态与副作用按 `conversation_id` 隔离，后台流可继续但仅写回其所属会话（数据由后端 finalize 落库）

### 索引后端精简（LSP）

- [x] **LSP-01**: 代码索引/图谱构建默认仅用 tree-sitter（Volar/gopls LSP 默认关闭、可经环境开关恢复），向量抽取路径在 LSP 关闭时正确回落 `TreeSitterBackend` 不报错

### 并发治理（CONC）

- [x] **CONC-01**: 仓库索引/图谱并发受可配置上限约束（系统设置，默认索引 5、图谱 3），超出的任务在 durable 队列原生排队等待被消费（不打爆 CPU/内存），同一仓库串行、不重复索引
- [x] **CONC-02**: 每个 LLM provider 凭证可单独配置最大并发（`ProviderCredential.max_concurrency`）；chat/深度分析/编码的 LLM 调用按凭证限流，超限时排队等待、超时给友好"系统繁忙"提示，而非打到 provider 触发 429/异常
- [x] **CONC-03**: 深度分析/编码的容器并发受 runner 并发上限（`runner.concurrent`）约束并暴露/文档化；MCP 工具调用为本地调用、不限并发

### 实时进度（PROG）

- [x] **PROG-01**: 索引进度条单调不回退（消除"文件级 90%/100% → chunk 级 0%"跳变与重触发残留），向量索引阶段实时展示百分比与阶段文案
- [x] **PROG-02**: 图谱构建展示实时进度（百分比 + 当前文件）；AI 描述生成在前端展示"排队中/生成中"状态

### 批量索引（BATCH）

- [x] **BATCH-01**: 超级管理员可在仓库列表页一键"全部更新索引"，批量入队并受 CONC-01 并发上限排队消费
- [x] **BATCH-02**: 提供批量建仓能力（接受数组的批量接口或明确可复用现有 create 接口循环），支持经 CSV 批量导入数百个仓库后受限并发索引

### 凭证重构（TOKEN）

- [x] **TOKEN-01**: 仓库 access token 改为可选；仓库可显式选择一个"密钥提供方"（`GitInstanceCredential` FK）或填写自有 token；解析优先级 per-repo token → FK 实例凭证 → host 自动匹配 → 无，老仓库行为不回退，`has_credential` 反映实例池可解析
- [x] **TOKEN-02**: 建仓表单按 provider 拼接 URL（前缀 `https://{host}` 只读 + 中间 group/repo 输入框 + 固定 `.git`），输入失焦后自动校验仓库存在性/权限（无 token 时按 FK/host fallback 实例池）

## v2 Requirements

Deferred to future milestones.

### 并发进阶（CONCX）

- **CONCX-01**: 容器内（编码/深度分析）LLM 调用接入同一 Redis provider 限流器（跨 server 与容器统一计数）
- **CONCX-02**: LLM 限流器自适应——根据 provider 实际 429 反馈动态收敛并发

### 图谱性能（GRAPHX）

- **GRAPHX-01**: 常驻热 LSP 池 + 图谱构建与索引主路径解耦异步化（重新开启 LSP 后仍快）

## Out of Scope

| Feature | Reason |
|---------|--------|
| 全局"所有任务总并发"硬上限 | 第一性原理：真正稀缺的是服务器资源与各 provider 配额；分类上限 + 资源级限流已覆盖，全局总数是错误抽象且与 KEDA 伸缩冲突 |
| chat 超并发硬 429 | 选"排队等待 + 超时友好提示"，避免粗暴拒答；provider 限流在凭证级处理 |
| DB 计数准入 + 延迟重投做并发上限 | 与 KEDA 按 `todo` 深度伸缩形成扩容空转反馈环；改用 Procrastinate 原生 `lock` 槽位池 |
| 永久禁用 LSP / 删除 LSP 代码 | 仅默认关闭（可开关恢复），调好后重新开启；GRAPHX-01 留 v2 |
