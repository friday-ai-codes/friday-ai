  <action>
    新建 `server/knowledge/api/artifact_overview.py`：定义 `ArtifactOverviewView(APIView)`（adrf，`permission_classes=[IsAuthenticated]`，`@extend_schema(tags=["knowledge"])`，async `get`）。逻辑（全部 async ORM 经 `sync_to_async`）：
    - `allowed = await resolve_allowed_project_ids(request.user)`（可见 Space id）；空 → 返回空结构 `{total:0, types:[], items:[], truncated:false}`（fail-closed，零 DB 越权）。
    - 计数：`Artifact.objects.filter(project__space_id__in=allowed).values("type__key","type__name","type__carrier","type__ragable").annotate(count=Count("id")).order_by("-count")` → `types` 列表（字段 type_key/type_name/carrier/ragable/count）。
    - `total = sum(count)`。
    - 条目列表（供前端即时搜索）：`Artifact.objects.filter(project__space_id__in=allowed).select_related("type","project").order_by("-updated_at")[:LIMIT]`（`LIMIT` 常量如 500，模块级定义，注释「跨项目聚合截断保护，沿用 max_nodes 思路」）；每项序列化 `{artifact_id,title,type_key,type_name,carrier,url,project_id,project_name,updated_at}`。
    - `truncated = total > LIMIT`。
    - 支持可选 `?type_key=` query 预筛（前端「点某类型进入」用）——收窄计数与列表；非法值 fail-soft 忽略。
    - 观测：`artifact_overview_started` / `artifact_overview_completed`（kv：user 可见 space 数、type 组数、item 数、`duration_ms`、component="knowledge"、category="caller"）；聚合异常 best-effort 捕获返回空结构 + `artifact_overview_failed` warning，绝不 500 反噬（观测/聚合永不反噬）。
    - 复用既有 `_parse_int_param` 模式（如支持可选 `?limit=` 收窄，clamp 到 [1, LIMIT]）。序列化保持 JSON 原生类型（uuid/datetime 转 str）。
  </action>
