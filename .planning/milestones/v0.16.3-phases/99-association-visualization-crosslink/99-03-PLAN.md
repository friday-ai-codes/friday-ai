<objective>
KDEP-11 前端：在知识实体详情页展示 Phase 98 建立的关联并双向可导航。当实体是工件（`source_kind==='artifact'` 的 document）时展示其关联的仓库 / 能力(node_paths) / 关键词；当实体是仓库（`kind==='repository'`）时反向展示相关交付文档，可点击跳该文档的知识实体，形成闭环。

Purpose: 让 Phase 98 的关联「看得见、点得动」，是关联可视化的知识图谱侧出口。read-only 只读展示，复用 Phase 98 查询端点（工件正向端点已存在，仓库反查端点由 99-02 提供）、复用 Phase 96 类型徽标 + Phase 97 载体图标 + 既有实体详情关联区块样式，空态优雅、最小新增。

Output: knowledge.ts 新增两个查询函数 + 类型；新增 `EntityAssociationsCard.vue`；实体详情页条件挂载该卡 + 导航锚点；zh-CN 文案。
</objective>
