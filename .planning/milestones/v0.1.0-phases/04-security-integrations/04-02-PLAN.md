# Plan 04-02 — 前端：向导安全校验 + 可选集成步骤

## Goal
在 `/setup` 多步向导外壳追加步骤 3「安全校验」（只读风险提示，非阻塞）、步骤 4「飞书集成」（可跳过）、
步骤 5「向量检索」（可跳过，末步进首页）。复用 `~/components/ui/*` + vee-validate/zod + vue-i18n（zh-CN）。
**不改** Phase 1 守卫 / Phase 2 自动登录 / Phase 3 provider 组件契约。

## Tasks

1. **`web/src/api/setup.ts`**（改动）新增类型 + 函数（走既有 `get`/`post`，此时已 superuser）：
   - `interface SecurityCheck { secure; secret_key_secure; encryption_key_set; keys_independent; risks: {code:string; level:string}[] }`
   - `getSecurityCheck(): Promise<SecurityCheck>` → `get('/system/security-check/')`
   - `interface SetupFeishuRequest { app_id; app_secret }`；`setupFeishu(data): Promise<{feishu_configured:boolean}>` → `post('/system/setup-feishu/', data)`
   - `interface SetupRagRequest { qdrant_url; qdrant_api_key?; embedding_api_url?; embedding_api_key?; embedding_model?; embedding_dimension?: number|null }`；`setupRag(data): Promise<{rag_configured:boolean}>` → `post('/system/setup-rag/', data)`
   - 加入 `default` 导出。

2. **`web/src/components/setup/SetupSecurityStep.vue`**（新建）
   - `defineEmits<{ continue: [] }>()`；onMounted 调 `getSecurityCheck()`，`loading` / `result` / `failed` 三态。
   - 全通过 → primary `shield-check` + `setup.security.allClear`；有风险 → amber 块 `riskTitle` + 逐条 `setup.security.risk.{code 驼峰映射}`；端点失败 → 中性 `unavailable`。
   - 始终渲染 `继续`(`setup.security.cta`) 主按钮 → `emit('continue')`，**任何态都不 disable**（非阻塞）。
   - code→i18n 映射：`secret_key_default→risk.secretKeyDefault`、`encryption_key_unset→risk.encryptionKeyUnset`、`keys_not_independent→risk.keysNotIndependent`。

3. **`web/src/components/setup/SetupFeishuStep.vue`**（新建）
   - `defineEmits<{ done: []; skip: [] }>()`；zod 表单 `appId`/`appSecret` 非空校验。
   - 提交 `setupFeishu({app_id, app_secret})` 成功 `emit('done')`；失败顶部 destructive 显示后端 `detail`。
   - `跳过`(`setup.feishu.skip`) 次级按钮 → `emit('skip')`（不调用端点）。App Secret 用 `type="password"`。

4. **`web/src/components/setup/SetupRagStep.vue`**（新建）
   - `defineEmits<{ done: []; skip: [] }>()`；zod 表单 `qdrantUrl` 必填 + 可选 `qdrantApiKey/embeddingApiUrl/embeddingApiKey/embeddingModel/embeddingDimension`。
   - 提交 `setupRag({...})`（空字段省略；dimension 转 number）成功 `emit('done')`；失败 destructive 显示 `detail`。
   - `跳过并进入系统`(`setup.rag.skip`) → `emit('skip')`。Key 字段 `type="password"`。

5. **`web/src/pages/setup.vue`**（改动，步骤机扩展）
   - `step` 类型扩为 `'admin' | 'provider' | 'security' | 'feishu' | 'rag'`。
   - 管理员提交成功 → `step='provider'`（不变）。
   - `<SetupProviderStep @done="step='security'" @skip="step='security'">`（原 `router.push('/')` 改为推进 security）。
   - `<SetupSecurityStep v-if="step==='security'" @continue="step='feishu'">`
   - `<SetupFeishuStep v-if="step==='feishu'" @done="step='rag'" @skip="step='rag'">`
   - `<SetupRagStep v-if="step==='rag'" @done="router.push('/')" @skip="router.push('/')">`
   - 步骤指示：用 `STEPS=['admin','provider','security','feishu','rag']` 渲染圆点（当前 primary，已过 muted-filled）+ `setup.steps.indicator` 文字（current=index+1, total=5）。卡片宽度 security/feishu/rag 复用 `max-w-lg`。

6. **`web/src/locales/zh-CN.json`**（改动）`setup.*` 追加：
   - `steps.security/feishu/rag`
   - `security.{title,subtitle,allClear,checking,unavailable,riskTitle,cta,risk:{secretKeyDefault,encryptionKeyUnset,keysNotIndependent}}`
   - `feishu.{title,subtitle,fields:{appId,appSecret,appIdPlaceholder,appSecretPlaceholder},validation:{appIdRequired,appSecretRequired},cta,saving,skip,error:{default}}`
   - `rag.{title,subtitle,fields:{qdrantUrl,qdrantApiKey,embeddingApiUrl,embeddingApiKey,embeddingModel,embeddingDimension,qdrantUrlPlaceholder},validation:{qdrantUrlRequired},cta,saving,skip,error:{default}}`
   - `finish.success`
   - 文案取值见 04-UI-SPEC.md Copywriting 表。

7. **测试**（vitest + @vue/test-utils）
   - `web/src/api/__tests__/setup.spec.ts`（扩展）：`getSecurityCheck` GET 路径、`setupFeishu`/`setupRag` POST 路径与 body。
   - `web/src/components/setup/__tests__/SetupSecurityStep.spec.ts`（新建）：mock `getSecurityCheck` 返回 secure → 显示 allClear + 继续可点；返回带 risks → 渲染风险项且继续仍可点（非阻塞）；reject → unavailable 且继续可点。
   - `web/src/components/setup/__tests__/SetupFeishuStep.spec.ts`（新建）：填表提交调用 `setupFeishu` 并 emit done；点击跳过 emit skip 且不调用端点；后端错误展示。
   - `web/src/components/setup/__tests__/SetupRagStep.spec.ts`（新建）：填 qdrantUrl 提交调用 `setupRag` emit done；跳过 emit skip。

## Verification
- `cd web && pnpm vitest run src/api/__tests__/setup.spec.ts src/components/setup/__tests__` 全绿。
- `pnpm exec eslint src/components/setup src/api/setup.ts src/pages/setup.vue --fix` 干净；`pnpm exec vue-tsc --noEmit`（或项目既有类型检查）无新增错误。
- i18n JSON 合法（无重复键 / 结构正确）。

## Risks
- vee-validate/zod 与 i18n `t()` 在 `<script setup>` 顶层调用：沿用 `SetupProviderStep.vue` 的 `toTypedSchema(z.object({...}))` 写法。
- 圆点指示重构需保证不破坏既有 admin/provider 两步视觉；用数组驱动，当前步高亮。
- 安全步骤"继续"按钮在 loading 期间可置 loading 文案，但**不得 disable 到无法继续**（非阻塞契约）；失败态必须可继续。
