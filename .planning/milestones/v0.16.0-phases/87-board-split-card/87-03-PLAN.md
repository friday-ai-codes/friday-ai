交付 BOARD-01 收口：把 87-02 的拆分提案落成真实子看板。新增 `BoardSplitService`（编排：抽取 → 逐 feature 建 work_item + 关联项目跟踪 + 落 ProjectWorkItemLink + 父子降级），并以**两个入口**暴露——工作流节点（`BaseNode` 自动注册）+ AI 会话工具（`@tool`），二者共用同一服务（单一编排收口）。

Purpose: 让"feature list → 子看板"既能在工作流编排里跑，也能被 AI 对话直接调用，且写入收口、可降级、逐条 fail-soft。
Output: `BoardSplitService` + `BoardSplitNode` + `split_feature_list_to_boards` 工具 + 服务/节点测试。
