## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| IDE stop hook（半可信）→ report_project_state 直写 | PAT 认证用户经 hook 直写结构化 STATE，须成员校验 + 审计 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-86-04-01 | Elevation of Privilege | 非成员写 STATE | mitigate | 成员校验 fail-closed → 非成员静默跳过不写（绝不抛、不阻断编码） |
| T-86-04-02 | Tampering | 重复/伪造条目污染清单 | mitigate | (project,method,path) 唯一约束幂等 upsert；每次写入经 ProjectDocService(INV-6) + 审计可回滚（remove） |
| T-86-04-03 | Information Disclosure | params(JSON) 留审计 | mitigate | AuditService `_redact_audit_payload` 入口强制脱敏；params 不应含凭证（资产文档告诫） |
| T-86-04-04 | Denial of Service | 批量回写部分失败反噬 | mitigate | 逐条 try/except，单条失败不影响其余；全路径 fail-soft 200 不阻断编码 |
