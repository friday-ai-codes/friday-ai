| T-85-02-02 | Information Disclosure | RetrievalTrace 留痕 | mitigate | `_record` → `arecord_retrieval_trace` 内置 `redact_for_ledger`；trace payload 只记 id/计数/score，不存正文 |
| T-85-02-03 | Repudiation | McpToolView | mitigate | `_begin` 绑触发用户 + RequestMetric(call_source=tool_name) + ToolCallRecord |
| T-85-02-04 | Spoofing | read_project_doc 存在性探测 | mitigate | doc 不存在与无权读对外同形（空文档），不泄漏存在性 |
