## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| feature list 正文 → 选仓 query / 日志 | 半可信文本，可能含密钥/超大体积 |

| 候选范围 → RepoRouterV2 | 不限范围会跨项目泄漏/噪声 |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-88-02-INFO | Information Disclosure | 选仓日志/RetrievalTrace | mitigate | payload 入库经 redact_for_ledger（ledger 内部）；日志仅记 query 长度/候选数，不回显 feature 正文 |
| T-88-02-SCOPE | Information Disclosure | 候选范围未限定 | mitigate | _resolve_repository_ids 限定 Space.repositories（Pitfall 6），不全库检索 |
| T-88-02-TAMPER | Tampering | 旁路写 RepoAssociation | mitigate | _persist_candidates 唯一写入口 + INV-6 grep 守护 |
| T-88-02-ATTR | Repudiation | 选仓归因 | mitigate | initiated_by_user_id 透传缺记 system；route 带 aux_repo_router call_source |
| T-88-02-DOS | Denial of Service | 超大 feature list 塞爆 query | mitigate | _build_query 截断 token 预算 |
</threat_model>
