<interfaces>
mergeCursorHooksConfig(existing, fridayEntries) → 新对象。existing 非对象则视为空。输出 version 恒为 1；保留 existing 其余顶级键；hooks 为按事件名合并的数组。fridayEntries 形如 { beforeSubmitPrompt: { command, timeout }, afterAgentResponse: { command, timeout } }。稳定 id 为 command 的 basename。同 basename 替换 command/timeout，不重复 append。不设置 failClosed。不主动删除 stop 事件。

writeMergedCursorHooksFile(targetPath, fridayEntries)：读文件；JSON.parse 失败则原样保留并返回 { ok: false, warning }（中文可操作说明：文件非法 JSON 未修改，请手工修复后再装）；成功则同目录临时文件写入后 rename。

installCursorHooks(packageRoot, { project })：复制 skills/hooks/cursor/before-submit-prompt 与 after-agent-response 到项目 .cursor/hooks/friday-before-submit-prompt.sh 与 friday-after-agent-response.sh，或全局 ~/.cursor/hooks/ 下同名；chmod +x。project true 时 command 为 .cursor/hooks/friday-before-submit-prompt.sh 等；global 为 ./hooks/friday-before-submit-prompt.sh。timeout 15。不要用 cursorRuleBootstrap 的「文件存在即跳过」策略对待 hooks.json。

performInstall 在 agent.id === cursor 时调用 installCursorHooks（与 bootstrap 开关无关，装 skills 即 merge hooks）。
</interfaces>
