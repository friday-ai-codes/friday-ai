<objective>
KDEP-08：把已确认的仓库关联（`RepoAssociation.status == verified`）单向派生为知识图谱中的 project→repo 边（`RELATES_TO`，metadata 标 source=repo_association），`RepoAssociation` 仍是唯一真相源、图谱边随状态流转派生/失效，不新建重复真相表。

</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| 真相源 vs 派生图层 | `RepoAssociation`（操作态）是唯一真相源；KnowledgeEdge 单向派生，禁止反向写回或新建重复真相表 |
| 验证状态机 | RepoAssociation 状态流转是核心业务流程，图谱同步为附加旁路，绝不可反噬 |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-98-05 | Tampering | 派生边一致性（真相源单向派生） | mitigate | `sync_repo_association_edge` 仅治理 `metadata.source=="repo_association" and association_id` 的边；verified→建/覆盖、离开→失效置位；按 association_id 幂等，经 `graph_store` + `uniq_kedge_active` 收口，不新建真相表 |
| T-98-06 | Denial of Service | RepoAssociation 状态机 / 验证流程 | mitigate | 图谱同步经 `_sync_association_edge` best-effort try/except，异常吞掉记 debug，绝不反噬状态流转与逐仓深验流程 |
