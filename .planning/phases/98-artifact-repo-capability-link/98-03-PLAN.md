## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client → 关联查询 API | 未受信 artifact_id / 查询参数跨界进入图谱遍历与工件补全 |
| 跨项目图谱遍历 | 遍历可能触达他项目工件/仓库节点，须按用户可见范围过滤 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-98-03-01 | Information Disclosure | 跨项目工件/仓库越权可见 | mitigate | 正向查询先校验工件 `space_id ∈ resolve_allowed_project_ids`（不可见 404）；反向查询经 `resolve_allowed_repository_ids` + 工件 `project__space_id` 二次过滤（fail-closed，无可见范围返回空） |
| T-98-03-02 | Denial of Service | 无锚点关键词/能力反查全量扫描 | mitigate | 无仓库锚的反查限定在 user 可见仓库集合内逐仓 in-edges（有界）；遍历经 graph_store.neighbors（内置有效性过滤，单跳邻居非无界 traverse） |
| T-98-03-03 | Tampering | 绕过 graph_store 裸写遍历 SQL | mitigate | 查询一律经 `graph_store.neighbors` 收口，本 plan 不写任何 `WITH RECURSIVE`/裸 edge 表 SQL（graph_store 收口纪律，test_graph_store grep 守护） |
| T-98-03-04 | Denial of Service | 查询/补全异常反噬请求 | mitigate | 服务层查询 try/except 返回空结构 + failed 观测；端点不 500，best-effort |
| T-98-03-SC | Tampering | npm/pip/cargo installs | mitigate | 本 plan 不安装任何新包（纯仓内新增 service + adrf 端点），无供应链面 |
</threat_model>
