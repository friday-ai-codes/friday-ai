# Plan 03-02 — 前端：供应商配置步骤

## Goal
将 `/setup` 升级为两步向导，新增供应商配置步骤：5 个一键预设（自动填充 base_url+model、展示能力）、
仅填 API Key、提交触发后端 `setup-wizard` 编排（健康校验 + 落库 + 设默认 + 绑 Claude Code），成功进首页。

## Tasks

1. **`web/src/lib/providerPresets.ts`** — 新增预设常量
   - `export interface ProviderPreset { id; label; baseUrl; model; contextLength; supportsVision; description; custom? }`
   - 5 项：
     - `deepseek` DeepSeek V4 Pro → `https://api.deepseek.com/anthropic`, `deepseek-chat`, 128000, vision false
     - `mimo` MiMo V2.5 Pro → `https://api.mimo.ai/anthropic`, `mimo-v2.5-pro`, 256000, vision true
     - `kimi` Kimi 2.6 → `https://api.moonshot.cn/anthropic`, `kimi-k2.6`, 256000, vision true
     - `anthropic` Anthropic 官方 → `https://api.anthropic.com`, `claude-sonnet-4-5`, 200000, vision true
     - `custom` 自定义兼容端点 → baseUrl/model 空、custom:true
   - `export const PROVIDER_PRESETS: ProviderPreset[]`。

2. **`web/src/api/setup.ts`** — 新增 `setupProvider`
   - `interface SetupProviderRequest { api_key; base_url; model; name?; context_length?; supports_vision? }`
   - `interface SetupProviderResponse { id; default_model; is_default; claude_code_bound; health? }`
   - `export async function setupProvider(data): Promise<SetupProviderResponse> { return post('/providers/setup-wizard/', data) }`
   - default export 补 `setupProvider`。

3. **`web/src/components/setup/SetupProviderStep.vue`** — 新增组件
   - props: 无；emits: `done`、`skip`。
   - vee-validate + zod：`apiKey`(min1)、`baseUrl`(min1)、`model`(min1)；初始值取默认选中预设。
   - 预设选择（原生 button 卡片网格）：选中高亮，点击填充 baseUrl/model（custom 清空）；能力 badge（上下文 `t('setup.provider.caps.context',{n})` + vision/textOnly）。
   - base_url/model 输入（预设已填，可编辑）；API Key 输入（`type=password`）。
   - 提交：`isSubmitting` + 调 `setupProvider({api_key, base_url, model, context_length, supports_vision})`；成功 emit `done`；失败把后端 `detail` 展示在顶部 destructive 错误条。
   - 次级动作「稍后在设置中配置」→ emit `skip`。
   - 全文案走 `t('setup.provider.*')` / `t('setup.steps.*')`。

4. **`web/src/pages/setup.vue`** — 两步化
   - 新增 `const step = ref<'admin'|'provider'>('admin')`。
   - 步骤指示（顶部，`t('setup.steps.indicator',{current,total})` + admin/provider 标签高亮）。
   - 管理员表单提交成功后：`authStore.applySetupSession` + `fetchMe` 后**不再** `router.push('/')`，改为 `step.value = 'provider'`。
   - 渲染 `<SetupProviderStep @done="router.push('/')" @skip="router.push('/')" />`（step==='provider' 时）。
   - 卡片宽度在 provider 步骤可放宽到 `max-w-lg`。

5. **`web/src/locales/zh-CN.json`** — 新增 `setup.steps.*` + `setup.provider.*`（见 UI-SPEC 文案表）。

6. **测试**
   - `web/src/api/__tests__/setup.spec.ts`：扩展 `setupProvider` 调用路径/参数断言。
   - `web/src/lib/__tests__/providerPresets.spec.ts`：断言 5 预设存在、anthropic 兼容字段齐全、custom 为空。
   - `web/src/components/setup/__tests__/SetupProviderStep.spec.ts`：mount（mock `~/api/setup`、stub i18n `$t`）；断言预设选中填充、提交调用 `setupProvider`、成功 emit `done`、失败展示错误。
