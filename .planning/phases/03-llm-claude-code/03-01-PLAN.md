# Plan 03-01 — 后端：供应商配置向导编排端点

## Goal
新增 `POST /api/providers/setup-wizard/`（`IsSuperUser`），对既有 service 层做幂等编排：
Pydantic 校验 → 落库前健康校验（连通/鉴权）→ Fernet 加密 upsert 系统级 anthropic `ProviderCredential`
→ 设 `is_default` → 绑定 `claude_code_config`。失败给可操作中文提示。**不新建存储、不绕过加密。**

## Tasks

1. **`server/services/provider_health.py`** — 新增无状态健康校验
   - `async def health_check_config(provider_type: str, cfg: dict[str, Any], model: str | None = None) -> HealthCheckResult`
   - 构造未保存 `ProviderCredential(provider_type=provider_type, default_model=model or "")` stub（不 save）。
   - 解析 `ProviderType`；取 `_PING_DISPATCH.get(pt)`；用 `httpx.AsyncClient(timeout=HEALTH_CHECK_TIMEOUT_SECONDS)` 调 `ping_fn(client, stub, cfg, model)`。
   - 复用既有 `try/except`（TimeoutException/ConnectError/Exception）降级 + `_safe_error` 脱敏，**不调用 `aupdate`**。
   - 未知 provider_type / 无 dispatch → `HealthCheckResult(ok=False, ...)`。

2. **`server/system/serializers.py`** — 新增 `ProviderSetupWizardSerializer(serializers.Serializer)`
   - 字段：`api_key`(CharField, required, write_only, trim_whitespace=False)、`base_url`(CharField, required)、`model`(CharField, required)、`name`(CharField, default="default")、`context_length`(IntegerField, required=False, allow_null=True)、`supports_vision`(BooleanField, required=False, default=False)。
   - `validate_base_url`/`validate_model`：strip 后非空。

3. **`server/system/views.py`** — 新增 `ProviderSetupWizardView(APIView)`
   - `permission_classes = [IsSuperUser]`（从 `permissions.api_permissions` 导入，已在用）。
   - `async def post(self, request)`：
     1. `ProviderSetupWizardSerializer(data=request.data)` → `await sync_to_async(serializer.is_valid)(raise_exception=True)`。
     2. `cfg = {"api_key": api_key, "base_url": base_url}`；`AnthropicCredentialSchema.model_validate(cfg)`（catch `pydantic.ValidationError` → 400 `{"detail":"凭证字段校验失败，请检查 API Key 与 Base URL"}`）。
     3. 健康校验：`result = await health_check_config("anthropic", cfg, model)`；若 `not result.ok` → 400
        `{"detail": f"连接或鉴权失败：{result.error}。请检查 API Key 是否正确、Base URL 是否为该供应商的 Anthropic 兼容端点", "code": "provider_health_failed", "error": result.error}`，**不落库**。
     4. `available_models = _normalize_available_models([{ "id": model, "display_name": model, **({"context_length": context_length} if context_length else {}), "supports_vision": supports_vision }], provider_type="anthropic")`。
     5. 幂等 upsert（`sync_to_async`）：`encrypt_value(json.dumps({"api_key":..., "base_url":...}, ensure_ascii=False))`；
        `ProviderCredential.objects.update_or_create(scope="system", provider_type="anthropic", name=name, defaults={encrypted_config, base_url, default_model=model, available_models, is_active=True, last_health_check_status="ok", last_health_check_at=timezone.now(), last_health_check_error=""})`。
     6. 原子设默认（`sync_to_async` + `transaction.atomic`）：清零同 `(scope=system, scope_id=None, provider_type=anthropic)` 维度其他 `is_default`，本行 `is_default=True` save。
     7. 绑定 Claude Code：`await aset_claude_code_config(str(cred.id), {"opus": model, "sonnet": model, "haiku": model})`（catch `ProviderConfigError` → 500/400 可操作提示）。
     8. 返回 `Response({id, provider_type, name, scope:"system", default_model, is_default:True, health:{status, latency_ms}, claude_code_bound:True}, status=200)`。
   - 结构化日志：仅记 `credential_id`/`provider`/`latency_ms`，不记 api_key。

4. **`server/system/urls_providers.py`** — 新增 path
   - `path("setup-wizard/", ProviderSetupWizardView.as_view(), name="provider-setup-wizard")`，置于 `*router.urls` 之前；import 视图。

5. **`server/tests/test_provider_setup_wizard.py`** — 新增（respx mock + APIClient）
   - `test_wizard_creates_encrypted_default_and_binds_claude_code`（PROV-01/05/SEC-02）：mock count_tokens 200；superuser POST；断言 201/200、`ProviderCredential` 存在、`is_default=True`、`encrypted_config` 不含明文 `api_key` 且 `decrypt_value` 还原；`SettingKeys.CLAUDE_CODE_CONFIG` 写入 credential_id + 三档映射。
   - `test_wizard_health_fail_no_persist_actionable`（PROV-04）：mock count_tokens 401 → 400、含可操作提示、DB 无凭证。
   - `test_wizard_idempotent_retry`：两次 POST 同 name → 仅一行、更新而非冲突。
   - `test_wizard_requires_superuser`：普通用户 403；匿名 401/403。
   - `test_wizard_error_redacted`：上游 body 含 sk-ant-* → 响应/库错误脱敏（含 REDACTED）。

## Risks
