## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| produced_artifacts（DB，半可信容器产物） → 下游 prompt | 上游仓（半可信 runner 产出）的产物文本被注入下游编码容器 prompt，构成下游 prompt 注入面 |
| 下游容器 prompt → 编码 agent | 上游契约段作为 global context 进入下游 agent 上下文 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-45-05 | Tampering (prompt injection) | render_upstream_artifacts_section 注入下游 prompt | mitigate | 渲染段仅列结构化白名单字段（仓名/分支/MR/契约文件路径/计数），**作为数据呈现**而非指令；不内联 raw_output 正文；上游契约文本视为半可信数据，渲染为 Markdown 列表项不解释执行 |
| T-45-06 | DoS | 半可信上游产物含超多/超长契约路径 → 下游 prompt 膨胀 | mitigate | 仅渲染路径/计数（非 diff 正文）；产物源已在 Plan 01 提取阶段限定白名单字段；如单仓文件清单超长，render 仅逐路径列出无递归（可按可读性截断，Discretion） |
| T-45-07 | Info Disclosure | 上游产物经下游 prompt 泄漏 | mitigate | 产物提取阶段（Plan 01）已保证不含 token/凭证；注入仅传递路径/URL/计数；coding.py 日志仅记 `has_*` 布尔/计数不记产物正文 |
| T-45-08 | DoS | 收集/渲染异常 → 回调 5xx 重试 | mitigate | `_dispatch_next_wave` 收集段 fail-soft（异常 warning → 注入空段，零回归降级），不冒泡使容器回调 5xx |
| T-45-SC | Tampering | npm/pip/cargo installs | accept | 本 plan 不安装任何外部包（纯内部 Django node + 纯函数），无 supply-chain 面 |
