<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| 用户表单（regex/glob/pattern） → 保存校验 | 不可信输入，非法 regex 或恶意 pattern 进入匹配器影响所有读取面 |
| 规则变更 → 匹配器缓存 | 缓存不失效则新规则不生效，造成"以为排除了实际没排"的安全错觉 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-22-17 | Denial of Service | 保存灾难性回溯 regex（ReDoS） | mitigate | 保存时 re.compile 校验语法（拒非法）；对超长 pattern 设长度上限；运行期匹配异常仍 fail-closed（Plan 01） |
| T-22-18 | Information Disclosure | 规则变更后缓存未失效，读取面仍放行 | mitigate | 写操作后 invalidate_matcher_cache(repository_id) |
| T-22-19 | Elevation of Privilege | 越权改他仓排除规则 | mitigate | 沿用仓库既有权限类（认证 + 仓库可见性校验） |
| T-22-20 | Repudiation | UI 过度承诺"git 物理删除"误导用户 | mitigate | 文案如实（DOMAIN §9.1）；checkpoint 人工核对措辞 |
</threat_model>
