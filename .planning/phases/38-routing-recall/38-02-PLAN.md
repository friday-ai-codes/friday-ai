构造参数 `top_k: int = 3`（可配，默认 3，对齐 38-CONTEXT）。`async def route(self, session)`：
1. query = `(session.decomposition or {}).get("requirement_text", "")`。若为空 → 返回 `{"candidates": [], "router_version": "skipped", "auto_selected": False}`（无 query 不路由，不抛）。
2. 候选范围 repository_ids 按优先级解析（实现 `_resolve_repository_ids(session)`）：
   ① `include = (session.decomposition or {}).get("include_repos")`；非空 list → `[str(r) for r in include]`。
   ② 否则若 `session.work_item_id` 非空 → 取该 work_item 所属 project 的仓库 id 列表（经 `sync_to_async` 包裹同步 ORM：`WorkItem.objects.select_related("project").filter(id=work_item_id).first()`，无 project 或无仓库返回 None；有则 `[str(r) for r in wi.project.repositories.values_list("id", flat=True)]`，空列表也回退 None）。
   ③ 否则 None（全库）。
3. 调 `result = await RepoRouterV2.route(query, top_k=self.top_k, repository_ids=repository_ids, use_llm=True)`（import `from codegraph.services.repo_router_v2 import RepoRouterV2`）。
4. 映射为精简 dict（避免存大正文）：`candidates = [{"repo_id": c.repo_id, "confidence": c.confidence, "repository_name": c.repo_name} for c in result.candidates]`，返回 `{"candidates": candidates, "router_version": result.router_version, "auto_selected": result.auto_selected}`。
不加额外容错（RepoRouterV2 自带 LLM 失败 → Stage0 → v1 的降级链）；async ORM 一律经 `sync_to_async`。ruff line-length 100。
在 `server/services/plan_orchestration/__init__.py` re-export `RepoRouterV2Adapter`（加入 import + `__all__`）。
新建 `server/tests/services/test_repo_router_adapter.py`（`@pytest.mark.asyncio`，RepoRouterV2 用 monkeypatch/`unittest.mock` 替换为返回构造 `RepoRouteResultV2(candidates=[RepoRouteCandidateV2(repo_id="r1", repo_name="N", score=0.9, confidence="high", reasoning="x")], router_version="v2", auto_selected=True)` 的 AsyncMock）：
- `test_maps_router_result`：decomposition 含 requirement_text，断言返回 dict 的 candidates[0] == {repo_id:"r1", confidence:"high", repository_name:"N"} 且 router_version/auto_selected 透传。
- `test_empty_query_skips`：requirement_text 空 → 返回 candidates 空 + router_version "skipped"，且 RepoRouterV2.route 未被调用。
- `test_scope_include_repos_precedence`（`@pytest.mark.django_db`）：decomposition include_repos=["rX"] → 断言 RepoRouterV2.route 收到 `repository_ids=["rX"]`（用 mock 捕获 kwargs）。

构造 work_item/project/repository 用既有工厂或最小 acreate（project.repositories.aadd(repo)）。
