创建 `server/audit/` Django app，注册到 INSTALLED_APPS。

**1. AppConfig** (`server/audit/apps.py`)：
- `name = "audit"`, `verbose_name = "操作审计"`
- `default_auto_field = "django.db.models.BigAutoField"`

**2. AuditEvent 模型** (`server/audit/models.py`)：
- `id`: UUIDField(primary_key=True, default=uuid4)
- `actor`: CharField(max_length=150) — 操作人用户名
- `actor_ip`: CharField(max_length=45, blank=True, default="") — IP 地址
- `action`: CharField(max_length=100, db_index=True) — 操作类型（如 credential.create, rule.update）
- `target_type`: CharField(max_length=100, blank=True, default="", db_index=True) — 目标对象类型
- `target_id`: CharField(max_length=255, blank=True, default="") — 目标对象 ID
- `before_value`: JSONField(null=True, blank=True) — 变更前值
- `after_value`: JSONField(null=True, blank=True) — 变更后值
- `source`: CharField(max_length=50, default="web", db_index=True) — 来源（web/api/system）
- `extra`: JSONField(default=dict, blank=True) — 附加上下文
- `created_at`: DateTimeField(auto_now_add=True, db_index=True)
- Meta: `ordering = ["-created_at"]`, verbose_name = "审计事件"
- `__str__`: `f"{self.actor} {self.action} at {self.created_at}"`

**3. Admin** (`server/audit/admin.py`)：
- `AuditEventAdmin` 只读（`readonly_fields` 全量字段）
- `list_display`: actor, action, target_type, source, created_at
- `list_filter`: action, source, created_at
- `search_fields`: actor, action, target_id
- `has_add_permission` / `has_change_permission` / `has_delete_permission` 返回 False

**4. 迁移**: `python manage.py makemigrations audit`

**5. 注册**: 添加 `'audit'` 到 `server/friday/settings.py` INSTALLED_APPS
  </action>

  </verification>

**1. 序列化器** (`server/audit/api/serializers.py`)：
- `AuditEventSerializer` (ModelSerializer): 暴露全部字段（只读）

**2. Views** (`server/audit/api/views.py`)：
- `AuditEventListView(APIView)`:
  - `permission_classes = [IsSuperUser]`
  - GET: 列表 + 过滤参数（action, source, target_type, start_date, end_date）
  - 分页: 使用 DRF PageNumberPagination
  - 支持 `?page_size=` 参数

- `AuditEventExportView(APIView)`:
  - `permission_classes = [IsSuperUser]`
  - GET: 导出 CSV 或 JSON
  - `?format=csv` → StreamingHttpResponse with text/csv
  - `?format=json` (default) → JsonResponse
  - 同样接受 action/source/target_type/start_date/end_date 过滤

**3. URLs** (`server/audit/api/urls.py`)：
- `path("audit-events/", AuditEventListView.as_view())`
- `path("audit-events/export/", AuditEventExportView.as_view())`

**4. 主路由**: 在 `server/friday/urls.py` api_patterns 添加:
- `path("audit/", include("audit.api.urls"))`

**5. 创建 `server/audit/api/__init__.py`**（空文件）
