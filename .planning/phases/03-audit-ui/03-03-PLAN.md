创建 `web/src/api/audit.ts`：

**类型定义**：
```ts
export interface AuditEvent {
  id: string
  actor: string
  actor_ip: string
  action: string
  target_type: string
  target_id: string
  before_value: unknown | null
  after_value: unknown | null
  source: string
  extra: Record<string, unknown>
  created_at: string
}

export interface AuditEventListResponse {
  count: number
  results: AuditEvent[]
}

export interface AuditEventFilters {
  action?: string
  source?: string
  target_type?: string
  start_date?: string  // ISO date
  end_date?: string
  page?: number
  page_size?: number
}
```

**API 函数**：
- `listAuditEvents(filters?: AuditEventFilters): Promise<AuditEventListResponse>`
  - GET `/audit-events/` with query params
- `exportAuditEvents(format: 'csv' | 'json', filters?: Omit<AuditEventFilters, 'page' | 'page_size'>): void`
  - 构建 URL + window.open 触发下载（不经过 fetch wrapper，直接下载）
  </action>
</task>

  <action>
创建 `web/src/pages/admin/audit.vue`：

**路由 meta**: `definePage({ meta: { requiresAdmin: true } })`

**页面结构** (仿 conversations.vue)：
1. PageContainer + PageHeader（icon: lucide--shield-check, title: 操作审计）
2. 过滤器区域（filters slot in DataTable）：
   - action 下拉选择（预设常见操作类型列表 + 自定义输入）
   - source 下拉选择（web/api/system）
   - target_type 文本输入
   - 日期范围（start_date / end_date，原生 date input）
   - 重置按钮
3. DataTable（使用 server-side 模式，自建分页控件）：
   - 列：时间、操作人、操作类型、目标类型、目标ID、来源、详情按钮
   - 行点击打开详情对话框
4. 详情对话框（Dialog）：
   - 基本信息卡片
   - before_value / after_value JSON diff 展示（用 pre/code 格式化显示）
   - extra 附加信息展示
5. 导出按钮（在 PageHeader actions slot）：
   - CSV 导出 / JSON 导出 下拉菜单
   - 使用当前过滤参数

**交互逻辑**：
- 页面加载 → 调用 listAuditEvents()
- 过滤器变化 → 重新请求（watch debounced）
- 分页 → 更新 page 参数并重新请求
- 导出 → window.open 带当前过滤参数的导出 URL
- 详情 → 弹出 Dialog 展示完整信息 + JSON diff
  </action>
</task>
