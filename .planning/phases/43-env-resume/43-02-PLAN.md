  <action>
    新建 `server/services/plan_orchestration/resume.py`，定义 `async def adrive_plan_session_to_pause_or_terminal(engine, session, *, max_steps: int = 20)`。逻辑抽自 analog 1（`plan_research.py:142-167`）与 analog 2（`plan_research_tools.py:124-153`）的公共 while 循环，但**剔除**入口私有的 `_maybe_suspend`/`NodeResult`/`ToolResult` marker 映射（驱动仍是入口私有，对齐 `entrypoint.py` docstring「helper 不驱动 engine.advance……驱动是入口私有」的精神——此处 helper 只负责入口无关的 advance 续驱与短路）：
    - `from delivery.models import Clarification, PlanSession, PlanSessionStatus`（函数内 lazy import，规避 import 环）。
    - `from services.plan_orchestration import aall_research_tasks_terminal`（lazy import）。
    - `terminal = {PlanSessionStatus.DONE, PlanSessionStatus.FAILED}`；`steps = 0`。
    - `while session.status not in terminal:`：
      - `steps += 1`；`if steps > max_steps:` → `await engine.session_service.transition(session, "fail", error={"reason": "advance_step_limit", "steps": steps})` 后 `return await PlanSession.objects.aget(id=session.id)`（**不**直接写 status，照搬 analog 1 fail 分支）。
      - **clarifying 在途短路（BLOCKER 修复，保护澄清 HITL）：** `if session.status == PlanSessionStatus.CLARIFYING:` 时查未答澄清——`has_pending = await Clarification.objects.filter(session_id=session.id, answered_at__isnull=True).aexists()`，`if has_pending: return session`（不再 advance，等用户作答后由入口私有挂起逻辑/再次 resume 推进）。该 query 必须**照搬节点/工具 `_maybe_suspend` 的 clarifying 分支**（`plan_research_tools.py:218-225` / `plan_research.py:258-296`：`Clarification.objects.filter(session_id=session.id, answered_at__isnull=True)`）以保证行为等价。理由：`engine._clarify`（`engine.py:170-179`）在 `needs_clarification` 时保持 `clarifying→clarifying` 自挂起，若 helper 不短路会一路 advance 到 `max_steps` 被错误 FAILED，回归澄清 HITL（red-line `test_plan_research_node.py::test_clarifying_suspends_waiting_event`）。
      - 重挂起短路（researching）：`if session.status == PlanSessionStatus.RESEARCHING and not await aall_research_tasks_terminal(session.id): return session`（researching 仍有在途调研 → 等下一次容器回调，不再 advance）。
      - `await engine.advance(session)`；`session = await PlanSession.objects.aget(id=session.id)`（重读状态，async ORM 经 aget）。
    - 循环结束 `return session`。
    在 `services/plan_orchestration/__init__.py` 按既有 barrel 范式（参考 `__init__.py:44-48` 的 `research_aggregation` re-export）新增 `from services.plan_orchestration.resume import adrive_plan_session_to_pause_or_terminal` 并加入 `__all__`。
    约束（Anti-Patterns）：engine 由调用方传入（入口无关，**不**在 helper 内新建第二个 engine 工厂）；status 只经 `engine.session_service.transition`；helper 内无任何 workflow/chat IO。
