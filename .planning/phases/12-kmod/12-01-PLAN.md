    - 四类 kind 各落库一条成功，字段（source_kind/source_id/origin/event_time）读回一致
    - 同 (kind, source_kind, source_id) 二次 create → IntegrityError（uniq_kentity_natural_key）

    - 删除被 supersedes 引用的 v1 → ProtectedError（PROTECT 失效置位不删除保险）
    - invalid_at <= valid_at → IntegrityError（kversion_valid_range）

    - invalid_at <= valid_at → IntegrityError（kedge_valid_range）
