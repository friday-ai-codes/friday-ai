`def _redact_json(value: Any) -> Any`（模块级私有纯函数，**本相位自建，本仓无先例**）：
- `str` → `redact_secrets_in_text(value)`
- `dict` → `{_redact_json(k) if isinstance(k, str) else k: _redact_json(v) for k, v in value.items()}`（**key 也脱敏**）
- `list` / `tuple` → 逐元素递归（返回 list）
- 其余标量（int/float/bool/None）原样返回
- 整个函数包 `try/except Exception: return value`？**不**——脱敏是安全边界，失败必须可见：递归内部对 `redact_secrets_in_text` 单点调用包 `try/except` 时**回落为空串而不是原文**（fail-closed），并 `logger.warning("blueprint_context_redact_failed")`。
