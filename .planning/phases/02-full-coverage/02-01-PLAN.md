  <action>
在 `server/accounts/views.py` 中为以下操作添加 `aemit_audit_event()` 调用：

1. **LoginView.post** — 用户登录成功后 emit `user.login`（target_type="User", target_id=str(user.id)）
2. **SetupInitView.post** — 首启初始化创建 superuser 成功后 emit `user.created`（actor_type="system", target_type="User", after={username, display_name, source}）
3. **InvitationView.post** — 创建邀请成功后 emit `user.invitation_created`（target_type="Invitation", target_id=str(invitation.id), after={email}）
4. **InvitationAcceptView.post** — 接受邀请注册用户成功后 emit `user.created`（target_type="User", target_id=str(user.id), after={username, source}）
5. **UserDetailView.patch** — 修改用户状态(is_active)后 emit `user.updated`（target_type="User", target_id=str(target_user.id), before/after={is_active}）
6. **ChangePasswordView.post** — 密码修改成功后 emit `user.password_changed`（target_type="User", target_id=str(request.user.id)）
7. **ForceChangePasswordView.post** — 强制密码修改成功后 emit `user.password_changed`
8. **ProfileUpdateView.patch** — 更新资料后 emit `user.updated`（target_type="User", target_id=str(user.id), after={display_name}）
9. **AdminProfileView.put** — 管理员修改 profile 后 emit `user.updated`
10. **AdminChangePasswordView.post** — 管理员修改密码后 emit `user.password_changed`

import `aemit_audit_event` from `audit.emitter`，每个 emit 包在 try/except 中（best-effort），emit 失败仅 log warning。

写测试文件 `server/tests/audit/test_coverage_accounts.py`：
- 使用 pytest + django TestCase
- 测试 LoginView、InvitationAcceptView、UserDetailView、ChangePasswordView 的 emit 点
- 每个测试执行操作后 assert AuditEvent.objects.filter(action=expected_action).exists()

**system/views.py:**
3. **SettingsListCreateView.post** — 创建设置后 emit `system_setting.created`（target_type="SystemSetting", target_id=key, after={key, description}）
4. **SettingsDetailView.put** — 更新设置后 emit `system_setting.updated`（target_type="SystemSetting", target_id=key, before/after 快照去掉 value 敏感字段）
5. **SettingsDetailView.delete** — 删除设置后 emit `system_setting.deleted`（target_type="SystemSetting", target_id=key）
6. **ProviderCredentialViewSet.perform_acreate** — 创建供应商凭证后 emit `provider_credential.created`（target_type="ProviderCredential", target_id=str(id), after={provider_type, scope, name}——不含 api_key）
7. **ProviderCredentialViewSet.perform_aupdate** — 更新供应商凭证后 emit `provider_credential.updated`
8. **ProviderCredentialViewSet.perform_adestroy** — 删除供应商凭证后 emit `provider_credential.deleted`
9. **ProviderCredentialViewSet.toggle_active** — toggle 后 emit `provider_credential.toggled`
10. **ProviderSetupWizardView.post** — 向导完成后 emit `provider_credential.created`（after={provider_type, name, scope}）

**system/setup_views.py:**
11. **SetupFeishuWizardView.post** — 飞书配置后 emit `system_setting.updated`（after={keys_written: ["FEISHU_APP_ID", "FEISHU_APP_SECRET"]}）
12. **SetupRagWizardView.post** — RAG 配置后 emit `system_setting.updated`（after={keys_written}）

每个 emit 在 DB 成功后、best-effort try/except 包裹。同步方法用 emit_audit_event()，异步用 aemit_audit_event()。
