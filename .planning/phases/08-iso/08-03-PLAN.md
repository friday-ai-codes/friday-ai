<objective>
Enforce conversation owner isolation at EVERY one of the 25 access paths in RESEARCH's inventory by routing all conversation lookups in `server/chat/views.py` through the centralized owner gate from 08-02. This turns the 08-01 RED suite GREEN.

Purpose: ISO-04 is all-or-nothing — a single ungated path is a security hole. This plan's coverage map is 1:1 with RESEARCH's 25-endpoint table.
Output: `views.py` with the owner gate applied uniformly across all conversation-touching endpoints.
</objective>
