    `Document` 模型（db_table="delivery_document"）：
      - `id = UUIDField(primary_key=True, default=uuid.uuid4, editable=False)`；
      - `document_type = CharField(max_length=32, choices=DocumentType.choices)`；
      - `source_kind = CharField(max_length=32, choices=DocumentSourceKind.choices)`；
      - `external_ref = CharField(max_length=255, blank=True, default="")`（飞书 doc token / 其他外部标识）；
      - `canonical_url = URLField(max_length=1000, blank=True, default="")`（自托管/多租户深链可超默认 200，沿用 WorkItem.prd_url 的 1000 宽度）；
      - `content_storage = CharField(max_length=16, choices=ContentStorage.choices, default=ContentStorage.BOTH)`；
      - `current_version = ForeignKey("delivery.DocumentVersion", null=True, blank=True, on_delete=models.SET_NULL, related_name="+")`（前向字符串引用 + related_name="+" 避免与 DocumentVersion.document 反查名冲突，避免删版本抹 Document）；
      - `last_synced_at = DateTimeField(null=True, blank=True)`；
      - `writeback_allowed = BooleanField(default=False)`（内部生成且需回写飞书时 True；本 phase 仅字段位）；
      - `work_item = ForeignKey(WorkItem, null=True, blank=True, on_delete=models.SET_NULL, related_name="documents")`（同 app 直接类引用，REFERENCES 操作态对应；null 允许=反查未落库占位）；
      - `feishu_tenant = CharField(max_length=64, blank=True, default="")`（多租户区分，如 guanghe）；
      - `created_at = DateTimeField(auto_now_add=True)`、`updated_at = DateTimeField(auto_now=True)`。
      - Meta.indexes：`Index(fields=["work_item", "document_type"])`（30-04 PRD 检索路径）、`Index(fields=["feishu_tenant", "external_ref"])`（30-02 external_feishu 去重定位）。verbose_name="文档"。

    `DocumentVersion` 模型（db_table="delivery_document_version"）：
      - `id = UUIDField(primary_key=True, default=uuid.uuid4, editable=False)`；
      - `document = ForeignKey(Document, on_delete=models.CASCADE, related_name="versions")`；
      - `version = PositiveIntegerField()`；
      - `supersedes = ForeignKey("self", null=True, blank=True, on_delete=models.SET_NULL, related_name="superseded_by")`（被本版本取代的旧版本；SET_NULL 与 §12.5 "supersedes FK(self,null)" 对齐）；
      - `content = TextField(blank=True, default="")`（文档正文快照；降级缺料时可空，对齐"缺段不缺实体"）；
      - `content_hash = CharField(max_length=64, blank=True, default="")`（sha256 hex；内容相等不翻版本，30-02 复用 knowledge hash 范式）；
      - `created_at = DateTimeField(auto_now_add=True)`。
      - Meta：`unique_together = (("document", "version"),)`、`Index(fields=["document", "-version"])`。verbose_name="文档版本"。

    模型层不写任何 create/save 业务方法（落库逻辑归 30-02 DocumentService，守 INV-6）。
