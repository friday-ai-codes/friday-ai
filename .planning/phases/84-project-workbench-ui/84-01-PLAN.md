<objective>
为 Phase 84 前端工作台补齐缺失的后端只读/写回 REST 支撑面（WB-02/03/05 的后端部分）。Phase 82/83 已落地项目聚合根、工作区文件容器元数据、ProjectStateApi、以及服务层的飞书双向同步引擎（`DocSyncService`），但**前端无法**：取单文档正文与 block 分区、把人工区编辑回灌、取 feature 树与进度灯、对项目做模糊搜索。本 plan 在 `server/initiatives` 暴露这些端点，**全部复用既有服务层**（`DocSyncService` / `ProjectDocService` / `MemoryService` / 知识检索），不绕过区段所有权与权限。

Purpose: 让前端 WB-02/03/05 有真实数据/写回路径；区段写回收口到同步引擎，永不整篇覆盖。
Output: doc content GET、人工区写回 PUT、feature-list GET、work-items 含 status、项目搜索 GET、StateApi PATCH，及守护测试。
</objective>
