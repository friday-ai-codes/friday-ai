新建 `spec_generation.py`：
1. `@runtime_checkable class SddSpecSynthesizer(Protocol)`：`async def synthesize(self, *, requirement: str, merged_plan: dict, repository) -> str: ...`（输出 openspec 格式 markdown，D-49-4）。
2. `class LLMSddSpecSynthesizer`（镜像 LLMMergedPlanSynthesizer）：`ProviderConfigService.aresolve()` + 取 default_model（无则 RuntimeError("no_default_model")）+ `build_chat_model` + `ainvoke([SystemMessage, HumanMessage])`，`_content_to_text` 归一化（可从 architect_merge_adapter import 复用或本地复制小工具）。system prompt **教 openspec change-proposal 结构**：`## Why` / `## What Changes` / `## Spec Deltas`（ADDED/MODIFIED/REMOVED Requirements + Scenarios）；human prompt 输入=需求文本 + MergedPlan(JSON) + 仓库名。输出 markdown（非 JSON，不需 JSON 解析）；合成失败抛异常由上层 hook 捕获降级。**真 LLM 路径仅构造 + 单测 mock，真容器/真模型 E2E deferred**（对齐 D-49-4，docstring 标注）。
3. `async def agenerate_specs_for_plan(plan_version_id, *, synthesizer=None, spec_service=None)`：
   - `synthesizer = synthesizer or LLMSddSpecSynthesizer()`；`spec_service = spec_service or SddSpecService()`（lazy import 防跨 app 环）。
   - 取 PlanVersion：`pv = await PlanVersion.objects.filter(id=plan_version_id).afirst()`；None → return（no-op）。`merged = pv.content if isinstance(pv.content, dict) else {}`。
   - 解析涉及仓 repo_id：遍历 `merged.get("execution_plan", [])` 取 `item["repository_id"]`（去空、去重，保持顺序）。
   - 取需求文本：从关联 session/work_item 派生（async 安全用标量）。**实现**：经 `session = await PlanSession.objects.filter(current_plan_version_id=plan_version_id).afirst()`；requirement = `(session.decomposition or {}).get("requirement_text", "")` if session else ""（与 LLMMergedPlanSynthesizer 取需求一致）。work_item = `await WorkItem.objects.filter(id=session.work_item_id).afirst()` if session else None。
   - 过滤 SDD 仓：对每个 repo_id `repo = await Repository.objects.filter(id=repo_id).afirst()`；跳过 None；跳过 `(repo.facets or {}).get("methodology") != "SDD"`（非 SDD → 零回归；全非 SDD → no-op）。
   - 逐 SDD 仓 try/except 隔离：`spec_md = await synthesizer.synthesize(requirement=requirement, merged_plan=merged, repository=repo)` → `spec = await spec_service.create_draft(plan_version_id=plan_version_id, repository=repo, work_item=work_item, content=spec_md, change_kind="proposal")` → emit。单仓异常 `logger.warning("sdd_spec_per_repo_failed", repository_id=..., error=...)` 继续下一仓。
   - emit：best-effort 经 `PlanSessionService()._emit_event(EVENT_SPEC_DRAFTED, session, {"spec_id": str(spec.id), "repository_id": str(repo.id), "plan_version_id": str(plan_version_id)})`，仅 session 非空时 emit；emit 包 try/except warning（绝不阻断后续仓）。**注意：emit 调用须写成 `await session_service._emit_event(EVENT_SPEC_DRAFTED, session, payload)` 字面，使 taxonomy 对齐守护正则（`_emit_event\(\s*EVENT_...`）命中**。
   - 返回产出的 SddSpec 列表（便于测试/调用方）。
   - **async ORM 防裸 lazy-FK**：全程 `*_id` 标量 + afirst/aexists，禁裸访问 lazy-FK。
4. `plan_orchestration/__init__.py` re-export `SddSpecSynthesizer` / `LLMSddSpecSynthesizer` / `agenerate_specs_for_plan` 进 import + `__all__`。
