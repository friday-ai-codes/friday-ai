  <action>
新增 async `create_internal_spec(self, *, work_item, repository_label, content, title="")` -> Document（签名对齐 D-49-2；`repository_label` 仅用于 __str__/日志区分，不作去重键）：
- 经 `@sync_to_async` 包裹的私有同步方法（如 `_create_internal_locked`）在 `transaction.atomic` 内落库。
- internal 文档**无 external_ref 去重键**（`external_ref=""`，豁免 `~Q(external_ref="")` 唯一约束）、`feishu_tenant=""`（不派生租户）。因此每次 create_internal_spec 调用建**新** Document（不像 external 走 get_or_create 收敛）——幂等收敛在上层 SddSpecService.get_or_create（Phase 49-03），DocumentService 只负责忠实落一份内部文档 + 版本。
- 字段：`document_type=DocumentType.SDD_SPEC`、`source_kind=DocumentSourceKind.INTERNAL_GENERATED`、`content_storage=ContentStorage.SNAPSHOT`、`work_item=work_item`、`canonical_url=""`。
- 版本：建 DocumentVersion(version=1, content=content, content_hash=_content_hash(content), supersedes=None)，置 document.current_version 并 save。复用既有 `_content_hash`。
- **hash 不翻版本铁律**：若上层后续在**同一** Document 上再写（本 phase 暂无该路径，但为对齐铁律保持方法可重入语义），content_hash 相等则不建新版本。本 phase create_internal_spec 每次建新 Document，铁律体现在「DocumentVersion 版本链 + content_hash」既有 add-version 语义；若决定支持「对已存在 spec Document 追加版本」，加一个 `document=None` 可选入参走翻版本分支。**默认实现：每调用建新 Document+v1**（最简、对齐 D-49-2「落 Document + DocumentVersion」，幂等由 SddSpec 层收口）。
- 不写 WorkItemSyncState facet（internal spec 非 prd/tech_plan facet 类型）。
- **守 INV-6**：所有写仍在 document_service.py 内（既有 grep 守护 writer 不变）。方法 docstring 标注「internal_generated 文档单一写入入口」。
