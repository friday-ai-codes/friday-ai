  <name>Task 1: 新建 SddSpec 模型 + SddSpecStatus / SddSpecChangeKind 枚举</name>
  <files>server/delivery/models/sdd_spec.py</files>
  <action>
按 D-49-1 新建 `SddSpec`（db_table="delivery_sdd_spec"，UUID 主键 default uuid4）：
- `document` FK → "delivery.Document"（on_delete=SET_NULL, null=True, related_name="sdd_specs"）——持有 spec 正文/版本，SET_NULL 避免删文档抹 spec 记录（对齐 Document.current_version 的 SET_NULL 取向）。
- `repository` FK → "repositories.Repository"（on_delete=CASCADE, related_name="sdd_specs"）——哪个 SDD 仓。
- `work_item` FK → "delivery.WorkItem"（null=True, blank=True, on_delete=SET_NULL, related_name="sdd_specs"）——SPEC-02 追溯，可空对齐 chat 自然语言入口（INV-2）。
- `plan_version` FK → "delivery.PlanVersion"（null=True, blank=True, on_delete=SET_NULL, related_name="sdd_specs"）——SPEC-02 来源方案。
- `status` CharField(max_length=16, choices=SddSpecStatus.choices, default=SddSpecStatus.DRAFT)。
- `change_kind` CharField(max_length=16, choices=SddSpecChangeKind.choices, default=SddSpecChangeKind.PROPOSAL)。
- `created_at = auto_now_add`，`updated_at = auto_now`。
定义两枚举（models.TextChoices）：
- `SddSpecStatus`：DRAFT="draft" / IN_REVIEW="in_review" / APPROVED="approved" / IMPLEMENTED="implemented" / ARCHIVED="archived"（全枚举现在定义；流转逻辑归 Phase 50，本 phase 仅落 draft 初值，per D-49-1）。
- `SddSpecChangeKind`：PROPOSAL="proposal" / DELTA="delta"。
Meta：`unique_together = (("plan_version", "repository"),)`（D-49-1 幂等键——同方案版本对同一仓只产一份 spec）；`verbose_name`/`verbose_name_plural` 中文；可加 `indexes` 便于 repository/work_item 检索（如 Index(fields=["repository", "status"])）。
**INV-6 硬约束**：模型层零业务方法——只放字段定义 + `__str__`，禁止写任何 create/save 业务逻辑（写入只经 Phase 49-03 的 SddSpecService）。模块 docstring 标注「落库只经 SddSpecService（INV-6）」。FK 一律用字符串前向引用避免 import 环。
