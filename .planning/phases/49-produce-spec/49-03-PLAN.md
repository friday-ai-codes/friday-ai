新建 `server/services/plan_orchestration/spec_generation.py`（镜像 architect_merge_adapter.py 的协议 + LLM 合成器 + 健壮文本归一化范式；中文 docstring）：

- `@runtime_checkable class SddSpecSynthesizer(Protocol)`：`async def synthesize(self, *, requirement: str, merged_plan: dict, repository) -> str`（输出 openspec 格式 markdown）。
- `class LLMSddSpecSynthesizer`：默认 LLM 合成器，镜像 `LLMMergedPlanSynthesizer`：
  - `ProviderConfigService.aresolve()` + `build_chat_model`（无 default_model → `raise RuntimeError("no_default_model")`）。
  - `_system_prompt()`：**教 openspec change-proposal 结构** —— 产出含 `## Why` / `## What Changes` / `## Spec Deltas`（`ADDED Requirements` / `MODIFIED Requirements` / `REMOVED Requirements`，每条带 `#### Scenario:`）的 markdown change proposal；只输出 markdown，不要解释。
  - `_build_prompt(requirement, merged_plan, repository)`：输入=需求文本 + MergedPlan（json.dumps）+ 仓库名（`repository.name`）。
  - `synthesize`：ainvoke → 复用/新增 `_content_to_text` 归一化为 markdown 文本；空文本 → `raise ValueError("spec_synthesis_empty")`。**真 LLM 路径仅构造 + 单测 mock，真容器/真模型 E2E deferred**（docstring 注明，对齐 LLMMergedPlanSynthesizer）。
- 模块级 `async def agenerate_specs_for_plan(plan_version_id, *, synthesizer=None, spec_service=None) -> list`（per D-49-4/5）：
  1. `synthesizer = synthesizer or LLMSddSpecSynthesizer()`；`spec_service = spec_service or SddSpecService()`（lazy import 防环）。
  2. 取 PlanVersion：`pv = await PlanVersion.objects.filter(id=plan_version_id).afirst()`；None → 返回 `[]`（防御）。`merged_plan = pv.content`（MergedPlan dict）。
  3. 解析来源 session（emit + requirement + work_item 用）：`session = await PlanSession.objects.filter(current_plan_version=plan_version_id).afirst()`；`requirement = (session.decomposition or {}).get("requirement_text","")` if session else ""；`work_item = await WorkItem.objects.filter(id=session.work_item_id).afirst()` if session else None（async 安全标量）。
  4. 解析涉及仓：从 `merged_plan.get("execution_plan", [])` 取去重 `repository_id`（过滤空串）。
  5. 逐 repo_id：`repo = await Repository.objects.filter(id=repo_id).afirst()`；`repo is None` 或 `(repo.facets or {}).get("methodology") != "SDD"` → 跳过（**非 SDD 跳过 = 零回归；无 SDD 仓 = no-op**）。
  6. 对每个 SDD 仓 **try/except 隔离**：
     - `content = await synthesizer.synthesize(requirement=requirement, merged_plan=merged_plan, repository=repo)`
     - `spec = await spec_service.create_draft(plan_version_id=plan_version_id, repository=repo, work_item=work_item, content=content)`
     - emit：`await PlanSessionService()._emit_event(EVENT_SPEC_DRAFTED, session, {"spec_id": str(spec.id), "repository_id": str(repo.id), "plan_version_id": str(plan_version_id)})`（session 非空时；best-effort，包 try/except warning）。
     - 收集 `spec.id` 到返回列表。
     - `except Exception` → `logger.warning("sdd_spec_generation_failed", repository_id=str(repo_id), plan_version_id=str(plan_version_id), error=str(exc))`，继续下一仓（单仓失败不影响其余）。
  7. 返回已产 spec id 列表。
  - 所有 import（PlanVersion/PlanSession/WorkItem/Repository/SddSpecService/PlanSessionService/EVENT_SPEC_DRAFTED）用模块顶部或函数内 lazy import，规避 import 环（plan_orchestration `__init__` 在加载期 re-export 本模块）。

改 `server/services/plan_orchestration/__init__.py`：re-export `SddSpecSynthesizer, LLMSddSpecSynthesizer, agenerate_specs_for_plan`，加入 `__all__`。
