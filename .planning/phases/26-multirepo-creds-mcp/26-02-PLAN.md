<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| 解析器 ↔ git 子进程 | token 仅进单次 clone/fetch argv URL |
| 取 token 路径 ↔ 日志 | token 明文绝不进日志 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-26-05 | Information Disclosure | indexer/graph clone token | mitigate | token 仅传 build_authenticated_git_url；接线不新增 token 日志；Test 3 守护 |
| T-26-06 | Information Disclosure | repo_mirror fetch token | mitigate | 保留 _scrub 脱敏 + 不写 git config 既有约束；仅替换取 token 来源 |
| T-26-07 | Spoofing | host fallback | mitigate | 复用 26-01 host 唯一匹配，避免错配他 host 实例凭证 |
| T-26-08 | Repudiation | 兼容回退 | accept | per-repo token 优先由解析器保证，接线为机械替换不改优先级 |
</threat_model>
