## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| task 容器 → Friday Server /api/tools/execute/ | 出站 HTTP 带 PAT；端点是 RBAC/吊销唯一真源 |
| LLM 可见 tool arguments ↔ handler 内部 | PAT 在 handler 内部从 config 取，**不**在 LLM 可见参数里（天然隔离） |
| TaskConfig（env）↔ 日志/落盘 | PAT 明文在 env，绝不进 structlog/print/session 文件 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-04 | Information Disclosure | PAT 进 docker logs / structlog / 返回文本 | mitigate | handler/build/executor 仅记 has_user_token bool 与 tool 名；token 只进 Authorization header（test_token_not_in_logs_or_result 守卫） |
| T-11-05 | Denial of Service / Spoofing | 吊销→401 致整任务崩溃 | mitigate | handler 不 raise_for_status；401/403/非200/传输错误一律 return is_error 结构化结果（RTOOL-04） |
| T-11-06 | Tampering | 把 PAT 拼进 prompt/返回文本被落库 | mitigate | handler 返回文本不含 token；PAT 仅 header；不 print config |
| T-11-07 | Elevation | 容器内提取 PAT 横向调用 | accept | 直传 PAT 里程碑取舍（v2 PATX-04 短 TTL broker 缓解；本期接受） |
