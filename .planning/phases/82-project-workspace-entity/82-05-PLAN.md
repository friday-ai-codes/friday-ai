合上 WS-03 的另一半——**AI 对话的项目绑定可解绑 / 改归**（`Conversation.bound_project`）。当前 `ConversationDetailView.patch`（`server/chat/views.py`）已支持会话内切换空间（`space_id` → `ConversationService.switch_space`）但**不支持改 `bound_project`**；`ConversationPatchSerializer` 也无 `bound_project_id` 字段。本 plan：① 给 `ConversationPatchSerializer` 增 `bound_project_id`（UUID / null）+ 存在性校验；② `ConversationDetailView.patch` 应用该字段（改归到目标项目 / null 解绑），并入 `update_fields` 持久化 + 结构化日志归因；③ 守护测试覆盖改归/解绑/不存在项目拒绝/非 owner 404。
