  新建 `research_task.py`（zh-CN 模块 docstring 引 DOMAIN §6/§7/§12，ruff line 100），定义：

  `RepoResearchTaskStatus(models.TextChoices)`：PENDING="pending" / RUNNING="running" /
  DONE="done" / FAILED="failed" / STALE="stale"（逐字对齐 DOMAIN §6/§14 子任务级状态，
  附 zh-CN label，镜像 PlanSessionStatus 风格）。

  `RepoResearchTask(models.Model)`：
  - `id` = UUIDField(primary_key, default=uuid.uuid4, editable=False)（镜像 PlanSession/TechnicalPlan）。
  - `session` = FK("delivery.PlanSession", on_delete=CASCADE, related_name="research_tasks")。
  - `repository` = FK("repositories.Repository", on_delete=CASCADE, related_name="+")（跨 app
    真实 FK，per CONTEXT：repositories 是稳定基础 app；related_name="+" 不污染 Repository 反查）。
  - `subagent_session` = FK("subagent.SubAgentSession", on_delete=SET_NULL, null=True, blank=True,
    related_name="+")（dispatch 后回填；删容器会话不删 task）。
  - `status` = CharField(max_length=16, choices=RepoResearchTaskStatus.choices, default=PENDING)。
  - `routed_confidence` = CharField(max_length=16, blank=True, default="")（来自 Phase 38 routing 的 high/medium/low）。
  - `attempt` = IntegerField(default=0)（重试计数，RESEARCH-02）。
  - `error` = JSONField(default=dict, blank=True)（失败结构化诊断）。
  - `created_at` = DateTimeField(auto_now_add=True)；`updated_at` = DateTimeField(auto_now=True)。
  - Meta：db_table="delivery_repo_research_task"，verbose_name/plural（zh-CN），
    indexes=[Index(fields=["session", "status"]), Index(fields=["repository"])]。
  - `__str__` 返回 `RepoResearchTask({id}, {status})`。

  `PartialPlan(models.Model)`：
  - `id` = UUIDField(pk, default=uuid.uuid4, editable=False)。
  - `research_task` = FK(RepoResearchTask, on_delete=CASCADE, related_name="partial_plans")。
  - `content` = JSONField(default=dict)（§7 PartialPlan schema：repository_id / research_summary /
    proposed_changes[] / candidate_files[] / api_contracts_exposed[] / dependencies_on_other_repos[]
    —— 校验/写入归 39-02 service，模型层不校验）。
  - `valid` = BooleanField(default=True)（RESEARCH-03 stale 失效位）。
  - `invalidated_reason` = CharField(max_length=64, blank=True, default="")（如 "repo_reindexed"）。
  - `content_hash` = CharField(max_length=64, blank=True, default="")（sha256 hex，由 service 计算）。
  - `created_at` = DateTimeField(auto_now_add=True)。
  - Meta：db_table="delivery_partial_plan"，verbose_name/plural（zh-CN），
    indexes=[Index(fields=["research_task", "valid"])]。
  - `__str__` 返回 `PartialPlan({id}, valid={valid})`。

  **模型层不写** create/save/状态变更/校验业务方法（INV-6 精神：写入只经 39-02 ResearchService）。

  避免 import 环（对齐 plan_session.py 用 "delivery.WorkItem" 字符串引用范式）。
