  <name>Task 1: ResearchService 单一写入入口</name>
  <files>server/delivery/services/research_service.py, server/delivery/services/__init__.py</files>
  <behavior>
    - create_tasks_for_session(session, deep_repos): 为每个 (repository_id, routed_confidence) 建一行 RepoResearchTask(status=pending, attempt=0)；返回创建的 task 列表；幂等——同 session+repository 已存在则复用不重建。
    - mark_running(task, subagent_session): task.status→running，回填 subagent_session 外键。
    - mark_done(task): task.status→done。
    - mark_failed(task, error): task.status→failed，error JSON 落库（dict）。
    - record_partial(task, content): 计算 content sha256 → 建 PartialPlan(content, content_hash, valid=True) 并 mark_done(task)；返回 PartialPlan。
    - retry_task(task): 仅当 task.status==failed 时 → status→pending + attempt+1（不触碰其他 task、不改 session.status）；非 failed 抛 ValueError。
    - invalidate_for_repo(repository_id): 该 repository 关联且 valid=True 的 PartialPlan → valid=False + invalidated_reason="repo_reindexed"；其 RepoResearchTask → status=stale；返回失效计数。
  </behavior>
  <action>
  新建 `research_service.py`（zh-CN docstring 引 DOMAIN §6/§14 + INV-6 精神，ruff line 100）。
  `class ResearchService`，所有 ORM 写经 `sync_to_async` 桥接（沿用 PlanSessionService async 范式，
  禁止 async 上下文裸 ORM）。

  方法签名（async）：
  - `create_tasks_for_session(session, deep_repos: list[dict]) -> list[RepoResearchTask]`：
    `deep_repos` 每项形如 `{"repository_id": str, "routed_confidence": str}`。用
    `get_or_create(session=, repository_id=, defaults={status,routed_confidence,attempt:0})` 保证
    幂等（resume 安全，重入不重建）；returns 创建/取到的 task 列表。
  - `mark_running(task, subagent_session) -> None`：set status=RUNNING + subagent_session，
    save(update_fields=["status","subagent_session","updated_at"])。
  - `mark_done(task) -> None`：status=DONE + save。
  - `mark_failed(task, error: dict) -> None`：status=FAILED + error=(error if dict else {"message":str})
    + save。
  - `record_partial(task, content: dict) -> PartialPlan`：`content_hash` = sha256 of canonical JSON
    （`json.dumps(content, sort_keys=True, ensure_ascii=False)` 的 hexdigest，本地算，不 import knowledge，
    对齐 PlanVersion content_hash 由 service 算的范式）；`PartialPlan.objects.create(research_task=task,
    content=content, content_hash=, valid=True)`；再 `mark_done(task)`；return partial。
  - `retry_task(task) -> RepoResearchTask`（RESEARCH-02 隔离）：以 `filter(id=task.id,
    status=FAILED).update(status=PENDING, attempt=F("attempt")+1, updated_at=now())` 条件更新；
    影响行数 != 1 → raise ValueError（非 failed 不可重试，镜像 PlanSessionService 条件更新 +
    断言范式）；refresh_from_db 后 return（**绝不触碰其他 task / 不改 session.status**）。
  - `invalidate_for_repo(repository_id) -> int`（RESEARCH-03）：找该 repository 的
    RepoResearchTask → 其 valid=True 的 PartialPlan `.update(valid=False,
    invalidated_reason="repo_reindexed")`，对应 RepoResearchTask `.update(status=STALE,
    updated_at=now())`；return 失效 PartialPlan 计数。整段为可重入幂等（已 stale/已 invalid 不二次改）。

  注：本 service **不** dispatch 容器、**不**做 filter（那是 39-03 adapter 的职责）——只管状态/落库。

  curated re-export：`delivery/services/__init__.py` 加 `from delivery.services.research_service
  import ResearchService` + 进 `__all__`。
  </action>
