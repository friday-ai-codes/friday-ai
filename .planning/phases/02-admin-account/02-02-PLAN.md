## Phase Goal

**As a** first-time admin filling the setup wizard, **I want** real-time password strength feedback, confirmation, and to be taken straight into the system after creating my account, **so that** I never see a second login screen.

<objective>
前端增强 `setup.vue` 表单并实现自动登录直达首页（依赖 02-01 后端会话下发）：
1. auth store 新增 `applySetupSession(user)`：集中写入会话状态。
2. i18n 新增强度/校验/成功文案（见 UI-SPEC Copywriting Contract）。
3. `setup.vue`：zod 增强（min 8 + 非纯数字 + 两次一致）、密码强度指示（弱/中/强）、提交成功后 `applySetupSession` + `fetchMe()` + `router.push('/')`、后端 400 字段错误回填。保持原始 fetch POST。
4. 前端测试通过（无回归）。

Output: stores/auth.ts（新增 action）、locales/zh-CN.json（新增键）、pages/setup.vue（增强）、setup.spec.ts（维持/扩展）。
</objective>

    - onSubmit 成功：const data = await response.json()；response.ok → authStore.applySetupSession(data.user)；try { await authStore.fetchMe() } catch {}；router.push('/')。
    - onSubmit 失败：若 data 含字段错误（如 data.password 数组 / data.username 数组）→ 汇总到 setupError 顶部错误条（用后端中文消息），否则用 data.detail || t('setup.error.default')。

    - 密码占位文案改用 t('setup.fields.passwordPlaceholder')。
  </behavior>
