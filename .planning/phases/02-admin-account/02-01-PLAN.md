## Phase Goal

**As a** first-time admin on a fresh Friday AI deployment, **I want** the setup endpoint to enforce password strength, create my superuser without forcing a password change, and immediately establish a logged-in session, **so that** I land in the system without a second login.

<objective>
后端增强同一 `POST /api/auth/setup/` 端点（不新增端点、不改路由、不回退 Phase 1 门禁）：
1. `SetupInitSerializer` 用 Django `validate_password` 做密码强度校验，`password.min_length` 提升到 8。
2. `SetupInitView.post` 创建 superuser 成功后，复用 `LoginView` 的 cookie-JWT 路径下发 `refresh_token`/`access_token` cookie，并返回 `{access_token, user, must_change_password}`（201）。
3. 不显式置 `must_change_password`（保持默认 False）。
4. 扩展 `test_setup_gate.py` 覆盖 ADMIN-01/02/03 与门禁不回退。

Output: serializers.py（增强）、views.py（增强）、test_setup_gate.py（扩展 + 更新弱口令断言）。
</objective>
