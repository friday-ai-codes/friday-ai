# Phase 62 — UI Design Contract

> 爬取+入库 durable 队列面板（`BatchIngestPanel`）的视觉与交互契约。**Reuse-first 改造既有组件，非 greenfield**。
> Generated by gsd-ui-researcher, verified by gsd-ui-checker. i18n 默认中文（zh-CN）。

---

## Scope

**In scope:** `web/src/components/knowledge/BatchIngestPanel.vue` 改造——从后端恢复的 durable 队列列表、实时状态徽标、行内开始/停止/重试、停止确认、`feishu_not_configured` 引导深链保留。

## Component States

单一卡片容器（沿用 `class="card"` + 头 `px-5 py-3.5 border-b border-border/50`）。爬取入队区在顶部，队列列表在下方。

1. **loading（首次从后端拉队列）** — 列表区 `Skeleton`（`~/components/ui/skeleton`）占位 2–3 行；不显示空态。沿用 `knowledge/index.vue` 的 `Skeleton` 用法。
2. **empty（后端返回空队列）** — `CompactEmptyState`（`~/components/common/CompactEmptyState.vue`），icon `lucide--inbox`，title=`crawlQueue.empty.title`，body=`crawlQueue.empty.body`。
3. **populated（队列列表）** — 每项一行（见 Layout）。运行中项触发轮询。
4. **per-item status** — queued/running/stopped/failed/completed 徽标（上表）。failed 项展开后端 `error`（已脱敏）红字 `text-destructive text-xs`。
5. **error（列表加载失败）** — 整列表区红字 `crawlQueue.loadError` + 「重试加载」按钮（重新 `refetch`）。沿用 `ReconcilePanel` `isError` 范式。
6. **feishu_not_configured（爬取入队时）** — 保留既有黄框引导块（amber-500/30 边框 + `lucide--alert-triangle`）+「去配置飞书应用」按钮 `router.push(settings_deeplink)`。文案接 i18n（见下），行为不回退。

## Layout

```
┌─ card ────────────────────────────────────────────────┐
│ 链接爬取入库 [icon]              副标题(粘贴链接说明)     │  ← 卡片头
├────────────────────────────────────────────────────────┤
│ [ url input  ............................. ] [ 入队 ]   │  ← 入队区
│ (feishu_not_configured 黄框引导 / empty·error 文案)      │
├────────────────────────────────────────────────────────┤
│ 队列（N）                                  [刷新]        │  ← 列表头
│ ┌ item ────────────────────────────────────────────┐   │
│ │ url 集合摘要(truncate)         [状态徽标]          │   │
│ │ 进度 x/y · 入队 13:20 · 更新 13:42                 │   │  ← 时间戳 text-xs muted
│ │ failed: <error 红字>                               │   │
│ │                         [开始] [停止] [重试]        │   │  ← 行内动作
│ └────────────────────────────────────────────────────┘  │
│ … （loading→Skeleton / empty→CompactEmptyState）         │
└──────────────────────────────────────────────────────────┘
```

- 入队区：`type="url"` input（`flex-1 h-9`）+ 主按钮 `Button`「入队」，回车提交（沿用既有 `@keydown.enter`）。
- 列表项：第一行 url 集合摘要（`truncate max-w-[55%]` + `title`）+ 右侧状态徽标；第二行进度 `{done}/{total}` + 入队/更新时间戳；failed 时追加 error 行。
- 行内动作按 status 条件渲染（见 Interaction）。次级按钮 `Button variant="outline" size="sm" class="h-8"`，停止用 destructive 文字色。
- 列表项间 `divide-y divide-border/40`，沿用既有进度列表写法。

## Interaction

真相源 = 后端 DB；**禁止依赖组件内存 `batchId`/`ref`**（移除既有 `batchId`/`runTriple`/`pollStartedAt` 内存态作为列表来源）。

- **enqueue（入队）** — `useMutation` 调入队 action API → 成功 `toast.success(crawlQueue.enqueued)` → `queryClient.invalidateQueries(['crawl-ingest-queue'])` 立即重拉列表。失败 `useErrorHandler`。`feishu_not_configured` 走引导分支（不入队）。
- **refresh-from-backend（恢复 + 轮询）** — `useQuery` queryKey `['crawl-ingest-queue']`，`queryFn` 拉后端队列列表；`refetchInterval`: 列表中存在 `running` 项 → 2000ms，否则 `false`（全部终态停轮）。沿用 `ReconcilePanel` 的 `refetchInterval: q => running ? 2000 : false` 范式。刷新页面/重建容器后由该 query 自动恢复，无需内存态。
- **inline start** — 仅 `queued`/`stopped`/`failed` 项显示「开始」；调开始 action → invalidate 列表。
- **inline stop（破坏性，需确认）** — 仅 `running`/`queued` 项显示「停止」；点击经 `useConfirmDialog().confirm({ title, description, confirmText, variant: 'destructive' })`，确认后调停止 action（→ stopped 终态可重投）。沿用 `ReconcilePanel.runCleanup` 的 confirm 范式 + 全局 `GlobalConfirmDialog`（已挂载于 `App.vue`，无需新增弹窗组件）。
- **inline retry** — 仅 `failed`/`stopped`/`completed` 项显示「重试」；调重试 action（同 idempotency key 重新 defer）→ invalidate 列表。retry 非破坏性，**不**弹确认。
- 动作进行中按钮 `disabled` + spinner（沿用 `icon-[lucide--loader-circle] animate-spin`）。
- 已保留：爬取出的内容回填走既有 resolve/校验链路的部分如仍需要可保留为入队前预处理，但**列表与状态一律以后端为准**。

## Accessibility / Responsive

- 所有图标按钮带可读文案或 `:title`；纯图标删除/动作按钮加 `aria-label`。
- 状态徽标除颜色外**必须带图标+文字**（不靠颜色单独表意）。
- 行内动作 `:disabled` 时降透明度并阻断点击；进行中显式 spinner。
- 容器宽度受 host `max-w-3xl` 约束；列表项 `flex-wrap`，窄屏徽标/动作换行；url 摘要 `truncate` 防溢出。
- 焦点态沿用既有 `focus:ring-1 focus:ring-primary/40`（输入）/ badge `focus:ring-2`。
- 确认弹窗（reka-ui AlertDialog）自带焦点陷阱与 ESC 取消，无需额外处理。
