- NO_GOLD="NO_GOLD"           # gold 为空 → 该 case 此指标不计入平均
- NOT_APPLICABLE="N/A"        # 无预测 → 不计入平均（非满分）
- SEED_MISSING="SEED_MISSING" # impact seed_in_graph=False → 单列，不计 precision
- NODE_NOT_IN_GRAPH="node_not_in_graph"  # trace 端点不在图 → 单列，不计成功率分母

指标口径（固定分母 + 空结果规则，详见 133-RESEARCH「指标集与空结果规则」表，须严格实现）：
- symbol Recall@5：分母 len(expected_symbols)；命中按 uid 集合
- process Recall@3：分母 len(expected_processes)；命中按 process_key 精确
- edge precision/recall：分母分别 = 预测边数 / gold 边数
- impact precision：分母 = 预测受影响数；seed_in_graph=False → SEED_MISSING
- trace：found=True 计成功；reason=no_path 计失败；node_not_in_graph 单列不计分母；found 但路径≠gold 计错误路径
