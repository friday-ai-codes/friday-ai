## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| KEDA 控制面 → Postgres | ScaledObject query 直查 DB 队列深度；DB 凭证必须经 secret 不明文 |
| 多副本 web → Redis channel layer | 多副本必须共享 channel layer，否则 WS 跨副本丢消息 |
| 非 KEDA 集群 → 新模板 | ScaledObject/PDB CRD 未装时 apply 会失败 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-63-04 | Information Disclosure | KEDA ScaledObject | mitigate | TriggerAuthentication + secretTargetRef（DATABASE_URL→connection），绝不在 metadata/values 明文 DB 密码 |
| T-63-05 | Denial of Service（WS 丢失） | 多副本内存 channel layer | mitigate | 双层 fail-closed：settings raise ImproperlyConfigured + helm template fail |
| T-63-06 | Denial of Service（rescue 停摆） | KEDA scale-to-zero | mitigate | minReplicaCount 默认 1（禁 0），保 periodic deferrer 持续驱动 rescue |
| T-63-07 | Availability（非 KEDA 集群破坏） | ScaledObject/PDB 模板 | mitigate | 全 `{{ if .Values.*.enabled }}` 默认 false，默认安装不渲染 |
| T-63-SC | Tampering | npm/pip/cargo installs | accept | 本 plan 不新增任何包（RESEARCH Package Legitimacy Audit：无新增） |
