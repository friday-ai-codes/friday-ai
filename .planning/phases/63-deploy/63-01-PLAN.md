<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| 编排层 → worker/scheduler 进程 | command + FRIDAY_PROCESS_ROLE 决定进程职责；误配 role 会跑错副作用 |
| k8s/compose 滚动更新 → scheduler 单例 | 滚动期双实例会重复跑 cron（重复通知/backfill OOM） |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-63-01 | Tampering（重复副作用） | scheduler-deployment | mitigate | `replicas: 1` 硬编码 + `strategy.type=Recreate`（禁滚动期双实例），flock 保留作同节点兜底 |
| T-63-02 | Denial of Service（在途丢失） | worker SIGKILL | mitigate | terminationGracePeriodSeconds(120) > gracefulTimeout(110) > heartbeat/stalled；超时由 heartbeat-stalled + 周期 rescue 兜底重投 |
| T-63-03 | Tampering（迁移顺序） | compose worker 启动 | mitigate | worker/scheduler 不自 migrate + depends_on postgres healthy；helm 侧 pre-upgrade migration hook 先行 |
| T-63-SC | Tampering | npm/pip/cargo installs | accept | 本 plan 不新增任何包（纯 YAML + 既有 procrastinate 消费，RESEARCH Package Legitimacy Audit：无新增） |
</threat_model>
