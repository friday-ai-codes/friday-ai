<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| serializer→public schema | 运行时输入约束被投影给不受信任的外部 Agent，错误投影可能诱导越权或无效调用。 |
| registry→runtime/build consumers | 单一声明同时驱动 URL 与发布制品，恶意或误配工具名/annotation 会扩大公开能力。 |
| current manifest→compat baseline | 被测输出不能控制验收金标，否则破坏性变化会自证通过。 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-146-01 | Tampering | `registry.py` | mitigate | 名称正则、重复注册、view/serializer/annotation 完整性在 import/build 时 fail-fast，并由独立 URL fixture 对拍。 |
| T-146-02 | Elevation of Privilege | tool annotations | mitigate | annotations 逐工具显式声明；mutation 不得误标 read-only/idempotent，风险升级由 compatibility checker 阻断。 |
| T-146-03 | Information Disclosure | schema/manifest | mitigate | manifest 仅含契约元数据，不含 PAT、凭证、业务 payload、内部 job ID 或堆栈。 |
| T-146-04 | Tampering | compatibility baseline | mitigate | baseline 永不由 generator 写回；测试静态守卫写文件 API 与自引用。 |
| T-146-SC | Tampering | npm/pip/cargo installs | accept | 本计划不新增或升级运行时依赖，使用现有 DRF、jsonschema 与 stdlib SHA-256。 |
</threat_model>
