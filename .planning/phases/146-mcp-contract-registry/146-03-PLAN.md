<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Django response→stdio adapter | 服务端 JSON 可能含业务正文或上游错误，客户端必须按 allowlist 转换。 |
| stdio result→Agent context | structuredContent 会直接进入模型上下文，handoff 正文与敏感错误不得透传。 |
| HTTP error→control flow | Agent 依据机器码决定重试/停止，错误分类必须稳定且不可由中文文案驱动。 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-146-09 | Information Disclosure | stdio error mapping | mitigate | 删除原始 body/exception 回显，只提取 allowlisted 字段并使用稳定本地安全文案。 |
| T-146-10 | Information Disclosure | handoff structuredContent | mitigate | handwritten adapter 仅返回路径/hash/计数/坐标，正文只落 0600 文件与 0700 目录。 |
| T-146-11 | Tampering | outputSchema validation | mitigate | 55-tool representative fixtures 和 Draft 2020-12 validator 阻止伪造或过宽契约。 |
| T-146-12 | Repudiation | run_id propagation | mitigate | 成功与错误 structuredContent 保留安全 run_id，后续请求继续携带 `X-Friday-Run-ID`。 |
| T-146-SC | Tampering | npm/pip/cargo installs | accept | 不新增依赖；schema 测试使用现有 jsonschema，stdio 使用现有 MCP SDK 与 Node built-ins。 |
</threat_model>
