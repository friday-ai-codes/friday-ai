<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| authenticated client→manifest endpoint | PAT 跨 HTTP 边界读取公开契约身份，不能泄露业务数据或凭证。 |
| deployed manifest→local doctor | 远端 catalog 是不受信输入，只用于诊断，不能覆盖 bundled allowlist。 |
| parent repo→mcp publish | npm 子模块发布必须证明 parent 已接纳相同 child SHA 与 compatibility baseline。 |
| CI checkout→contract gate | 缺失 submodule/generated 资产必须被视为配置失败，不能 skip 假绿。 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-146-13 | Spoofing | manifest endpoint | mitigate | 复用 MCP PAT/JWT authentication 和 IsAuthenticated；server version 取 package metadata，hash 取 committed canonical bytes。 |
| T-146-14 | Information Disclosure | manifest logs/doctor | mitigate | 日志与 CLI 仅输出版本、hash、工具名、计数和 token 长度；凭证、正文、异常原文统一禁止。 |
| T-146-15 | Tampering | doctor remote manifest | mitigate | 远端 manifest 只比较不替换 bundled catalog；breaking diff 非零，未知工具仍 fail-closed。 |
| T-146-16 | Tampering | npm publish | mitigate | parent gitlink==child SHA、authoritative baseline/generator、secret scan、version/test/build 全部为发布前硬门。 |
| T-146-17 | Denial of Service | manifest endpoint | accept | 返回 committed 小型静态 manifest，无 DB、LLM、召回或后台任务；沿用现有 API 基础限流边界。 |
| T-146-SC | Tampering | npm/pip/cargo installs | mitigate | 只用 committed lockfiles 和 frozen install；不使用 npm@latest、不新增依赖，并在 publish 前执行 secret scan。 |
</threat_model>
