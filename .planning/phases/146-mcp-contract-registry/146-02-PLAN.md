|---|---|
| registry→generated files | 生成器把服务端声明写入 Python/JSON/TypeScript 多仓制品，部分目标位于 dirty git submodule。 |
| generated endpoint→HTTP | 外部 Agent 提供 tool name，stdio 只能路由到 allowlisted canonical endpoint。 |
| parent repo→mcp submodule | 父仓 gitlink 与 child commit 必须可复核，不能覆盖或遗漏用户未提交 handoff 工作。 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-146-05 | Tampering | generator outputs | mitigate | 内存渲染、确定性 bytes、原子替换、只读 `--check` 和 canonical hash 对拍。 |
| T-146-06 | Elevation of Privilege | stdio tool dispatch | mitigate | 调用前按 generated 55-tool catalog fail-closed，endpoint 不接受任意 tool name 拼接。 |
| T-146-07 | Information Disclosure | generation logs | mitigate | 仅记录路径标识、数量、hash、diff count 与 duration；不记录 schema/description/PAT/异常原文。 |

| T-146-SC | Tampering | npm/pip/cargo installs | accept | 无安装或新依赖；使用当前 lockfile、TypeScript、Vitest 与 Python 依赖。 |
