`class BlueprintConfirmGateAdapter`（依赖 keyword-only 可注入：`lifecycle`、`artifacts`、`fitness_loader`（112-04 的 `acollect_fitness`）、`charter_writer`）：
- `async def open_gate(self, session) -> dict`（与 spec_gate 同形）：
  1. pending 门：`await lifecycle.ahas_open_blocking_threads(artifact, kind=ThreadKind.REPO_CONFIRMATION)` 为 True → 直接返回 `{"event": "awaiting_confirmation", "thread_id": <已有线程>}`（不重复开门）。
  2. 组装 `options` 快照：逐仓 `{repository_id, repository_name, role_suggestion, responsibility, fitness: {verdict, reasons, citations}, current_state_summary, routing_evidence: {total, router_base, charter_match, history_match, router_version, matched_domains, violated_boundaries, history_match_unavailable}}`（来源：112-03 的候选 breakdown + 112-04 的 fitness 聚合 / `escalation` 快照）。快照走「小摘要」纪律：正文类字段截断，明细由 115 按 id 自取。
  3. `await lifecycle.open_thread(artifact, kind=ThreadKind.REPO_CONFIRMATION, blocking=True, question=<中文确认提示>, options=<快照>, initiated_by_user_id=..., return_stage=BlueprintStatus.RESEARCHING)`。
  4. emit `EVENT_BLUEPRINT_CONFIRMATION_OPENED`（payload：`thread_id`/`repo_count`/`unsuitable_count`/`escalated`）。
  5. 返回 `{"event": "awaiting_confirmation", ...}`——**adapter 只返回 dict，stage 转移由 handler 的 StageOutcome 承担**。
- `def build_locked_associations(*, snapshot: list[dict], decisions: dict) -> list[dict]`（**纯函数**）：把快照 + 用户动作结果映射成蓝图 `repo_associations` 条目——写 `role`（direct/indirect）、`responsibility`（block_list 形状）、`fitness`、`routing_evidence`、`decided_by="human"`、`confirmed_at_gate=True`；被 `remove_repo` 的仓**不进** associations（其信息进 boundaries 草案与 `decision_log`）。字段名严格对齐 schema（`blueprint_schema.py:225-318`），不新增 schema 外键。
- `async def alock(self, session, *, acting_user, decisions: dict) -> dict`：
  1. 深拷贝当前 `ArtifactVersion.content` → `content["repo_associations"] = build_locked_associations(...)`；`content["decision_log"]` 追加 `{thread_id, action, repository_id, before, after, decided_at, decided_by}` 逐动作条目（**同 (thread_id, action, repository_id) 已存在则跳过**，幂等重跑不堆积）。
  2. `await artifacts.add_version(artifact, content, produced_by_session_id=..., produced_by_ref="blueprint_confirm_gate")`；捕获 `ArtifactContentInvalid` → 记 `blueprint_confirm_gate_invalid_content`（文本经 `redact_secrets_in_text`）并返回 `awaiting_confirmation`（**fail-closed：内容非法不放行，也不落 failed**）。
  3. `await lifecycle.resolve_thread(thread, ...)` 收尾确认门线程；`await lifecycle.add_reviewer(artifact, acting_user, first_action="repo_confirmation")`（确认者自动进名单，复用 111 upsert）。

  5. emit `EVENT_BLUEPRINT_CONFIRMATION_LOCKED`（payload：`locked_repo_count`/`removed_count`/`decided_by`/`charter_draft_count`）；返回 `{"event": "confirmed", ...}`。
