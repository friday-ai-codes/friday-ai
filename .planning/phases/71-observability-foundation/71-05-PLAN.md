<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| 外部 webhook → InboundWebhookEvent 入库 | 不可信原始 payload/headers 持久化 |
| 超管 → 下钻 API | 跨表读取调用详情/会话原始/召回内容 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-71-05-01 | Information Disclosure | webhook 原始 payload/headers 含签名/密钥落库 | mitigate | `record_inbound_webhook` 入库前 headers 经 `redact_for_ledger`、body 经 `redact_for_ledger`/`redact_secrets_in_text`；守护测试断言落库无明文 |
| T-71-05-02 | Information Disclosure | 下钻回显 token 明文 | mitigate | token_fingerprint 仅 hash（绝不明文，沿用 ledger 契约）；retrieval/tool payload 已在写入时 redact_for_ledger；下钻只读不重拼明文 |
| T-71-05-03 | Elevation of Privilege | 非超管下钻他人会话/调用 | mitigate | 下钻/webhook 视图全 `IsSuperUser` fail-closed |
| T-71-05-04 | Denial of Service | 超大 webhook body 撑爆 TextField | mitigate | record_inbound_webhook 截断 body（如 64KB）+ best-effort 写入（背景派发不阻塞响应） |
| T-71-05-05 | Repudiation | webhook 留痕失败静默丢主流程 | mitigate | best-effort try/except 仅吞留痕异常、不吞 webhook 业务；失败 warning 可见 |
| T-71-05-SC | Tampering | npm/pip/cargo 安装 | accept | 不新增依赖 |

## Redaction 注记
webhook 原始入库必经 `redact_for_ledger`（headers/dict body）/`redact_secrets_in_text`（str body）；下钻数据源（InteractionRun/ToolCallRecord/RetrievalTrace/Message）均为写入时已脱敏的 append-only 行，下钻只读不重拼。新增 `test_inbound_webhook_event.py` 提供 webhook 落库脱敏对称守护；`test_credential_leak_protection.py` 顶层守护保持绿。
