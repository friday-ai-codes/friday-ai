## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client → DRF/ASGI 入口 | 不可信请求头（X-Request-ID/X-Trace-ID）跨界进入 contextvars |
| 入队方 → 后台 worker | initiated_by_user_id 经 payload/job metadata 跨线程/进程传递 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-71-01-01 | Spoofing | request_id/trace_id 取自客户端 header | accept | 仅作关联键、非鉴权凭证；user_id 不取自客户端而由服务端 DRF 认证后 `rebind_user(resolve_user_id(request))` 权威写入（客户端无法伪造归因用户） |
| T-71-01-02 | Information Disclosure | contextvars 注入字段进日志 | mitigate | 只绑定 user_id/request_id/source/trace_id 等非敏感字段；明文 PAT/凭证绝不进 contextvars（沿用 access_tokens/context 契约）；redact_credentials 仍在 renderer 前兜底 |
| T-71-01-03 | Tampering | source 任意字符串污染基数 | mitigate | `LogSource.normalize` 受控枚举，非法值回退 system |
| T-71-01-04 | Information Disclosure | contextvars 泄漏到同 worker 后续请求 | mitigate | 中间件 finally `clear_request_context()`；bind_task_context 退出 clear；测试断言请求后无残留 |
| T-71-01-SC | Tampering | npm/pip/cargo 安装 | accept | 本 plan 不新增依赖（structlog/contextvars 标准库与既有依赖） |
