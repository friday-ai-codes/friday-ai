## Trust Boundaries

|----------|-------------|

| 容器 → server HTTP 工具面 | 容器持 task token 回调，认证/授权由服务端裁决 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-103-01 | Information Disclosure | mint_task_token / dispatch 链 | mitigate | 明文只在 dispatch 内存；DB 只存 sha256；日志只记 has_user_token=bool；落库泄漏扫描测试（Task 3） |
| T-103-02 | Elevation of Privilege | 泄漏的 task token 被长期滥用 | mitigate | expires_at=timeout+10min 短 TTL + 终态幂等吊销（Task 3）；认证复用 is_valid 天然拒过期/吊销 |
| T-103-03 | Spoofing | 伪造 session_id 吊销他人 token | accept | 吊销入口仅服务端内部调用（callbacks/consumers），无外部可达面；吊销本身是失效操作，无提权价值 |
| T-103-04 | Repudiation | token 铸造/吊销不可归因 | mitigate | task_token_minted/revoked 结构化事件（user_id/session_id/category=caller） |
| T-103-SC | Tampering | 依赖安装 | accept | 本 plan 零新增第三方依赖（纯存量栈） |
