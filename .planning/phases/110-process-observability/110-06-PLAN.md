    新建 `web/src/components/chat/OrchestrationStageTimeline.vue`（`<script setup lang="ts">`，Composition API）。

    **Props**：`sessionId: string`（必填）。**不接受任何后端自由文本作为渲染入参。**

    **数据来源**：`useChatStore()` 取 `orchestrationSessions[props.sessionId]` 与 `orchestrationRuntimeActive`，喂给 `buildOrchestrationTimeline`。整个 computed 包 `try/catch`，异常时返回 `null` ⇒ 整块不渲染（观测代码绝不反噬业务：编排跑通比进度可见重要得多）。

    **渲染条件（§A.5，三条同时成立）**：
    1. `props.sessionId` 非空；
    2. `orchestrationSessions[sessionId]` 存在；
    3. 该桶至少有一条已知事实（`events.length > 0` 或 `snapshot` 非 null）。
    任一不成立 ⇒ `v-if` 整块不渲染。🔴 **不渲染一个全 `unknown` 的空壳** —— 那是在告诉用户「我们丢了东西」，而实际上这条消息本来就从没有过进度信息（§E.3 末行）。不抛错、不打 warn。

    **DOM（§A.6 逐层，逐字沿用既有 token）**：

    ```
    div.card.mt-2.animate-fade-in   role="group" aria-label="方案编排进度" data-test="orchestration-stage-timeline"
    ├─ header.px-4.py-3.border-b.border-border/50.flex.items-center.gap-2
    │   ├─ span.icon-[lucide--workflow].text-primary
    │   ├─ span.text-sm.font-semibold          {{ view.title }}
    │   ├─ span.text-[10px].text-muted-foreground.ml-auto   {{ view.doneCount }}/{{ view.totalCount }} 步
    │   └─ button（原生 button，type="button"）
    │        :aria-expanded="String(!collapsed)"  :aria-controls="bodyId"
    │        :aria-label="collapsed ? '展开编排进度' : '收起编排进度'"
    │        └─ span.icon-[lucide--chevron-right]  :class="collapsed ? '' : 'rotate-90'"
    ├─ p.sr-only  role="status" aria-live="polite"   {{ view.liveMessage }}
    └─ div :id="bodyId" v-if="!collapsed" class="px-4 pb-3 pt-1"
        └─ <SubStepTimeline :steps="view.steps" :interactive="false" />
    ```

    - 🔴 **live region 的内容只来自 `view.liveMessage`**（110-05 已保证它不含 `{done}/{total}`）。不要在模板里另外拼计数进去。
    - 头部的 `{n}/{m} 步` **用纯文本计数、不用 `Badge`**（Badge 的垂直尺寸在 11px 行里过重，沿用 `DeepAnalysisCard:56` 的惯例）。

    **终态收敛（§A.6 规则表）**：

    - `collapsed` 为组件本地 `ref`，初值 `false`。
    - `watch(() => view.phase)`：首次变为 `'done'` 时把 `collapsed` 置 `true`，并置一个一次性 flag。
      🔴 **只触发一次**；用户手动展开后**不再被自动折叠回去**（进度是过程信息，完成后默认让位给结果，但用户想回看时不能被抢走）。
    - `phase === 'failed'` ⇒ **不自动折叠**（保持展开，红步与原因行可见）。
    - `sessionId` 变化 ⇒ 重置 `collapsed` 与一次性 flag（与 `expandedBreakdowns` / `expandedTools` 的既有惯例一致）。
    - 🔴 **状态不持久化**：不写 store、不入 localStorage。
    - 🔴 **自动折叠不移动焦点、不 autofocus**；折叠按钮不被 `v-if` 卸载（只有正文区被卸载），因此用户焦点若在按钮上，折叠后焦点**留在原按钮**。

    **文案**：全部取 `COPY` 常量（复用 110-05 导出的那份，避免两处各写一份中文串漂移）。硬编码中文常量惯例，**不接 vue-i18n**（家族现状；107/109 两份 UI-SPEC 已就同一问题作出同样裁定）。
