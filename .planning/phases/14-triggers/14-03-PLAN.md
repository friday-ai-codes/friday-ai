## 规划定案（供 verify 对照）

- **OQ-3（规划定案）**：文件级降级封顶 `MAX_FILE_LEVEL_EDGES_PER_FILE = 20`，常量起步不配置化；超出只记 metadata（unresolved 形态）不建边。
- **畸形 diff 防线（locked）**：unidiff 解析失败 → warning + 该文件 `parse_failed=True`（files JSON 记录），归档照常落库（"只归档不解析"），对齐与向量化跳过该文件；整批绝不 raise。
- **生成文件语义（locked）**：is_generated 只跳过"管线重活"（向量化 + 符号对齐），归档原文不跳。
- **对齐命名空间（Pitfall 7）**：Symbol/ChunkRegistry 查询恒 `branch_name=""`（base）；新增文件在 base 无 chunk 属预期 unresolved。
- **常量表**：`GENERATED_PATH_PATTERNS` / `GENERATED_CONTENT_MARKERS` / `SINGLE_FILE_GENERATED_LINE_THRESHOLD = 3000` / `MAX_DIFF_CHUNKS = 200` / `MAX_ARCHIVE_RAW_BYTES = 8 * 1024 * 1024` / `MAX_CONTENT_BYTES = 256 * 1024` / `MAX_FILE_LEVEL_EDGES_PER_FILE = 20`，全部置于 diff_archive.py 顶部。
