<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| 客户端 → REST upsert | 认证客户端提交三元组触发 upsert（IsAuthenticated 守卫，入参校验） |
| 飞书 webhook → 后台 upsert | webhook 仅投三元组 ID，正文经 plugin token 后台权威回源（不信任 payload 业务字段为权威） |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-28-08 | Elevation of Privilege | delivery REST 端点 | mitigate | `IsAuthenticated` 守卫；只读端点不旁路 fetch，写端点经单一 upsert（无直接 ORM 写） |
| T-28-09 | Tampering | INV-6 旁路写表 | mitigate | grep 守护测试断言 WorkItem 落库仅经 WorkItemService，CI 拦截旁路 .objects.create/.save |
| T-28-10 | Spoofing | 伪造 webhook payload | mitigate | 复用既有 webhook token 校验（feishu/views）；delivery upsert 只取三元组、业务字段经 plugin token 权威回源，不信任 payload 值 |
| T-28-11 | Denial of Service | webhook 后台 upsert | mitigate | upsert 经 run_in_background 脱离请求生命周期，主响应不被阻塞；upsert 内部 fail-soft（28-02） |
</threat_model>
