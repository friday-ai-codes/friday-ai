## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| 客户端 ↔ `CodingPlan.provenance` | 来源标志决定「是否可信」，若客户端可写则 RELY-01 被绕过 |
| MCP 执行链（裸 ORM） ↔ chat 模型字段形状 | 桥接不经 service，字段必填性变化会直接崩链 |
| 存量数据 ↔ 新列语义 | 迁移 default 的取值决定历史数据被标为可信还是不可信 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-109-02-01 | Spoofing | `CodingPlanSerializer` / `ConversationRuntimeCodingPlanSerializer` | mitigate | `provenance` 声明为 `read_only=True`；只有投影 service 写 `orchestrated`，其余路径恒走 DB default `draft`；Task 3 有 read-only 断言 |
| T-109-02-02 | Repudiation | 迁移 default 取值 | mitigate | `default="draft"` 而非 `orchestrated`，不把存量徒手产物谎报为可信；显式禁止 data migration |
| T-109-02-03 | Denial of Service | `mcp_tools/execution_service.py::_create_bridge_session` | mitigate | 新列 `default` / `null=True`，Task 2 用直接调用 `_create_bridge_session` 的用例断言不抛 |

| T-109-02-SC | Tampering | npm/pip/cargo installs | accept | 本 plan 零新增依赖 |
</threat_model>
