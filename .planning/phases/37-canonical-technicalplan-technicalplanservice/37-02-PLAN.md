`PlanRef` dataclass（统一来源标识，Claude's Discretion 精确形态）：`origin: str`（chat|mcp|workflow|orchestration）+ `source_key: str`（chat/mcp = 旧记录 id 字符串；workflow = `f"workflow:{execution_id}:{node_id}"`）。提供 `@classmethod` 便捷构造（`for_chat(coding_plan_id)` / `for_mcp(plan_id)` / `for_workflow(execution_id, node_id)`），workflow 的 source_key 规范化为 `external_ref` 串。

本地 content_hash helper（**不 import knowledge**，INV-3 边界；对齐 document_service `_content_hash` 语义）：
```
def _content_hash(content: dict) -> str:
    canonical = json.dumps(content, sort_keys=True, ensure_ascii=False, separators=(",", ":"))
    return hashlib.sha256(canonical.encode("utf-8")).hexdigest()
```

content 校验（仅校验用 import，per CONTEXT「service 可 import workflows schema 作 validation」）：从 `workflows.schemas.technical_plan import validate_technical_plan`；校验失败 → `raise PlanContentInvalid(msg)`（自定义异常）。注：§7 MergedPlan 含 title/summary/execution_plan，满足 validate_technical_plan 必填；完整 PlanValidator 是 Phase 40，本 phase 只对齐 execution_plan 子集。

`TechnicalPlanService` 方法（async 公开 API，内部 `sync_to_async` 包同步 ORM 段，写操作用 `transaction.atomic`）：

- `async create_from(self, origin, payload, *, work_item=None) -> TechnicalPlan`：校验 `origin in TechnicalPlanOrigin.values`（非法 raise ValueError）；取 `content = payload["content"]`（或 payload 本身即 content——按 CONTEXT「payload 的 content 经校验」，约定 payload 是 dict 且含 content 键，缺则 raise）；`validate_technical_plan(content)`；`transaction.atomic`：建 `TechnicalPlan(work_item=work_item, origin=origin, status=draft)` → 建 `PlanVersion(plan=plan, version=1, content=content, content_hash=_content_hash(content))` → `plan.current_version = v1; plan.save(update_fields=["current_version", "updated_at"])`。INV-2：origin=chat 且 work_item=None 合法（不校验 work_item 必填）。
- `async add_version(self, plan, content) -> PlanVersion`：`validate_technical_plan(content)`；`new_hash = _content_hash(content)`；取 `current = plan.current_version`；若 `current and current.content_hash == new_hash` → **复用不翻版本**，返回 current（对齐 v0.3/v0.6「hash 相等绝不产生新版本」铁律）；否则 `transaction.atomic`：`next_version = (current.version + 1) if current else 1`，建 `PlanVersion(plan=plan, version=next_version, supersedes=current, content=content, content_hash=new_hash)`，更新 `plan.current_version` → 返回新版本。
- `async archive(self, plan) -> TechnicalPlan`：`plan.status = ARCHIVED; plan.save(update_fields=["status", "updated_at"])`；**不**触碰任何旧表 / 不删 PlanVersion（DOMAIN §5.4 归档不级联）。返回 plan。

- `async link(self, old_record, canonical) -> None`：按 old_record 类型回填软链——`chat.CodingPlan` / `mcp_tools.McpWorkItemTechnicalPlan` 实例 → set `old_record.canonical_plan_id = canonical.id; await old_record.asave(update_fields=["canonical_plan_id", "updated_at"])`；workflow（传 external_ref 字符串或 PlanRef）→ `PlanExternalRef.objects.update_or_create(external_ref=ref, defaults={"canonical": canonical})`（幂等）。类型判定用 `isinstance` + 鸭子判定（避免硬 import 顺序问题，chat/mcp 模型 lazy import 防循环）。

- `async resolve(self, ref: PlanRef) -> TechnicalPlan`：按 §5.4：
  1. 取旧记录 + 已有 canonical 软链：chat → `CodingPlan.objects.aget(id=source_key)` 读其 `canonical_plan_id`；mcp → `McpWorkItemTechnicalPlan.objects.aget(id=source_key)`；workflow → `PlanExternalRef.objects.filter(external_ref=source_key)` 命中取 `canonical`。
  2. 软链命中（canonical_plan_id 非空 / PlanExternalRef 存在）→ `return TechnicalPlan.objects.aget(id=canonical_id)`（**读 canonical**，冲突以 canonical 为准）。
  3. 无 canonical 但旧记录存在且完整 → **lazy 建 canonical**：从旧记录 payload 取材构造 content（chat：`{"title": title, "summary": tech_plan[:200], "execution_plan": [...由 affected_files/recommended_repository_ids 派生最小合法 execution_plan...]}`；mcp：复用 `plan_body`/`repository_tasks` 映射成 content；workflow：本 phase resolve 对 workflow 无旧表可取材 → 见下注）→ `canonical = await self.create_from(origin=ref.origin, payload={"content": content}, work_item=None)` → `await self.link(old_record_or_ref, canonical)` 回填 → 返回 canonical。
  4. 找不到旧记录 → `raise PlanNotFound(ref)`。
  - **取材最小化注**：本 plan 的 lazy 取材建「最小合法 content」（满足 validate_technical_plan：title/summary/execution_plan 非空即可），真实 MergedPlan 融合是 Phase 40；37-03 会把三路径 lazy 取材做扎实 + 幂等再 resolve 守护。workflow 无旧独立表，resolve 仅在已 link（PlanExternalRef 存在）时命中 canonical，否则 PlanNotFound（eager 投影由调用方先 create_from+link，DOMAIN §5.3）。
  - chat/mcp 模型用函数内 lazy import（`from chat.models import CodingPlan`）防循环依赖。
