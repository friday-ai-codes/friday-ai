    新建 `server/services/sensitive_detect.py`，zh-CN docstring 声明隐私边界（绝不记录/泄漏密钥本体）。实现：
    1. `@dataclass(frozen=True) SuggestionCandidate`：path / severity / detector / reason（均脱敏）。
    2. 独立有界遍历 `_walk_candidate_files(repo_path) -> list[tuple[abs_path, rel_path]]`：os.walk 跳过结构性目录（.git/、node_modules/、以及 BUILTIN_GLOBAL_DEFAULTS 中 rule_type=="dir" 的目录名），跳过单文件超过大小上限（如 1 MiB）与二进制（含 NUL 字节嗅探），rel_path 经 `normalize_rel_path` 归一；**不**应用扩展名白名单、**不**用 ExclusionMatcher 过滤候选（被排除的恰是要识别的敏感文件）。
    3. 文件名启发式 `_filename_severity(rel_path) -> str | None`：用 `BUILTIN_GLOBAL_DEFAULTS` 构造的判定复用其 glob/basename 语义判断文件名是否敏感（可用 `services.exclusion.ExclusionMatcher` 仅承载 BUILTIN_GLOBAL_DEFAULTS 的 glob 规则做命中判断，命中返回 config_review 基线 severity）。
    4. 内容扫描 `_scan_content(text) -> list[tuple[severity, reason]]`：编译常量正则集 `_SECRET_PATTERNS`，覆盖：私钥头 `-----BEGIN [A-Z ]*PRIVATE KEY-----`、AWS Access Key `AKIA[0-9A-Z]{16}`、AWS secret 赋值 `AWS_SECRET_ACCESS_KEY\s*[:=]`、GitHub token `gh[pousr]_[A-Za-z0-9]{20,}`、Slack token `xox[baprs]-[A-Za-z0-9-]{10,}`、通用赋值 `(?i)(api[_-]?key|secret|password|token)\s*[:=]\s*\S{8,}`、高熵 base64/hex 串（长度 ≥40 且 Shannon 熵 ≥ 阈值，辅以非注释行判定）。命中即 severity=real_secret（除高熵单独命中且无明确密钥关键字时降为 likely_sensitive）。reason 形如「检测到 RSA 私钥块（行 N）」「检测到 AWS Access Key 格式（行 N）」「检测到疑似密钥赋值 KEY=…（行 N）」——**只记类型与行号**，绝不回填命中文本/密钥值；提供 `_redact_reason` 保证不含原值。
    5. severity 合并：同文件多命中取最高（real_secret > likely_sensitive > config_review）；detector 选 content（有内容命中）否则 heuristic。
    6. `detect_sensitive_files(repository_id: str, repo_path: str) -> int` async 入口：遍历候选 → 逐文件 try/except 隔离（单文件读失败/解码失败不致命）→ 收集 `SuggestionCandidate` → 调 `_upsert_suggestion`，返回入库/更新条数。
    7. `_upsert_suggestion(repository_id, candidate)` async：ORM 经 `aupdate_or_create(repository_id, path=...)`；命中 dismissed 行时，仅当新 severity==real_secret 且旧 severity!=real_secret 才把 status 重置回 pending（升级打扰），否则保留 dismissed 不复扰；其余按 severity/detector/reason 更新。
    8. 审计：`logger.info("sensitive.detected", repository_id=..., count=..., real_secret=..., likely_sensitive=...)` —— 仅计数/severity，无路径敏感内容、无密钥本体。
    所有正则用 `re.compile` 模块级常量；遵守 ruff line-length 100、zh-CN 注释。
