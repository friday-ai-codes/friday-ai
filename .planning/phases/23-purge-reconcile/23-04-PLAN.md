实现对账/清理前端（EXCL-06）：在仓库详情页（`pages/repositories/[id]/index.vue`）的 Phase 22 排除规则面板旁挂 `ReconcilePanel.vue`，展示"当前排除规则 vs 已索引内容"差异（命中文件数 + 列表），提供"一键清理（普通）"与显式"敏感清理"两入口（§9.2 不混一个按钮），敏感清理需更强确认（措辞如实：不可逆 + 不承诺 git/备份物理消失），清理派发后刷新对账使差异归零。对齐 23-02 后端契约（`GET/POST /api/repositories/<id>/reconcile/`，`ReconcileReport{indexed_count, excluded_paths, match_count, suggested_mode}`，POST 返回 202 + `{mode, match_count, dispatched}` 后台执行）。复用既有 `web/src/api/` 类型化 client + TanStack Query + reka-ui + `useConfirmDialog` + vue-i18n（默认中文）。
