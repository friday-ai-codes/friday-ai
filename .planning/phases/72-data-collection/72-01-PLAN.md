## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client → DRF/ASGI/WS 入口 | 不可信请求（path/header/body）跨界，指标行从中派生 route/source |
| 写入热路径 → metric_sink 队列 | 高频请求经内存队列异步落库（背压：满则丢弃计数） |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-72-01-01 | Information Disclosure | labels jsonb 写入用户输入原文 | mitigate | `_ALLOWED_LABEL_KEYS` 受控枚举白名单过滤；route 取 URL pattern 去 path 参数/query；绝不把 query 文本/body 落 labels（基数失控 + 泄漏，§A.4） |
| T-72-01-02 | Information Disclosure | 凭证/token 经 RequestMetric 泄漏 | mitigate | RequestMetric 仅记元数据（source/route/status/duration/user_id），不落 raw body/headers；user_id 取服务端 contextvars 非客户端 header |
| T-72-01-03 | Denial of Service | 高频请求 + 同步 ORM 拖垮热路径 | mitigate | enqueue 纯内存非 ORM，落库交 daemon worker 批量；队列 `maxlen=5000` 满则丢弃计数（背压），绝不阻塞请求 |
| T-72-01-04 | Tampering | source 任意字符串污染基数 | mitigate | source 取 Phase 71 `LogSource.normalize` 受控枚举或各入口硬编码常量 |
| T-72-01-05 | Spoofing | 客户端伪造 user 归因 | accept | user_id 取服务端 DRF 认证后 contextvars（71 已 rebind），不取客户端 header |
| T-72-01-SC | Tampering | npm/pip/cargo 安装 | accept | 本 plan 不新增第三方依赖（Django ORM + 标准库 deque/threading + 既有 structlog） |
