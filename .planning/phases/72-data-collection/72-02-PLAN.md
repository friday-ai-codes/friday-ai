## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| LLM provider 上游 → Runner | 上游响应/异常文本（可能含敏感）跨界，解析 status_code 写指标 |
| caller → call_source contextvar | 调用方声明 call_source，chokepoint 读取（受控枚举） |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-72-02-01 | Information Disclosure | 上游响应体/异常文本经 ModelUsageRecord 泄漏 | mitigate | 仅写 status_code(int)/failure_type(枚举标签)，**绝不**把上游 body/异常完整文本入库；如需记文本先 `redact_secrets_in_text`（_parse_upstream_status 只取数值码） |
| T-72-02-02 | Information Disclosure | prompt/completion 明文经 ledger 泄漏 | mitigate | arecord_llm_usage 只记 token 计数 + 元数据，不落 prompt/completion 文本（留痕内容走 RetrievalTrace/Interaction Ledger 既有脱敏路径） |
| T-72-02-03 | Tampering | call_source 任意字符串污染基数 | mitigate | `CallSource.normalize` 受控枚举（22 值）+ 非法值回退 default |
| T-72-02-04 | Spoofing | user 归因伪造 | accept | user_id 取服务端 Phase 71 contextvars，不取客户端输入 |
| T-72-02-05 | Denial of Service | 观测 await 阻塞 LLM 流 | mitigate | arecord_llm_usage best-effort + 不在 astream 内逐 chunk 写（仅 turn 收尾/异常点一次）；写库经 sync_to_async 不阻塞事件循环 |
| T-72-02-SC | Tampering | npm/pip/cargo 安装 | accept | 本 plan 不新增依赖（复用 structlog/contextvars/既有 langchain） |
