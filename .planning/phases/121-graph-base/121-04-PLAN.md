实现 `def detect_edge_build_in_flight(repository_id: str, branch: str) -> tuple[bool, str]`，返回 `(是否在途, 原因短码)`；在途 ⇒ 上层在图元数据打 `partial_edges=True` 且 `partial_reason=<原因短码>`。

超时兜底：`timeout_min = getattr(settings, "GRAPH_BUILD_ORPHAN_TIMEOUT_MINUTES", 30)`，`cutoff = timezone.now() - timedelta(minutes=timeout_min)`。⛔ **不新增配置项**——复用既有语义（Pitfall 5），注释写明理由。

判定顺序与判据：
**轨 B（Symbol/CallEdge 抽取）** —— 取 `Repository.objects.filter(id=...).values_list("graph_build_status", "index_status").first()`。若 `graph_build_status == RepositoryGraphStatus.RUNNING` **且** 存在 `GraphBuildHistory.objects.filter(repository_id=..., status=GraphBuildHistoryStatus.RUNNING, started_at__gte=cutoff).exists()` → 返回 `(True, "symbol_extraction_running")`。注意 `RepositoryGraphStatus` **没有 PENDING**，所以这条轨不存在「默认值长鸣」问题。若 `index_status == IndexStatus.INDEXING` → 返回 `(True, "indexing")`。
**轨 A（ChunkEdge 构建）** —— 取最近一条 `IndexHistory.objects.filter(repository_id=...).values_list("graph_build_status", "status", "started_at").first()`。🚨 D-06-3：`IndexHistory.graph_build_status` 的**模型默认值就是 `PENDING`**，且只有走 `enqueue_edge_build_for_history` 才推进（`history_id is None` 直接透传、`ENABLE_CODEGRAPH=False` 或 `auto_build_graph_enabled=False` 同样不推进）。因此判在途必须**三条同时成立**：`graph_build_status ∈ {PENDING, RUNNING}` **且** `IndexHistory.status ∈ {PENDING, RUNNING}`（该行自身也在跑）**且** `started_at is not None and started_at >= cutoff`（未超时）。满足则返回 `(True, f"chunk_edge_build_{graph_build_status}")`。
**明确不在途**：`GraphBuildStatus.SKIPPED`（空 dirty 集的正常终态）、`IndexHistory.status` 已终态（COMPLETED/FAILED/CANCELLED）、`started_at` 超过 cutoff 的 RUNNING 孤儿、无任何 history 行。全部落到默认返回 `(False, "")`。

函数 docstring 写明设计意图：**无法确证在途时不打标记**——宁可不报也不长鸣；降级标记一旦长鸣就等于没有。
