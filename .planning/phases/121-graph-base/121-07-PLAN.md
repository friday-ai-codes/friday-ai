实现 `class GraphService`：
`__init__(self, max_bytes: int, max_graph_bytes: int)` —— 入参 ≤ 0 抛 `ValueError`（照 `volar_pool.py` L58–61）；状态：`self._cache: OrderedDict[tuple[str, str], _Entry]`、`self._total_bytes: int = 0`、`self._lock = threading.RLock()`（只保护 map 本身）、`self._inflight: dict[tuple[str, str], Any] = {}`（占位，Plan 121-08 填）。缓存键 = `(repository_id, branch_name)` 二元组，`branch_name` 沿用既有模型语义（`""` = 基线分支），**不做归一化别名**。
`_put(self, key, entry) -> None`（调用方须已持锁）：写入/覆盖时先减去旧条目字节，再加新条目，`move_to_end`，然后调 `_evict_until_within_budget()`。
`_evict_until_within_budget(self) -> None`（调用方须已持锁，docstring 明写这条前置条件）：`while self._total_bytes > self._max_bytes and self._cache:` → `key, entry = self._cache.popitem(last=False)`（LRU 端）→ `self._total_bytes -= entry.estimated_bytes` → 发 `logger.info(_EVENT_CACHE_EVICTED, component="code_graph", category="sampling", repository_id=key[0], branch=key[1], evicted_bytes=..., total_bytes=..., cache_size=..., reason="budget_exceeded")`（低频事件，INFO 可接受）。
`_get_entry(self, key) -> _Entry | None`（调用方须已持锁）：命中则 `move_to_end` 并发 `logger.debug(_EVENT_CACHE_HIT, ...)`（🚨 高频，必须 DEBUG，规范禁止 INFO 刷屏）。
`stats(self) -> dict`：返回 `{"entries": ..., "total_bytes": ..., "max_bytes": ...}`，供诊断与测试断言。

⛔ 本 task 的所有方法均为**同步**方法，不含任何 `await`——「持锁」与「await」在物理上不可能重叠（Pitfall 7）。async 外壳由 Plan 121-08 交付。
