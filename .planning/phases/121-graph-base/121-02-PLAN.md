定义 `@dataclass(frozen=True, slots=True) class ChunkEvidence`：`source_chunk_id: str`、`target_chunk_id: str`、`edge_type: str`、`weight: float`、`target_repository_id: str | None`。docstring 写明它是 ChunkEdge 的**旁挂证据面**，`chunk` 与 `symbol` 是不同粒度、一个 chunk 常含多个 Symbol，展开成符号级会 k² 笛卡尔爆炸（Pitfall 2），因此**绝不写进 MultiDiGraph 的边集**。

定义 `@dataclass(frozen=True, slots=True) class GraphMeta`：
`repository_id: str`、`branch: str`、`node_count: int`、`edge_count: int`、`estimated_bytes: int`、`resolution_rate: float`、`low_resolution: bool`、`partial_edges: bool`、`partial_reason: str`（在途原因，非在途为空串）、`degraded: str`（`""` 或 `"on_demand_subgraph"`）、`cross_repo_unresolved_count: int`、`cross_repo_branch_unfiltered: bool`、`excluded_file_count: int`、`built_signature: str`、`built_at: datetime`。
每个「标记类」字段上方写一行注释说明上层工具**必须透出**它（`partial_edges` / `degraded` / `low_resolution` / `cross_repo_unresolved_count` 四项）。`cross_repo_branch_unfiltered` 注释写明成因：`ApiCallSite` 没有 `branch_name` 字段，跨仓边无法按分支过滤，这是必须如实声明的语义缺口。

定义 `@dataclass(frozen=True, slots=True) class CodeGraph`：`meta: GraphMeta`、`graph: nx.MultiDiGraph`（TYPE_CHECKING 下的字符串注解）、`chunk_evidence: Mapping[str, tuple[ChunkEvidence, ...]]`（键 = `symbol_id`）。
docstring 写明：图对象是 **`MultiDiGraph` 而非 `DiGraph`**（D-06-1；实测 `DiGraph` 对同一符号对的第二条边是静默覆盖，会让四档边契约失效；代价 +224 字节/边 / +44% 内存，已接受）；节点属性恒为 5 个（`name` / `symbol_type` / `file_path` / `start_line` / `end_line`），边属性恒为 3 个（`kind` / `confidence` / `line_number`），**唯一例外**是 `cross_repo` 边额外带 `match_confidence`（该档边数量在千级，第 4 属性的阶跃成本可忽略）。
