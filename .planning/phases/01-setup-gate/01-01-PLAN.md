<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| 互联网 → POST /api/auth/setup/ | 任何人可发起 POST 请求（公网暴露） |
| 并发请求 → DB 写入 | 两个并发请求同时通过 permission check 进入 SetupInitView |
| Status 接口 → 响应体 | GET 接口返回内容不得泄露用户标识信息 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-1-01 | Elevation of Privilege | SetupInitView — 已初始化实例被外部重调 POST /setup/ | mitigate | SetupNotInitialized permission class：存在任意 is_superuser=True 用户即返回 403，与调用者身份无关（per D-B3 fail-closed 决策） |
| T-1-02 | Tampering | SetupInitView — 并发请求竞态创建第二个 superuser | mitigate | transaction.atomic() + 事务内 double-check（per D-B2）；IntegrityError 捕获（username UNIQUE 约束）作最终兜底；SQLite 依赖 WAL 写锁串行化，Postgres 依赖 READ COMMITTED 事务 |
| T-1-03 | Information Disclosure | SetupStatusView 响应体泄露用户信息 | mitigate | 响应仅含 {needs_setup: bool, is_initialized: bool}，不含用户名、数量或任何标识符（per D-A 响应体约束） |
| T-1-SC | Tampering | 无新包安装 | accept | Phase 1 无新外部依赖，全部使用已在 pyproject.toml 中的包 |
