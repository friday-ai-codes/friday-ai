## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| IDE MCP client → Django MCP API | 未可信 question、answer、仓库/项目标识、token 计数与 client 元数据进入认证写接口 |
| MCP view → CaptureService | API 层必须把正文交给唯一脱敏 writer，不能旁路 ORM 或 Memory |
| MCP lifecycle → Interaction Ledger | 调用审计可保留 redacted client 元数据，但不得替代 Capture/RAG 正文 |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-142-01 | Spoofing | report_session_knowledge endpoint | mitigate | 401 契约锁定 McpToolView 的 PAT/JWT + IsAuthenticated |
| T-142-02 | Information Disclosure | Capture 与 ToolCallRecord | mitigate | MCP 路径密钥脱敏测试；不记录 structlog 正文；审计走既有 redact_for_ledger |
| T-142-03 | Elevation of Privilege | repository/project FK | mitigate | 未授权只影响 FK/reason，不影响独立 Capture；测试覆盖 repo_unauthorized |
| T-142-05 | Tampering | 幂等重试 | mitigate | 测试锁定用户/session/question_hash 三元组 first-write-wins |
| T-142-06 | Tampering | accepted 响应 | mitigate | accepted=true 必须由数据库中的 capture_id 行证明 |
| T-142-07 | Elevation of Privilege | report_project_knowledge | mitigate | 旧工具全文件回归与新工具零 ProjectMemory 断言 |
