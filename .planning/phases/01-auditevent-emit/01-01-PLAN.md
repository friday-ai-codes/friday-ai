**2. AuditEvent 模型** (`server/audit/models.py`)：

字段规格（per AUDIT-01）：

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | `UUIDField(primary_key=True, default=uuid.uuid4, editable=False)` | 主键，沿用 interactions 模式 |
| `event_id` | `UUIDField(default=uuid.uuid4, unique=True, db_index=True)` | 对外暴露的 trace id，与内部 pk 解耦 |
| `actor_type` | `CharField(max_length=20, choices=ActorType.choices)` | `user` / `pat` / `system` |
| `actor_id` | `CharField(max_length=128, db_index=True)` | 用户 ID / PAT fingerprint / "system" |
| `actor_display` | `CharField(max_length=255, blank=True, default="")` | 冗余用户名/描述，便于 admin 展示 |
| `action` | `CharField(max_length=64, db_index=True)` | 动作标识，如 `user.login` / `credential.create` / `exclusion_rule.delete` |
| `target_type` | `CharField(max_length=64, db_index=True)` | 目标对象类型，如 `User` / `ProviderCredential` / `RepoExclusionRule` |
| `target_id` | `CharField(max_length=255, blank=True, default="")` | 目标对象 PK 或标识 |
| `before` | `JSONField(default=dict, blank=True)` | 变更前快照（无变更场景为空 dict） |
| `after` | `JSONField(default=dict, blank=True)` | 变更后快照（无变更场景为空 dict） |

| `ip_address` | `GenericIPAddressField(null=True, blank=True)` | 请求来源 IP |
| `extra` | `JSONField(default=dict, blank=True)` | 扩展元数据（如 user_agent、reason 等） |
| `created_at` | `DateTimeField(auto_now_add=True, db_index=True)` | 事件时间戳 |

`ActorType` 用 `TextChoices`：`USER = "user"` / `PAT = "pat"` / `SYSTEM = "system"`。

Meta：
- `db_table = "audit_events"`
- `ordering = ["-created_at"]`
- 索引：`["action", "-created_at"]`、`["actor_type", "actor_id", "-created_at"]`、`["target_type", "target_id"]`

**append-only 守护（per AUDIT-04）**：覆写 `save()` 和 `delete()` 方法——当 `self.pk` 已存在（非首次 save）时 raise `ValueError("AuditEvent is append-only")`；`delete()` 直接 raise `ValueError("AuditEvent cannot be deleted")`。这是应用层防护，DB 层再加一道：

```python
# 应用层：禁止更新和删除
def save(self, *args, **kwargs):
    if self.pk and not self._state.adding:
        raise ValueError("AuditEvent is append-only; updates are not permitted.")
    super().save(*args, **kwargs)

def delete(self, *args, **kwargs):
    raise ValueError("AuditEvent cannot be deleted; it is append-only.")
```
