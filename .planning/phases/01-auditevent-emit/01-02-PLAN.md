**1. contextvars 模块** (`server/audit/context.py`)：

```python
"""审计 actor 上下文管理 —— 基于 contextvars 在请求生命周期内传递 actor 信息。

使用 Python 标准库 contextvars（线程/协程安全），由中间件在请求进入时设置、
请求结束时清理。emit_audit_event() 从 contextvars 读取当前 actor。
"""
import contextvars
from dataclasses import dataclass

@dataclass(frozen=True)
class AuditActor:
    actor_type: str      # "user" / "pat" / "system"
    actor_id: str        # user PK / PAT fingerprint / "system"
    actor_display: str   # 冗余展示名
    ip_address: str | None = None
    request_id: str = ""

_current_actor: contextvars.ContextVar[AuditActor | None] = contextvars.ContextVar(
    "audit_current_actor", default=None
)

def set_current_actor(actor: AuditActor | None) -> contextvars.Token:
    return _current_actor.set(actor)

def get_current_actor() -> AuditActor:
    return _current_actor.get() or AuditActor(actor_type="system", actor_id="system")

def reset_current_actor(token: contextvars.Token) -> None:
    _current_actor.reset(token)
```

**2. ASGI 中间件** (`server/audit/middleware.py`)：

遵循 Django ASGI 中间件签名 `(app) -> async __call__(scope, receive, send)`（与 `core/middleware.py` 一致）。

提取逻辑（per AUDIT-02）：
- 仅处理 `scope["type"] == "http"` 请求（WebSocket 和其他类型跳过）
- 从 `scope` 重建请求上下文检查认证状态：
  - 检查 `scope.get("user")` 是否为 authenticated User → `actor_type="user"`, `actor_id=str(user.pk)`, `actor_display=user.username`
  - 如果 `scope.get("user")` 存在但不是 User 实例（可能是 SimpleLazyObject），用 `getattr` 安全取值
  - PAT 认证：检查 `scope.get("auth")` 是否为 `AccessToken` 实例（`hasattr(scope["auth"], "token_hash")`）→ `actor_type="pat"`, `actor_id=scope["auth"].token_hash`, `actor_display=getattr(scope["auth"], "name", "")`
  - 如果已认证用户（scope["user"].is_authenticated）但 auth 不是 AccessToken → JWT 路径 → `actor_type="user"`
  - 未认证 → `actor_type="system"`, `actor_id="anonymous"`
- 从 `scope["headers"]` 提取 `x-request-id`（如果存在）
- 从 `scope.get("client")` 提取 IP 地址（`(host, port)` tuple 取 host）
- 设置 contextvar → 调用 `self.app(scope, receive, send)` → finally 清理 contextvar

注意：Django ASGI 中间件在 `AuthenticationMiddleware` 之后执行时，`scope["user"]` 已被填充。确保本中间件在 MIDDLEWARE 列表中位于 `AuthenticationMiddleware` 之后。

**1. emitter 模块** (`server/audit/emitter.py`)：

沿用 `interactions/ledger.py` 的 sync/async 双入口 + best-effort 模式。

核心函数签名：

```python
def emit_audit_event(
    *,
    action: str,
    target_type: str,
    target_id: str = "",
    before: dict[str, Any] | None = None,
    after: dict[str, Any] | None = None,
    source: str = "",
    extra: dict[str, Any] | None = None,
    # 可选：显式覆盖 contextvars 中的 actor（某些系统操作需要）
    actor_type: str = "",
    actor_id: str = "",
    actor_display: str = "",
    ip_address: str | None = None,
    request_id: str = "",
) -> AuditEvent | None:
```

实现逻辑：
1. 从 `get_current_actor()` 获取默认 actor 信息
2. 显式传入的 `actor_type`/`actor_id`/`actor_display`/`ip_address`/`request_id` 覆盖 contextvars 默认值
3. 如果 `source` 为空，尝试从 contextvars actor 的 request_id 推断，否则默认 `"system"`
4. 包在 try/except 中，`AuditEvent.objects.create(...)`，写库失败降级 `logger.warning("audit_emit_failed", action=action, error=str(exc))` 返回 `None`
5. 成功时 `logger.debug("audit_event_emitted", action=action, event_id=str(event.event_id))` 返回 `AuditEvent`

异步入口：

```python
async def aemit_audit_event(...) -> AuditEvent | None:
    """emit_audit_event 的异步包装（adrf 异步视图调用）。"""
    return await sync_to_async(emit_audit_event)(...)
```

`__all__` 导出：`emit_audit_event`, `aemit_audit_event`。
