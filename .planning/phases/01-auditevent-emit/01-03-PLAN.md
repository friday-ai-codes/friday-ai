**1. Serializer** (`server/audit/api/serializers.py`)：

```python
from rest_framework import serializers
from audit.models import AuditEvent

class AuditEventSerializer(serializers.ModelSerializer):
    class Meta:
        model = AuditEvent
        fields = [
            "event_id", "actor_type", "actor_id", "actor_display",
            "action", "target_type", "target_id",
            "before", "after",
            "source", "request_id", "ip_address", "extra",
            "created_at",
        ]
        read_only_fields = fields  # 全部只读
```

**2. Views** (`server/audit/api/views.py`)：

使用 DRF `generics.ListAPIView` + `generics.RetrieveAPIView`（只读视图，不提供 Create/Update/Delete）。

权限：`permissions.IsAdminUser`（仅 superuser 可访问，per AUDIT-04）。在 view docstring 中说明"审计记录仅 superuser 可查，REST API 只提供 GET（list/detail），POST/PUT/PATCH/DELETE 均 405"。

`AuditEventListView(ListAPIView)`：
- `queryset = AuditEvent.objects.all().order_by("-created_at")`
- `serializer_class = AuditEventSerializer`
- `permission_classes = [permissions.IsAdminUser]`
- `filterset_fields`（或用 `django-filter`）：`action`, `actor_type`, `target_type`, `source`
- `search_fields`: `actor_id`, `action`, `target_id`, `request_id`
- `ordering_fields`: `created_at`, `action`
- `ordering = ["-created_at"]`（默认倒序）

`AuditEventDetailView(RetrieveAPIView)`：
- `lookup_field = "event_id"`（用 event_id 而非 pk，对外暴露的标识符）
- `queryset = AuditEvent.objects.all()`
- `serializer_class = AuditEventSerializer`
- `permission_classes = [permissions.IsAdminUser]`

关于 filterset：如果项目已安装 `django-filter`，用 `FilterSet`；否则通过 `queryset.filter()` 手动实现 query param 过滤。先检查项目 deps 中是否有 `django-filter`。

**3. URL 路由** (`server/audit/urls.py`)：

```python
from django.urls import path
from .api.views import AuditEventListView, AuditEventDetailView

app_name = "audit"

urlpatterns = [

    path("events/<uuid:event_id>/", AuditEventDetailView.as_view(), name="event-detail"),
]
```

**4. 注册 URL** (`server/friday/urls.py`)：
在主 URL 配置中添加 `path("api/audit/", include("audit.urls"))`。沿用现有 include 模式。

关于 POST/PUT/PATCH/DELETE 返回 405：DRF 的 `ListAPIView` 和 `RetrieveAPIView` 默认只支持 GET，其他方法自动返回 405。无需额外代码。
