## Task 1: REST API — List + Detail

### Prompt

Create read-only REST API for audit events in `server/audit/api/`.

**Serializer** in `server/audit/api/serializers.py`:

```python
class AuditEventSerializer(serializers.ModelSerializer):
    actor_username = serializers.CharField(source="actor_display", read_only=True)

    class Meta:
        model = AuditEvent
        fields = [
            "id", "timestamp",
            "actor", "actor_username", "actor_type",
            "action", "target_type", "target_id",
            "before", "after",
            "source", "ip_address",
        ]
        read_only_fields = fields
```

**Views** in `server/audit/api/views.py`:

```python
class AuditEventListView(adrf.ListAPIView):
    """管理员审计事件列表 — 仅限 is_superuser"""
    serializer_class = AuditEventSerializer
    permission_classes = [IsAuthenticated, IsSuperUser]
    queryset = AuditEvent.objects.all()
    filterset_fields = ["action", "source", "target_type", "actor"]
    search_fields = ["actor_display", "action", "target_id"]
    ordering_fields = ["timestamp", "action"]
    ordering = ["-timestamp"]
    pagination_class = PageNumberPagination  # default page size

class AuditEventDetailView(adrf.RetrieveAPIView):
    """管理员审计事件详情 — 仅限 is_superuser"""
    serializer_class = AuditEventSerializer
    permission_classes = [IsAuthenticated, IsSuperUser]
    queryset = AuditEvent.objects.all()

    # Block mutation methods explicitly
    def update(self, request, *args, **kwargs):
        return Response(status=status.HTTP_405_METHOD_NOT_ALLOWED)

    def destroy(self, request, *args, **kwargs):
        return Response(status=status.HTTP_405_METHOD_NOT_ALLOWED)
```

**URLs** in `server/audit/api/urls.py`:

```python
urlpatterns = [
    path("audit-events/", AuditEventListView.as_view(), name="audit-event-list"),
    path("audit-events/<uuid:pk>/", AuditEventDetailView.as_view(), name="audit-event-detail"),
]
```

**Register in `server/friday/urls.py`** (include audit urls under `/api/`).
