为 KDEP-04 在 `/knowledge` 知识树页（tree Tab）新增一棵**并行**「交付文档」树视图，与现有代码能力树（PageIndex，`KnowledgeTreePanel.vue`）通过视图切换并列。默认仍是代码能力树（既有行为不变），切到「交付文档」渲染新组件 `DeliveryDocsTree.vue`（项目 → 工件类型 → 工件，计数 + 类型徽标 + 载体图标 + 更新时间），切换状态存 URL `?view=docs`。
