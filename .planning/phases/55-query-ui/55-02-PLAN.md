# 55-02 — 审计导出（CSV / JSON 流式）

## Tasks
1. `server/audit/api/views.py`：`AuditEventExportView(APIView)`（同步 get，`IsSuperUser`）：
   - 复用列表过滤构造 queryset（不分页）。
   - `format=csv|json`（默认 csv）；`StreamingHttpResponse` + `Content-Disposition: attachment`。
   - `max_rows`（默认 50000）超限返回 400「请收紧过滤」。
   - CSV 列：occurred_at, actor_repr, action, target_type, target_id, target_repr, source, before, after, metadata（JSON 字段 json.dumps）。
   - 共享过滤逻辑：抽 `_filtered_queryset(params)` 供 list/export 复用。
2. `server/audit/urls.py`：`events/export/`（GET）。
3. `server/tests/audit/test_export_api.py`：csv/json 内容 + 过滤透传 + max_rows 400 + fail-closed 403。

## Acceptance
- CSV/JSON 导出含正确表头/字段、复用过滤、超限 400、非 superuser 403。
- `uv run pytest tests/audit/test_export_api.py -q` 全绿。
