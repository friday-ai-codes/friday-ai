| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-83-03-DOS | Denial of Service | 同步风暴/限流 | mitigate | per-doc 串行 lock=docsync-{feishu_document_id}（与 pull/poll 统一标识）+ debounce 合并 + @retry 退避；写不并发 |

| T-83-03-FAILSOFT | Tampering | push 失败反噬 | mitigate | best-effort，失败置 broken，钩子投递失败不阻断 DB 写 |
