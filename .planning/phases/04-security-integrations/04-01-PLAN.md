# Plan 04-01 — 后端：安全校验 + 飞书/RAG 配置编排端点

## Goal
新增三个挂载于 `/api/system/` 的 `IsSuperUser` 端点，全部复用既有 `SystemSetting` / `SettingKeys` /
`encrypt_value`（`bootstrap_system_settings` 同款加密写法），**不新建存储、不绕过加密、不阻塞向导**：
1. `GET /api/system/security-check/` — 只读检测 `SECRET_KEY`/`FRIDAY_ENCRYPTION_KEY` 安全性，返回布尔+风险清单，绝不回显密钥。
2. `POST /api/system/setup-feishu/` — 写 `FEISHU_APP_ID`(明文)/`FEISHU_APP_SECRET`(Fernet 密文)。
3. `POST /api/system/setup-rag/` — 写 `QDRANT_URL`/`EMBEDDING_*`(明文) 与 `QDRANT_API_KEY`/`EMBEDDING_API_KEY`(密文)。

## Tasks

1. **`server/system/setup_serializers.py`**（新建）
   - `SetupFeishuSerializer(serializers.Serializer)`：`app_id`(CharField, required)、`app_secret`(CharField, required, write_only, trim_whitespace=False)；`validate_app_id`/`validate_app_secret` strip 后非空。
   - `SetupRagSerializer(serializers.Serializer)`：`qdrant_url`(CharField, required)、`qdrant_api_key`/`embedding_api_url`/`embedding_api_key`/`embedding_model`(CharField, required=False, allow_blank=True)、`embedding_dimension`(IntegerField, required=False, allow_null=True, min_value=1)；`validate_qdrant_url` strip 非空。

2. **`server/system/setup_views.py`**（新建）— 三视图（adrf `APIView`，`permission_classes=[IsSuperUser]`）
   - `SetupSecurityCheckView.get`：
     - 读 `settings.SECRET_KEY`、`getattr(settings,"FRIDAY_ENCRYPTION_KEY","")`、`settings.INSECURE_SECRET_KEY`（导入或用常量字符串兜底）。
     - `secret_key_secure = bool(secret_key) and secret_key != INSECURE_SECRET_KEY`
     - `encryption_key_set = bool(enc_key)`
     - `keys_independent = bool(enc_key) and enc_key != secret_key`
     - `risks=[]`：分别 append `{code:"secret_key_default"|"encryption_key_unset"|"keys_not_independent", level:"warning"}`。
     - 返回 `{secure: all三者, secret_key_secure, encryption_key_set, keys_independent, risks}`，**不含任何密钥值**。
   - `SetupFeishuWizardView.post`：校验 → `@sync_to_async` `update_or_create`：
     - `FEISHU_APP_ID`：`defaults={"value": app_id, "is_encrypted": False, "description": "Feishu App ID configured via setup wizard"}`
     - `FEISHU_APP_SECRET`：`defaults={"value": encrypt_value(app_secret), "is_encrypted": True, "description": "..."}`
     - 返回 `{feishu_configured: True}`；结构化日志仅记键名，不记 secret。
   - `SetupRagWizardView.post`：校验 → `@sync_to_async` 仅对"已提供且非空"字段 `update_or_create`：
     - 明文：`QDRANT_URL`、`EMBEDDING_API_URL`、`EMBEDDING_MODEL`、`EMBEDDING_DIMENSION`(str(int))
     - 密文：`QDRANT_API_KEY`、`EMBEDDING_API_KEY`（`encrypt_value` + `is_encrypted=True`）
     - 返回 `{rag_configured: True, written_keys: [...]}`。
   - 键名一律 `SettingKeys.*`，加密一律 `common.encryption.encrypt_value`。

3. **`server/system/urls_system.py`**（改动）— 追加：
   - `path("security-check/", SetupSecurityCheckView.as_view(), name="setup-security-check")`
   - `path("setup-feishu/", SetupFeishuWizardView.as_view(), name="setup-feishu")`
   - `path("setup-rag/", SetupRagWizardView.as_view(), name="setup-rag")`

4. **`server/tests/test_setup_integrations.py`**（新建，APIClient + force_authenticate）
   - `test_security_check_reports_insecure_defaults`：`override_settings(SECRET_KEY=INSECURE, FRIDAY_ENCRYPTION_KEY="")` → `secure=False`、含三类 risk code；响应 JSON 不含任何密钥字符串。
   - `test_security_check_reports_secure`：`override_settings(SECRET_KEY="strong-x", FRIDAY_ENCRYPTION_KEY="indep-y")` → `secure=True`、`risks==[]`。
   - `test_feishu_setup_encrypts_secret`（FEISHU-01/02）：POST app_id+app_secret → 200；`FEISHU_APP_ID` 明文/`is_encrypted=False`；`FEISHU_APP_SECRET` `is_encrypted=True` 且 value 非明文、`decrypt_value` 还原；幂等二次 POST 仅一行。
   - `test_rag_setup_aligns_settingkeys_and_encrypts`（RAG-01/02）：POST qdrant_url+qdrant_api_key+embedding_* → 键名等于 `SettingKeys.*`；`QDRANT_URL` 明文、`QDRANT_API_KEY`/`EMBEDDING_API_KEY` 密文 + `decrypt_value` 还原。
   - `test_rag_setup_partial_only_writes_provided`：仅 qdrant_url → 不创建空的 key。
   - `test_setup_requires_superuser` / `test_setup_anonymous_rejected`：普通用户 403、匿名 401/403（三端点各覆盖）。

## Risks
- `INSECURE_SECRET_KEY` 取值：优先 `from friday.settings import INSECURE_SECRET_KEY`；若导入受限，硬编码同字符串常量并加注释。
- `override_settings` 仅改 Django settings 对象（不重启），端点读 `settings.*` 实时生效，测试可控。
- `EMBEDDING_DIMENSION` 以字符串存（SystemSetting.value 为 TextField），读侧 int() 解析既有，故写 `str(dimension)`。
