<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| 容器 task → Friday Server 回调端点 | report_question 携带 callback_token；question/context/code_snippet 文本来自编码 agent（半可信内容） |
| 共享卷 answer.json → 容器 | server 写入用户回答，容器读取（受 transfers 卷隔离，per-session 目录） |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-47-02 | Information Disclosure | report_question / ask_user 日志 | mitigate | question/context/code_snippet/answer 正文绝不入日志，仅记 has_*/question_id/status（D-05，对齐 RTOOL-03 脱敏） |
| T-47-03 | Denial of Service | ask_user 等待循环 | mitigate | 有界轮询 + `timeout_minutes` 上限；超时 default_option 或优雅失败，绝不无限挂起（D-04）；handler 永不 raise 崩容器（RTOOL-04） |
| T-47-04 | Tampering | answer.json 读取 | accept | answer.json 在 per-session transfers 卷，写入方为受信 server question_handler；容器仅消费回答文本作为 agent 上下文（非命令注入面，编码 agent 自行判断） |
</threat_model>
