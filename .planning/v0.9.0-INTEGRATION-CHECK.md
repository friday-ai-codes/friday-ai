## 链路 3：状态机 → gate（WIRED）

- **消费侧（Phase 51）** — `workflows/nodes/ai/coding.py::_apply_openspec_gate`（line 684-692）：
  ```python
  spec = await SddSpec.objects.filter(
      plan_version_id=task.plan_version_id,
      repository_id=task.repository_id,
  ).order_by("-updated_at").afirst()
  ```

- **fail-closed:** 未批准 / 无 spec / 校验异常 → `mark_gate_blocked`（`spec_not_approved` / `gate_error`）拦截不 dispatch，单仓 try/except 隔离不崩 wave，下游经 `aadvance_coding_waves` 传递闭包阻断。
- **零回归短路:** `service is None or tasks_by_repo is None`（legacy/非 wave）直接放行，不触发任何 `SddSpec` 查询。
- **测试证据:** `test_coding_openspec_gate.py`（11 passed，gate 全态 + 下游阻断 + fail-closed 隔离 + legacy 短路）。
