## Accomplishments

- server 重启不再丢「未派出」的编码/调研/摘要任务：`dispatch()` = redacted 快照落库（`last_output["dispatch"]`，非编码链由 dispatcher 统一补齐）+ defer `durable_runner_dispatch`（`lock=dispatch-{session_id}`、无 `idempotency_key`）；Postgres 路径由 procrastinate 持久化
- 无 runner / 无空槽时任务体按 5s→300s 指数退避 re-defer，runner 恢复后自动派出；`drain_pending` / `on_runner_online` / `on_task_rejected` 内存队列语义整体退役（`grep asyncio.Queue|drain_pending` 零命中）
- 重派幂等由状态守卫承担（终态 / active assignment → no-op），防重复容器 / 重复 commit 而不是禁止重派；rejected 重派走同曲线退避且 `reject_count≥8` 落终态 error + 吊销 token + `runner_dispatch_rejected_exhausted` 告警
- 凭证纪律：payload 只有 session_id/attempt；快照剔除 `CREDENTIAL_ENV_KEYS`（+ nested `git_credentials` 整体丢弃）；重建时 Git token / API key 从权威源 rehydrate、USER_TOKEN 按新增非敏感键 `task_token_user_id` 重铸（fail-soft）
- workflow 蓝图首驱不再内联：新建蓝图会话 defer `durable_blueprint_resume` 后返回 `waiting_event(kind=enqueued)`，回灌经既有 `_aresume_workflow_node_if_any` + 三层兜底（作答链 / 15min 保险丝 / 超时订阅），竞态与兜底已落注释；defer 失败降级内联；resume / 旧链 / chat 入口逐字不动
- 测试：新增 21 个用例（任务体守卫 / backoff 形参 / 成功派发链 / rehydrate+重铸 / stranded 扫描 / rejected 链 / 首驱入队四分支）；受影响面全量回归 2604 passed 零回归
