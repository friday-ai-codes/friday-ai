# Quick Task 260811-av8 — 统一仓库路由服务（v1 通道内化进 v2）

## 背景（已核实，勿重新调研）

### 现状

| 入口 | 当前调用 | 文件 |
|------|----------|------|
| 业务路由主路径 | `RepoRouterV2.route` | MCP / REST / skill_steps / blueprint / association / knowledge 等 |
| V2 节点无命中回退 | `_fallback_v1` → `RepoRouter.route` | `repo_router_v2.py` ~2181 |
| **LayeredSearch L1** | **直接** `RepoRouter.route`（BM25+关键词） | `layered_search.py` ~113 |
| v1 实现 | `repo_summaries` hybrid（sparse BM25 + dense）+ `_compute_keyword_score` 精排 | `repo_router.py` |

生产侧**唯一仍直调 v1** 的业务路径是 LayeredSearch L1；其余生产调用已是 V2。测试/fixture 里仍大量 patch `RepoRouter.route`（layered_search、mcp_read_flow、skill_workflow_trace、conftest）。

### 目标架构（锁定）

```text
业务入口 ──► RepoRouterV2.route（唯一公开路由服务）
                ├─ Stage0 repo_index_nodes hybrid …
                ├─ Stage1 LLM（可选，use_llm）
                └─ 无节点命中 → 内部通道 repo_summaries_channel
                       （原 v1：BM25+dense RRF + 结构化关键词精排）
                       → 映射为 RepoRouteResultV2（router_version=v1_fallback）
```

- **不**把 v1 保留为可独立调用的业务 service。
- **不**在本任务把 summaries 通道升级成 Stage0 并行融合召回（仅内化现有 fallback；并行融合若需要另开任务）。
- **不** commit（父 agent / 执行方负责）。

### 关键决策（实现必须遵守）

1. **D-01 唯一公开面**：对外只暴露 / 只允许业务调用 `RepoRouterV2.route`（及现有 adapter 对它的包装）。原 `RepoRouter` / `repo_router.py` 不再作为业务 API。
2. **D-02 内化而非删除**：把 v1 算法迁到 `repo_summaries_channel.py`（建议入口名 `route_repo_summaries`），由 `_fallback_v1` 独占调用；行为（hybrid 参数、权重、关键词字段、`RepoRouteResult` 字段语义）保持等价。
3. **D-03 L1 切 V2 + `use_llm=False`**：`LayeredSearchService._l1_repo_routing` 改为 `RepoRouterV2.route(query, top_k=min(top_k,5), use_llm=False)`。L1 是 RAG 热路径，禁止默认打开 Stage1 LLM（历史延迟 34–71s）。节点空时仍走内部 summaries 回退。
4. **D-04 输出兼容**：L1 `LayerResult.items` 继续提供 `repo_id` / `repo_name` / `score` / `match_reason`（从 V2 candidate 的 `repo_id`/`repo_name`/`score`/`reasoning` 映射）。异常时仍降级「已索引仓库前 N」，行为不变。
5. **D-05 降级可观测**：回退必须保留 `router_version="v1_fallback"`、`degraded=True`、`degrade_reason`→`no_node_index`；通道内补齐结构化日志（`category=sampling`，`component=repo_router_v2`，事件名建议 `repo_router_summaries_channel_started/completed/failed`，带 `duration_ms`；异常文本 `redact_secrets_in_text`；观测失败 swallow）。
6. **D-06 旧模块收口**：`repo_router.py` 可留薄 re-export（仅测试过渡）或改为明确「内部勿用」文档 + 转发到 channel；**生产代码**不得 `from codegraph.services.repo_router import RepoRouter` 后直调 `.route`（守卫测试锁定）。

### 不在范围

- 改 Stage0 打分公式 / 权重配置 / golden set 阈值。
- summaries 与 node-index 的并行 RRF 融合。
- 前端权重设置 UI、MCP 协议字段变更。
- ROADMAP / 里程碑台账。

**action:**

3. **改** `_fallback_v1`：改为调用 `route_repo_summaries`；映射逻辑、`classify_degrade_reason("v1_fallback")`、`RepoRouteResultV2` 字段保持现契约（既有 `test_degrade_reason_v1_fallback_is_no_node_index` 必须继续绿）。
