# 彻底清理仓库并恢复公开

## 目标

清除当前树和全部 Git 历史中的个人绝对路径、可识别业务语料、真实运营资料与清理审计残留；验证功能后强推全部分支与标签，最后恢复为 Public。

## 任务

1. 扫描当前树、全部 refs 和本地未跟踪敏感内容。
2. 将工具文件中的个人绝对路径改为可移植路径。
3. 将 golden/测试中的可识别业务语料改为完全通用的软件工程样例。
4. 删除不应公开的历史规划与一次性运维材料。
5. 运行重点测试和残留扫描。
6. 创建离线 bundle 备份，使用 `git filter-repo` 重写全部历史。
7. 强推所有分支和标签，恢复 Public，并用匿名请求验证。

## 约束

- `server/.env` 保持未跟踪，不上传。
- 不提交或覆盖 `mcp` 子模块本地修改。
- 重写前创建新的离线 bundle。
- Public 前必须保证敏感 token 扫描为零。
