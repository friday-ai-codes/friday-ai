# Quick Task 260611-g31: 打磨工作流列表与执行监控界面视觉

用户反馈：

- 工作流列表卡片视觉粗糙：缩略图空、卡片厚重、节点标签和执行按钮显得堆叠。
- 执行监控页也需要美化：顶部统计卡和表格里的“失败”状态太刺眼，筛选/表格整体偏笨重。

## Task 1: 锁定工作流列表卡片新结构

- 修改 `web/src/components/__tests__/workflow-data-table.test.ts`
- 新增断言：
  - 卡片外层使用 `.workflow-card`
  - 缩略图区域使用 `.workflow-preview`
  - 节点类型标签使用 `.workflow-node-chip`
  - 操作区使用 `.workflow-card-actions`
  - 执行按钮含 `.workflow-execute-button`

验收：先运行测试看到新结构断言失败，再实现通过。

## Task 2: 锁定执行监控页新结构

- 新增 `web/src/pages/executions/__tests__/index.spec.ts`
- mock TanStack Query、router、stores、DataTable、PageHeader 和 Select/Button
- 验证：
  - 顶部 KPI 使用 `.execution-stat-card`
  - 筛选栏包裹在 `.executions-filter-strip`
  - 状态列渲染局部 `.execution-status-pill`
  - `failed` 状态使用克制危险态 `.execution-status-pill--failed`

验收：先运行测试看到新结构断言失败，再实现通过。

## Task 3: 重做工作流列表和 mini map 视觉

- 修改 `web/src/components/workflow/WorkflowDataTable.vue`
- 修改 `web/src/components/workflow/WorkflowMiniMap.vue`
- 卡片改为 8px 圆角、轻边框、浅 hover；缩略图改为浅网格画布；节点标签改为浅 chip；执行按钮更扁平但仍保留主动作地位。

## Task 4: 重做执行监控页视觉

- 修改 `web/src/pages/executions/index.vue`
- KPI 卡改为轻量状态概览；筛选区改为低噪工具条；状态列改为局部 pill，失败态不再使用高饱和红底。
- 不改 `DataTable.vue` 通用组件，避免影响其他页面。
