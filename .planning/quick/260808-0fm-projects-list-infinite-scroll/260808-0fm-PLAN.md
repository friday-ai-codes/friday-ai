# Quick Task 260808-0fm: 项目列表倒序排列并支持无限滚动按需加载

**Date:** 2026-08-07
**Mode:** quick（inline 执行，跳过 research/discuss/validate）

## 背景

`/projects` 页面一次性拉全量项目列表；后端 `ProjectListCreateView.get` 无显式排序
（依赖模型 `Meta.ordering = ["-created_at"]`）也无分页。用户要求：

1. 倒序排列（越新越靠前）。
2. 无感的滚动按需加载（滚到底附近自动加载下一页）。

## 方案决策

- **排序**：视图查询显式 `order_by("-created_at")`，不依赖模型默认排序（join + distinct 下更稳）。
- **分页**：additive —— 请求带 `limit` 参数时返回 `{results, total, limit, offset}` 分页包；
  不带 `limit` 保持原数组响应，`BlueprintsTabPanel` 等既有调用方零改动。
- **前端**：`useInfiniteQuery` + `useIntersectionObserver`（@vueuse/core 已有依赖）哨兵元素，
  `rootMargin` 预取实现"无感"加载；每页 24 条（2/3 列网格均可整除）。
  不引入新的 DOM 虚拟化依赖（@tanstack/vue-virtual）——按需分页加载已满足"到那再加载"，
  响应式网格 + window 滚动下 windowing 复杂度高、收益低。
