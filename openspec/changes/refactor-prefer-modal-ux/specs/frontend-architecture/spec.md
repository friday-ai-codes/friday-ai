## ADDED Requirements
### Requirement: Modal-First Interaction Pattern
系统 SHALL 优先使用弹窗（Modal/Dialog）处理用户交互，而非跳转到子页面。
适用弹窗的场景：
- 查看单个实体的详情信息
- 编辑表单（字段数量适中）
- 确认操作（删除、提交等）
- 快速创建新实体
- 显示操作结果或错误信息
适用子页面的场景：
- 内容复杂，需要大量展示空间
- 包含多步骤的独立工作流
- 需要支持浏览器前进/后退导航
- 需要独立的 URL 用于分享或收藏
#### Scenario: 查看任务详情使用弹窗
- **WHEN** 用户点击任务列表中的某个任务
- **THEN** 系统在弹窗中展示任务详情
- **AND** 用户可以在弹窗中查看完整信息
- **AND** 关闭弹窗后回到原列表位置
#### Scenario: 编辑设置使用弹窗
- **WHEN** 用户点击编辑按钮修改某项设置
- **THEN** 系统弹出编辑表单弹窗
- **AND** 用户完成编辑后弹窗关闭
- **AND** 列表自动刷新显示更新后的数据
#### Scenario: 复杂流程使用子页面
- **WHEN** 用户需要进行多步骤的复杂操作（如创建项目向导）
- **THEN** 系统跳转到独立的子页面
- **AND** 子页面提供完整的工作流程空间
