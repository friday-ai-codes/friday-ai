# 高三提分专项（极速提分营）跨仓技术蓝图

## 执行摘要

为高三数学 60-100 分学生在 App 高中数学全部功能页新增「极速提分营」入口（课程包鉴权、fail-closed），提供按高考高频题型组织的「做真题→补知识→看讲解→做同型题」4 节点闯关闭环，以同型题结果量化掌握程度，暑期覆盖函数/导数/三角函数 3 版块约 30 个题型。

四仓直接改动：study-app 新建 speed-score-camp 子应用（8 页面 + 新手引导 + 入口改造）、problem-app 新增做题场景与倒计时插件、study-practice 新建 speedcamp 后端模块（状态机/进度/掌握度/作答会话）、study-course 提供权益校验与结构聚合。crs-special-course、basic-resource、wrong-problem 为间接依赖。回滚以入口配置开关为第一出口，无数据回滚。

## 需求规格

### 目标

持有「高三暑期数学提分专项」课程包的高三学生，能从 App「高中数学全部功能页」培优课模块的「极速提分营」入口进入题型图谱，对任一高频题型走完「做真题 → 补知识 → 看讲解 → 做同型题」4 节点闯关闭环，并在完成页获得可量化的掌握程度反馈（完全/初步/未掌握，仅按同型题 2 道结果判定）；学习进度与历史最佳掌握度跨页面一致且不回退。

### 背景

高三是付费能力最强但组合品转化率最低（0.86%，不足高一/高二的六成）且唯一「留存倒挂」的年级。根因是产品形态错配：核心动画课解决「听懂概念」，而高三刚需是「解题 + 应试稳定发挥」。本专项以题驱动的「诊断—学习—检验—反馈」确定性闭环，验证新产品形态对高三组合品转化率的拉动。

暑期覆盖函数、导数、三角函数 3 个版块约 30 个高频题型；目标用户为高三数学 60-100 分学生；目标上线 2026-07-15，此前经 618 预演（约 100 单期货售卖）与 7 月暑促（7/1-7/12）两次市场验证。

## 实现概述

### 需求叙事

总体路径：Wave 1 后端先行——study-course 落权益校验与专项结构聚合、study-practice 落专项模块（数据模型、4 节点状态机、作答会话与掌握度）；Wave 2 前端并行——problem-app 落做题场景与倒计时插件，study-app 新建 speed-score-camp 子应用并逐页接入（图谱→学习页→真题→知识卡片→视频→同型题→完成页），最后改造功能页入口；Wave 3 收尾——新手引导、埋点补齐、跨仓联调与灰度。

**impl_01 课程包权益校验接口（入口可见性 + 页面防越权）**

**impl_02 speedcamp 专项模块骨架与数据模型**

Kratos 标准分层新增 speedcamp 模块：api proto + biz + service + data

**impl_03 4 节点解锁状态机与节点完成接口**

状态机唯一写入口 NodeComplete（幂等）：同一（user, topic_type, node, session）重复上报不重复推进。

初始态: 仅 EXAM(做真题) 解锁
EXAM 首次完成:
  全对  -> 解锁 CARD(补知识) + VIDEO(看讲解) + SIMILAR(做同型题)
  未全对 -> 仅解锁 CARD
CARD 完成   -> 解锁 VIDEO
VIDEO 播放完成 -> 解锁 SIMILAR（先落库再返回，跳转前退出不丢）
SIMILAR 完成 -> 生成本次掌握度并更新历史最佳；progress=100%
任意节点重复完成 -> 状态与进度不回退

涉及文件：internal/biz/speedcamp/state_machine.go(create)

**impl_04 作答会话、提交判定与诊断合并（真题/同型题共用）**

CreateSession：按题型 + 节点类型（EXAM/SIMILAR）取题目 ID 列表建会话；中途退出重进即新会话（旧会话作废，满足「从第 1 道重开」）
SubmitAnswer：逐题判定、写 study_record、按端内契约投递答题 Kafka 事件（错题本/收藏自动生效）
整卷完成：EXAM 合并诊断（全对/未全对；仅 1 道时以该道为整体结果），首次结果写 first_exam_result 且不可覆盖
SIMILAR 完成：按 2/2、1/2、0/2 生成本次掌握度，历史最佳取 max

涉及文件：internal/service/speedcamp_session.go(create)

**impl_05 专项结构聚合接口（章/小节/题型图谱）**

### 业务影响

### 兼容风险与回滚

兼容风险：iOS/Android 双端 + 手机/平板多尺寸，横屏为主、竖屏响应式待 UED 设计稿；WebView 内图片全屏缩放与视频播放器手势存在机型差异，需真机矩阵覆盖。

回滚方案：第一层：服务端入口配置开关/权益配置关闭「极速提分营」入口，页面与接口自然不可达（分钟级，无数据回滚）；第二层：problem-app 场景配置与 study-course/study-practice 新接口独立于存量路径，可单独下线；已产生的学习进度、掌握度、错题数据全部保留。

## 验收锚点

### 可观察行为断言

- 持有「高三暑期数学提分专项」课程包的用户在高中数学全部功能页能看到「极速提分营」入口；无权限用户完全看不到（无置灰、无引导）
- 点击入口进入题型图谱页，题型卡展示进度条与掌握程度标签，离开后重进能恢复到上次位置
- 首次进入题型仅「做真题」可点，点待解锁节点有提示且不进入
- 首次真题全对同时解锁其余 3 节点并弹二选一弹窗；未全对仅解锁补知识并弹引导弹窗
- 视频播放完成后同型题解锁且该解锁在跳转前退出也不丢失
- 同型题 2 道完成后进入完成页，掌握程度按 2/2、1/2、0/2 三档生成并更新历史最佳
- 重做真题不覆盖首次诊断结果；学习进度与掌握度历史最佳永不回退
- 完成后返回学习页与功能主页均展示最新状态（旧掌握度视为缺陷）
- 真题与同型题答错自动进入错题本；两页均不展示习题年份
- 关闭入口配置开关后用户立即不可达新功能，已产生学习数据保留
