弹性流水线：不是一条死线，而是一组可回环的推进动作

Clarify -> Replan -> Execute -> Review -> Write back
01

接住需求

工作项、文档、评论、聊天消息或手动输入进入 Friday。

02

建立上下文

聚合飞书材料、仓库索引、历史执行和相关学习案例。

03

Graph RAG 找证据

语义检索后沿图谱扩散，补齐调用链和跨仓影响面。

04

生成方案并确认

写回飞书字段或文档，等待字段、卡片或人工审批。

05

Claude Code 执行

Runner 在隔离环境中编码、整理分支并保留执行日志。

06

审查与交付

自动 review、生成摘要，创建 PR / MR 或等待人工接管。

07

回写与学习

状态、结果、证据、失败恢复点回到飞书和审计轨迹。

多入口：飞书 / Web Chat / Skill / 未来系统
可暂停：等审批、等字段、等补充资料
可恢复：失败后重试、改计划、继续分支
可复用：索引、Trace、学习案例沉淀给下一次
